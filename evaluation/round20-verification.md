## 2. Блокер, найденный A6, — подтверждён и исправлен

В `index.astro` все четыре `<div class="fact-bg">` стояли подряд внутри **первой** плашки
(«Ростов-на-Дону, ул. Портовая, 439»); у плашек 2–4 своих слоёв не было вовсе. На экране это
значило: в первой плашке друг под другом лежат четыре фотофактуры, видна последняя (`about-f4`,
«сталь и резина»), а три остальные плашки прозрачные.

**Причина, почему гейт был зелёным, — и это главное в этой приёмке.** Проверка считала слои
**по всему документу**:

```js
if (cnt(/<div class="fact-bg" aria-hidden="true"><picture>/g) !== 4) bad.push(…);
```

Четыре слоя в документе есть → `4 === 4` → зелёный. Ровно тот случай, о котором в задании
написано «гейт, который не может упасть, — не гейт».

**Исправлено (оркестратор, `index.astro` + `check-about-bg.mjs`):**

1. по одному слою в каждой плашке: `f1` → адрес, `f2` → часы, `f3` → гарантия, `f4` → парк;
2. гейт теперь проверяет **вложенность**, а не счёт по документу: разбивает разметку по
   `<div class="fact…">` и требует ровно один `.fact-bg` внутри каждой из четырёх (то же для `.feat`);
3. добавлен мутант, воспроизводящий именно этот блокер: он падает с
   `разметка: в .fact №1 слоёв fact-bg = 4, ожидался ровно 1`.

Заодно поймано два ложных срабатывания собственной проверки — регулярка `.btn--ghost{…}` ловила
вхождение внутри `.about .btn--ghost{…}`, и парсинг `<div class="feat">` не видел
`<div class="feat reveal">`. Оба исправлены, после правки гейт зелёный.
