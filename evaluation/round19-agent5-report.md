## 7. Что не сделано / честно

1. Скринов Chromium нет: в sandbox браузер недоступен (apt и CDN вне allow-list). Всё визуальное —
   мок-рендеры sharp по формулам CSS + макетной модели раскладки; финальные скрины снимает оркестратор.
2. Проверка сирот (§2.2/2.3) — модель переносов с em-метриками, калиброванная ПО ЗАМЕРАМ оркестратора
   (95/85/18, 88/96, 99/12, 53/57), а не живой Range.getClientRects; модель — часть гейта и валит мутанты.
3. Макетные высоты в моках (1041/1037/999/1934/1759/2192) — моя модель раскладки; geometry.json оркестратора
   не перезаписывал (это входные данные гейта).
4. Воспроизводимость сборки доказана без 4 страниц demo-новостей (seed-времена); остальной набор побайтово идентичен.
5. Запас §2.5 по низу карточки B1 — 3,3 при норме ≥3: feather рампы съедает часть приглушения у границы полосы;
   увеличивать рампу не стал, чтобы не просадить пол видимости B1 (+5,3 сейчас).
6. origin/main (d0c382f) не мержил: неродственный корень, слияние удаляет работу (standing с r17).
7. Палитра, шрифты, тексты, телефоны, состав и порядок плашек не тронуты; `.btn--ghost` изменён только
