## Формы: что удалось прогнать

Автоматический прогон в jsdom — приближение, а не браузер: часть обработчиков реагирует на указатель и реальную видимость, поэтому «застрял на шаге» здесь **не значит «форма сломана»**.

| Агент | Что видно | Вывод |
|---|---|---|
| A1 | шаги 1→2→3, дальше «Далее» не проходит валидацию даты/слота | требуется проверка в браузере |
| A2 | шаги 0→1→2→3→4, на последнем не сработала отправка | требуется проверка в браузере; «Далее» блокируется до валидности — по заданию |
| A4 | «Шаг 1 из 5», 8 полей, марка выбирается чипом `[data-brand]`; «Далее» активна только после выбора | архитектура другая: экраны рендерит `assets/app.js`, в HTML нет `data-step` |
| A5 | остался на шаге 1: марка не проставилась автоматическим вводом | требуется проверка в браузере |
| A6 | шаги 1→2, «Далее» на шаге 2 осталась неактивной | требуется проверка в браузере |

Сквозной сценарий «открыл → заполнил → отправил → увидел номер заявки» **ни у одного мокапа не подтверждён**. Это ограничение проверки, а не доказательство дефекта. Первое, что стоит сделать заказчику при просмотре, — пройти форму целиком.
