## 2. Что A6 не заметил

### 2.1. PR тащит в репозиторий 46 файлов вне `site/` — и удаляет один файл из базы

В описании PR сказано: «вне `site/` обновлён только `docs/12-content-checklist.md`». Это неверно. `git diff --name-status` даёт 46 путей:

| Что | Сколько | Оценка |
|---|---|---|
| `promts/00-universal-agent-prompt.md` | 1 | **опечатка в имени каталога** (`promts` вместо `prompts`), копия нашего же файла |
| `agents/agent-05/concept.md` | 1 | дубль уже импортированного `agents-output/round1/agent-05/concept.md` |
| `mockups/agent-05/**` (круг 2, одностраничный) | 43 | дубль уже импортированного материала |
| `mockups/agent-05/mockup.html` | — | **удаляется** файл, который есть в базе |
| `docs/12-content-checklist.md` | 1 | разрешено, нужно |

Причина: ветка A5 содержит свои коммиты этапов 1–3, а мы импортировали их в другие пути. При merge «как есть» в репозитории появится второй набор мокапов, мусорный каталог `promts/` и пропадёт `mockups/agent-05/mockup.html`.

**Как забирать:** только `site/**` + `docs/12-content-checklist.md`. Не мержить ветку целиком. Это работа оркестратора при приёмке, A5 её делать не должен — но A5 стоит знать, чтобы не удивляться.
