# Перенос принятого сайта в `main` без закрытия сессии A5

Дата: 22.10.2026. Основание: решение заказчика — «мержить конечно же надо», но кодинг-сессию
с агентом 5 нужно сохранить, чтобы использовать его дальше (гейты G6/G7, правки после запуска).

## Почему не кнопкой «Merge pull request»

PR #5 (`arena/c0d7d4ba-avtotehservis` → `arena/099a14c5-avtotehservis`) — это и есть сессия A5.
Любой merge через GitHub закрывает PR и завершает ветку. Ветку `arena/c0d7d4ba-avtotehservis`
нельзя пушить из нашей сессии (правило Arena: работаем только в `arena/099a14c5-avtotehservis`),
поэтому единственный способ не потерять A5 — **не мержить PR, а перенести его содержимое**.

```

cd /tmp/clone-main/site && npm ci && npm test && npm run build && npm run migrate
```

Вывод: `main` — самодостаточный: клонируется, собирается, мигрирует и поднимается без ветки A5.
