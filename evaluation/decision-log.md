# Журнал решений

## 2026-10-21 — старт проекта

- Клиент: «АвтоТехСервис», Ростов-на-Дону, Портовая, 439. Рейтинг 4,5/182 (данные заказчика).
- Формат: одностраничник + квиз + галерея + отзывы + админка + e-mail/Telegram.
- Процесс: 5 агентов → скоринг → замены → 5 мокапов → выбор → код.
- Ограничения: mobile-first, лёгкая анимация, 152-ФЗ, без выдуманных фактов.

## 2026-10-21 — переработка конкурсного пакета (по замечаниям заказчика)

**Решения:**

1. **Один универсальный промпт** вместо пяти узких. Все агенты дают полноценную концепцию по 12 разделам; специализация — только акцент. Пропуск раздела = дисквалификация.
2. **После замен в конкурсе остаются пять участников.** Каждый делает свой HTML-мокап.
3. **Стек не зафиксирован.** Вместо тех-направления — `docs/02-solution-options.md`: требования, 4 класса решений, критерии, TCO, шорт-лист. Решение после мокапа и теста мобильной публикации.
4. **Палитра не задана.** Визуал выводится из концепции и проверяется на контраст.
5. **Отдельный разбор CMS vs самописной админки** — `docs/05-cms-vs-custom.md`, с фокусом на публикацию фото/видео с телефона.
6. **Добавлен фактчек** — `docs/06-fact-check.md`: версии, лицензии, цены, противоречия, что не проверено.
7. **Git-протокол для агентов:** ветка `agent/NN-*`, папка `agents/agent-NN/`, PR в `main`. Импорт — `scripts/import-agent.sh` с проверками.
8. **Гейт:** разработка не начинается до выбора мокапа заказчиком.

**Исправлено в собственных документах:**

| Было | Стало | Причина |
|---|---|---|
| Next 16 + Prisma + Tailwind как решение | варианты + критерии, выбор позже | запрет предрешать стек |
| 3 финалиста | 5 участников с мокапами | требование заказчика |
| Узкие промпты | один универсальный, 12 разделов | специализация отменяла разделы |
| Хостинг 800–1 500 ₽/мес | Beget ≈960–1 140, Timeweb от 1 920 | проверка цен |
| Node 22 LTS | Node 24 (maintenance), далее 26 | 22 в maintenance |
| WordPress 6.x | 7.1.3 | проверка версий |
| «Prisma 7» | `latest` = 8.0.0-rc.23, клиент 7.10.1 | проверка dist-tags |
| «Публикация с телефона работает» | «требует теста на iPhone/Android» | нет результата проверки |

**Проверено инструментами:** 6 тестов `import-agent.sh` (dry-run, копирование, секрет, внешний JS, отсутствие папки, отсутствие файла) — все дали ожидаемый результат; 21.10.2026.
