# Журнал решений

## 2026-10-21 — старт проекта

- Клиент: «АвтоТехСервис», Ростов-на-Дону, Портовая, 439. Рейтинг 4,5/182 (Яндекс).
- Формат: одностраничник + квиз + галерея + отзывы + админка + e-mail/Telegram.
- Процесс: 5 агентов → скоринг → 3 финалиста → HTML-мокапы → выбор → продакшн-код.
- Тех-направление: Next.js 16 + React 19 + Tailwind 4 + Motion 14 + PostgreSQL + Prisma 7; VPS в РФ, Docker.
- Ограничения: mobile-first, лёгкая анимация, 152-ФЗ, без выдуманных фактов.
