# logo/ — вектор знака и лейбла Voyah

Задание №45, агент 11 (направление «векторная графика»).

## Файлы

| Файл | Что это |
|---|---|
| `vy-mark.png` | **эталон**: файл владельца из Google Drive, `Voyah_Logo-1536x864.png` (1536×864, RGBA, знак и лейбл в альфа-канале) |
| `vy-logo.svg` | сдача: знак + лейбл, только `<path>`, лейбл контурами, `viewBox="0 0 804 765"` |
| `vy-mark.svg` | только знак (2 лопасти + игла), `viewBox="0 0 441 622"` |
| `vy-mark-paths.json` | те же контуры для 3D-экструзии другому агенту |
| `compare.png` | эталон · вектор · наложение · карта ошибки контура |
| `metrics.md` | отчёт: допуски и факт |
| `check-voyah-vector.mjs` | проверка допусков, при нарушении — код выхода 1 |
| `tools/vectorize.py` | сборка SVG и JSON из растра (воспроизводимо) |
| `tools/verify.mjs`, `tools/svg-path.mjs`, `tools/png.mjs`, `tools/json-contours.mjs` | общее ядро: метрика контура, разбор path, PNG-кодек |
| `tools/make-report.mjs` | сборка `compare.png` и `metrics.md` |

## Допуски

| Проверка | Допуск |
|---|---|
| средняя ошибка контура к эталону | ≤ 1.5 px |
| максимальная ошибка контура | ≤ 3 px |
| вес SVG | ≤ 4096 байт gzip (level 9, без имени файла — число детерминировано) |
| текст в SVG | 0 элементов `<text>`/`<tspan>`, шрифты не используются |
| лейбл | 5 глифов контурами + отверстие O |
| знак | 2 лопасти + игла |
| IoU площади | ≥ 0.96 (4× суперсэмплинг) |
| разница площади | ≤ 1.5 % |
| покрытие с допуском 1 px | 100 % |
| расхождение JSON ↔ SVG | ≤ 0.1 px |

Факт: среднее **0.317 px**, максимум **1.294 px**, gzip **1659 байт**, IoU **0.993**.
Подробности — `metrics.md`.

## Команды

```bash
# пересобрать вектор из растра владельца (numpy, scipy, scikit-image, pillow)
python3 logo/tools/vectorize.py

# проверить допуски: 0 — в допуске, 1 — нарушения, 2 — нет входных файлов
cd logo && npm install && node check-voyah-vector.mjs
node check-voyah-vector.mjs --json          # машиночитаемый отчёт

# проверить другой файл (негативный тест, проверка чужой сборки)
node check-voyah-vector.mjs --svg path/to/other.svg

# пересобрать сдачу
node logo/tools/make-report.mjs
```

`npm install` нужен только для `@resvg/resvg-js` (настоящий SVG-рендерер в растровой
сверке). Без него проверка работает встроенным растеризатором по правилу nonzero —
и это честно пишется в отчёте.

## Как получен вектор

Изолиния 50 % альфа-канала → углы в трёх масштабах с уточнением по прямым → участки
между углами приближаются отрезками, дугами окружности и кубическими Безье с контролем
цепочки целиком. Полное описание — в `metrics.md`.
