# Задание 78 · Агент 1 — кейсы на главной без заглушек + озвучка каруселей

Ты **Агент 1** («обложки и главная»). Работаешь в репозитории `sledovatel61/avtotehservis` (сайт
автосервиса «АвтоТехСервис», Ростов-на-Дону). Astro + Node, публикация — статическая
превью-сборка на GitHub Pages. Все тексты по-русски, тон спокойный, без рекламных преувеличений.

Ты один из четырёх агентов круга 78. Остальные параллельно правят другие файлы —
**строго держись своей зоны** (§5). Твой единственный файл-страница — `index.astro` и `about.astro`,
их больше никто не трогает.

---

## 1. Задача

На главной блок «Шесть кейсов „до / после“» показывает шесть векторных заглушек
(`/img/case-1.svg` … `case-6.svg`), поверх картинки бейдж «до / после», под лентой приписка
«Показываем только реальные работы — фото появятся после съёмки». На странице «О компании» те же
шесть кейсов уже выводятся фото-иллюстрациями (`/img/ab-case-1-640.avif|webp` … `ab-case-6`)
с подписью «пример работы».

Нужно: главную привести к тому же виду (реальные кадры вместо схем, честная подпись, без обещаний
«до / после»), и попутно починить озвучку каруселей для незрячих пользователей.

---

## 2. Что сделать

### 2.1 Кадры кейсов на главной
1. Карта `CASE_COVERS` живёт в `site/src/pages/about.astro`. Не делай третью копию: вынеси её
   в `site/src/server/case-covers.ts` (тип `{ avif: string; webp: string; alt: string }`),
   импортируй в `about.astro` и `index.astro`.
2. На главной в секции `aria-labelledby="gal-h"` замени `<img src={cov.src} …>` + бейдж
   `<span class="ba">до / после</span>` на разметку как в `about.astro`:
   `<picture><source type="image/avif" srcset={cv.avif}><img src={cv.webp} …></picture>`,
   `sizes="(max-width:640px) 84vw, (max-width:1024px) 44vw, 380px"`,
   `width="640" height="480"`, `loading="lazy" decoding="async"`, `alt` из карты.
3. Бейдж-обещание убрать с картинки. Допустимая подпись в `gal-cap--case` — «пример работы»
   (как на «О компании»).
4. Приписку `p.gal-note` («Показываем только реальные работы — фото появятся после съёмки»)
   удалить совсем. Фраза про съёмку не должна остаться нигде в блоке.
5. Атрибуты карусели и лайтбокса (`data-carousel`, `data-gal`, `data-img`, `data-title`,
   `data-sub`, `aria-label`) не меняй — на них завязан существующий jsdom-тест лайтбокса.
   `data-img` должен остаться крупным кадром (`cv.webp`), иначе лайтбокс покажет мелкий.

### 2.2 Заголовок и подпись
- `h2 id="gal-h"`: «Шесть кейсов из практики». Eyebrow «Галерея работ» оставить.
- Цены и названия кейсов не менять.

### 2.3 Озвучка каруселей
Для незрячих карусель объявляет «Экран 1 из 6» (слово по умолчанию в
`site/src/client/global.ts`, атрибут `data-live-word`). Нужно:
- на главной: карусель кейсов (`sec` с `gal-h`) — `data-live-word="Кейс"`;
  карусель отзывов (`sec` с `rev-h`) — `data-live-word="Отзыв"`;
- на «О компании»: карусель кейсов (`ab-gal-h`) — «Кейс», карусель отзывов (`ab-rev-h`) — «Отзыв»;
- карусель услуг на главной уже имеет `data-live-word="Услуга"` — не трогай;
- `global.ts` **не твой файл** — не правь его (слово по умолчанию меняет Агент 4).
