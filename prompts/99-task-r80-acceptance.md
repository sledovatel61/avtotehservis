## 3. Отчёт

Куда: комментарий к PR #42 (`gh pr review 42 --comment --body-file …` из клона в `/tmp`,
не из `/tmp`-worktree без `.git`-контекста) плюс файл `reviews/r80-acceptance.md` в своей ветке
`arena/...`. В чат — короткое резюме.

Формат вердикта:

- **BLOCKERS** — что нельзя пускать на живой сайт (с `файл:строка` и воспроизведением);
- **MAJOR** — что портит впечатление, но не блокирует;
- **MINOR** — косметика;
- таблица гейтов (гейт → rc/вывод);
- отдельно: «на владельца» (юридическая вычитка согласия и политики, домен);
- отдельно: «долг, не этот круг» (два падающих теста, если подтвердились на базе).

Вердикт одной строкой: APPROVE / APPROVE WITH COMMENTS / REQUEST CHANGES.

**Помни:** PR мержит только владелец через оркестратора. Твой APPROVE — это разрешение
сводить ветку, а не публикация.
