## 2. Арт-дирекшн: что должно быть на каждом кадре

Общее для всех четырёх:

* **тёмная атмосфера, а не «обложка»**. Картинка живёт под скримом 0.65–0.78 — она должна
  читаться как **фактура и свет**, а не как сюжет с деталями. Свет мягкий, источник один-два,
  глубокие тени, лёгкое зерно, никакой HDR-жёсткости;
* **палитра из темы**: ночь `#0B1410`, глубина `#10201A`, изумруд `#4E9E74`, медь `#C87F45`,
  латунь `#E0A96D`, слоновая кость только как свет. Зелёные тени + тёплый медный ключевой свет —
  та же связка, что на первом экране (неон вывески + лампы в боксах);
* **никакого текста, логотипов, номеров, лиц, водяных знаков**. Генераторы в прошлых кругах
  рождали битые глифы на вывеске — здесь любая надпись = перегенерация кадра, а не замазывание;
* **не коллаж**: один фотографический кадр, без рамок, бордюров и «наклеенных» элементов;
* **ни одного узнаваемого бренда** — секция про сервис, а не про марку.

### 2.1. Фон секции (2 варианта одного сюжета)

Не сцена, а **атмосфера цеха**: глубина бокса, размытые пятна ламп, стойка с инструментом
в расфокусе, легкая дымка/пыль в контровом свете, мокрый бетон с отражениями, тонкие
зелёные отблески. Допустимо: стеллаж с шинами в расфокусе, подъёмник без машины, канистры,
пневмошланги. Недопустимо: читаемые машины крупным планом, люди в фокусе, вывески, окна с улицей.

Композиция — **центрально-симметричная по смыслу**, потому что кроп гуляет (см. §3.1):
интересное — в центральной трети по ширине; края — ровный тёмный фон, который можно резать
без потерь. Верх кадра — темнее (за заголовком идёт текст), низ — чуть светлее (там подпись
и воздух).

### 2.2. Карточка 01 «Колёса»

Макро-атмосфера шины: протектор, боковина, диск в контровом свете, капли воды на резине,
пыль в луче. Угол — низкий, боковой. Цвет: графит + зелёный отблеск, медь на кромке диска.
Без читаемых надписей на боковине (обычно генератор пишет там абракадабру — лучше кадр,
где надпись не попадает в фокус).

### 2.3. Карточка 02 «Ремонт и ТО»

Подкапотное/подъёмник: металл, патрубки, блик на крышке, тёплый медный свет лампы,
капли масла на металле, руки в перчатках **вне фокуса** (или без рук вовсе). Это самая
«тёплая» карточка серии — она же средняя, акцентная.

### 2.4. Карточка 03 «Диагностика»

Сканер/экран диагностики в расфокусе (зелёное свечение без цифр и букв!), провода, разъёмы,
осциллограммы как чистые светящиеся линии, холодный изумрудный свет + отблеск на металле.
Это самая «холодная» карточка серии.

**Логика серии:** 01 — зелёно-графитовая (холодная), 02 — медно-тёплая (акцент), 03 —
изумрудно-холодная. Порядок «холодная → тёплая → холодная» держит середину акцентной,
как сейчас с градиентом.

## 3. Технические требования, без которых будет брак

### 3.1. Кропы: посчитаны, а не «на глаз»

Карточка в сетке имеет **разные пропорции на разных ширинах** (замерено рендером):

| окно | карточка | что видно из мастера 2400×1600 (`object-fit:cover`, центр) |
|---|---|---|
| 1440 / 1920 | 375×369 | x **16,1…83,9 %**, y 0…100 % |
| 1024 | 984×269 | x 0…100 %, y **29,5…70,5 %** |
| 768 | 728×287 | x 0…100 %, y **20,4…79,6 %** |
| 390 | 350×386 | x **19,8…80,2 %**, y 0…100 % |
| 360 | 332×387 | x **21,4…78,6 %**, y 0…100 % |

**Безопасная зона сюжета в мастере 2400×1600: x 514…1886, y 472…1128**
(21,4…78,6 % по ширине, 29,5…70,5 % по высоте). Всё, что должно быть видно на всех
пяти ширинах, — только здесь. За её пределами — ровный тёмный фон, который не жалко резать.

Фон секции, мастер 2560×1440:

| окно | что видно |
|---|---|
| 1440×680 | вся ширина, y 8…92 % |
| 1024×1142 | x **24,8…75,2 %**, вся высота |
| 768×1111 | x **30,6…69,4 %**, вся высота |
| мобильный 900×1600: 390×1434 | x **25,8…74,2 %**, вся высота |

Пересечение для десктопного мастера: **x 782…1778, y 116…1324** — «сюжет» только там,
края однородные. Для мобильного мастера 900×1600: **x 249…651**.

### 3.2. Сборка и вес

Картинки не кладём в сайт «как есть» — прогоняем через `site/scripts/build-images.mjs`
(как остальные фото): `sharp`, avif + webp, лимиты по весу. Новые ключи `CAPS`
(ориентир, финальные согласуй с замером):

```js
'tri-bg-2560':    { avif: 130, webp: 150 },   // фон секции, десктоп
'tri-bg-960':     { avif: 70,  webp: 80  },   // фон секции, планшет/узкий
'tri-bg-m-900':   { avif: 80,  webp: 95  },   // фон секции, мобильный (900×1600)
'tri-wheel-1600': { avif: 70,  webp: 80  },   // 01
'tri-wheel-960':  { avif: 45,  webp: 50  },
'tri-wheel-640':  { avif: 28,  webp: 32  },
'tri-serv-1600':  { avif: 70,  webp: 80  },   // 02
'tri-serv-960':   { avif: 45,  webp: 50  },
'tri-serv-640':   { avif: 28,  webp: 32  },
'tri-diag-1600':  { avif: 70,  webp: 80  },   // 03
'tri-diag-960':   { avif: 45,  webp: 50  },
'tri-diag-640':   { avif: 28,  webp: 32  },
```

Итого добавка к странице на 1440 — **не больше 400 КБ** во всех форматах, на телефоне — не больше
160 КБ. Всё — `loading="lazy" decoding="async"`, вне первого экрана.

### 3.3. Разметка и CSS

* фон карточки — отдельный слой, а не `background-image` на `.tri-card`
  (иначе не отдадим avif/webp через `<picture>` и не сможем анимировать):
  `<div class="tri-bg" aria-hidden="true"><picture>…<img alt="" …></picture></div>`,
  `position:absolute; inset:0; z-index:0; overflow:hidden`;
* контент карточки — `position:relative; z-index:1`;
* скрим поверх фото — отдельным слоем `::after` на `.tri-bg`, **не** на тексте:
  `linear-gradient(180deg, rgba(11,20,16,.55) 0%, rgba(11,20,16,.72) 38%, rgba(11,20,16,.86) 100%)`
  (числа согласуй сам по замеру контраста, §4);
* **радиус**: карточка `border-radius: var(--r)` c `overflow:hidden` — фото обязано обрезаться
  скруглением, никаких прямоугольных углов внутри;
* **hover**: сейчас карточка светлеет. С фото фон на hover — `scale(1.03)` слоя `.tri-bg`
  за 600 мс и усиление скрима на 0.04; при `prefers-reduced-motion: reduce` — без масштаба;
* `.tri-card--accent` оставить акцентной: поверх её фото — изумрудная тонировка
  (`box-shadow: inset`, `mix-blend-mode: soft-light` или полупрозрачный слой `#1C3126`),
  но не градиент «вместо» фото;
* на 1024 и ниже (карточки в один столбец, 984×269) и на ≤640 — те же мастера, кроп центрируется;
  ничего не «пересобираем» вторыми мастерами;
* фон секции — на `.sec--deep.dirs` (новый модификатор), `background-size:cover`,
  `background-position:50% 45%`, под ним сплошной `--deep` (чтобы не мигало до загрузки);
  мобильный вариант — `@media (max-width:640px)` через `-webkit-image-set`/`image-set()`
  или просто вторым правилом с `image-set`; если `image-set` с `type()` не проходит по браузерам —
  отдельное правило через `@media` и два файла.

### 3.4. Доступность

* все четыре картинки — декоративные: `alt=""`, `aria-hidden="true"` на обёртке,
  `pointer-events:none`;
* при `prefers-reduced-data: reduce` — не грузить фоны карточек (оставить текущие плашки);
* при `print` — фоны off, текст чёрным по белому;
* контраст текста — по §4, это не «пожелание», а гейт.

## 4. Контраст: числа, которые нельзя нарушить

Текст в карточке: `h3` — слоновая кость `#F4EFE6`, абзац — `#B7C4BB` 15,5 px, ссылка —
латунь `#E0A96D` 14,5 px. Нормы: абзац и ссылка — **≥ 4,5:1** (ссылка — самый строгий случай,
она светлее всех по относительной яркости), заголовок — ≥ 4,5:1.

Предельная яркость фона под текстом (серый эквивалент):

| цвет текста | максимум фона при 4,5:1 |
|---|---|
| `#F4EFE6` | 109 / 255 |
| `#B7C4BB` | 80 / 255 |
| `#E0A96D` (ссылка) | **70 / 255** |

Скрим над фото `#0B1410`:

| альфа скрима | какой фон под текстом ещё проходит |
|---|---|
| 0,60 | ≤ 149 / 255 |
| 0,66 | ≤ 172 / 255 |
| **0,72** | ≤ 205 / 255 |
| ≥ 0,78 | проходит при любом фоне |

Вывод: **скрим 0,72 и темнее** — рабочий диапазон; выбирай самое тёмное, при котором картинка
ещё видна. Проверять не на глаз, а пиксельно (см. §5).

Фон секции: заголовок `h2` — 36,8 px (`2.3rem`), две строки, блок 84 px; по WCAG это
**крупный текст**, норма 3:1. Но под ним в кадре должны быть тёмные зоны — проверь худший
пиксель той же функцией, что для карточек.

1. **`site/scripts/check-dirs.mjs` — новый.** Считает ровно те кропы, что в §3.1, из настоящих

   * все 4 мастера и все производные файлы существуют, размеры совпадают с заявленными;
   * вес каждого файла ≤ `CAPS`;
   * «сюжетная зона» (задаётся в `docs/photos-source/r18-dirs/zones.json` — прямоугольники

   * в CSS есть `.tri-bg` с `object-fit:cover`, скрим и `border-radius` наследуется от карточки;
   * **самопроверка на мутантах**: сдвинуть зону за край → падает; поставить `object-position:0 0`
     → падает; уменьшить скрим до 0,4 → падает; вернуть плоский фон без `<picture>` → падает.
2. **`measure-contrast.mjs` — расширить**: для каждой из трёх карточек посчитать худший пиксель
   **в зоне текста** (x 27…348, y 113…340 в координатах карточки 375×369 — замерено рендером;

   Плюс зона заголовка секции (3:1). Мутант: убрать скрим → гейт обязан упасть.
3. `check-pages.mjs`, `check-cascade.mjs`, `check-hero-layout.mjs`, `check-safe-zone.mjs` —
   должны остаться зелёными (ты их не ломаешь).

**Правило круга 16, оно остаётся:** у каждого нового гейта есть секция «самопроверка на мутантах»,

## 7. Чего не делать

* Не менять тексты, сетку, шрифты, палитру, порядок карточек, ссылки.
* Не ставить фото «в рамке» и не превращать карточку в открытку: это фон под текстом.
* Не генерировать фон «на 100 % ширины» одним файлом и не растягивать его на мобильном —
  для мобильного секции отдельный вертикальный мастер (§1).
* Не «рисовать» разметку и надписи в картинке — генератор их искажает, а замазывать нельзя.
* Не тащить новые зависимости: `sharp` уже есть.
* Не оставлять `Math.random()` в сборке — воспроизводимость (`sha256` двух сборок) остаётся.
* Не «улучшать» попутно другие секции: круг 17 — только фоны «Трёх направлений».
