# Как запустить конкурс

## Один промпт на всех

Главный файл — **`00-universal-agent-prompt.md`**. Он одинаковый для всех пяти агентов.

1. Открой пять отдельных чатов (агенты не должны видеть работы друг друга).
2. Отправь каждому файл целиком и одну строку:

```
Ты Агент 1, работай по промпту.
```

Номер — от 1 до 5. Больше ничего добавлять не нужно: этап, структура, критерии и git-протокол уже внутри.

3. Агент сам создаёт ветку `agent/NN-<слаг>`, коммитит в `agents/agent-NN/` и открывает PR в `main`.
4. Ты присылаешь мне **номер PR или ссылку**. Дальше я подтягиваю работу скриптом:

```bash
# из корня репозитория
scripts/import-agent.sh --branch agent/01-brand-concept
```

Скрипт проверит, что в ветке нет лишних файлов, секретов и бинарников, скопирует работу в `agents-output/` и напечатает отчёт. Если PR ещё не влит — это нормально: скрипт читает ветку, а не мержит её.

> Если у агента нет прав на push, он обязан честно написать «push недоступен» и приложить полный файл. Тогда просто сохрани текст в `agents-output/round1/agent-NN/concept.md` — я подхвачу.

## Что важно

- **Не подсказывай агентам «правильный» ответ.** Чем независимее концепции, тем полезнее сравнение.
- **Не давай им другие файлы репозитория**, кроме промпта. Иначе они начнут соглашаться с чужими решениями вместо того, чтобы предлагать свои.
- **Все пять работ — полноценные.** Специализация агента — только акцент; если он пропустил раздел, он получает дисквалификацию, а не скидку.
- **Мокапы делают все пять**, а не только финалисты. Замены нужны, чтобы поднять уровень, а не чтобы сократить число участников.
- **Разработка не начинается**, пока ты не выберешь мокап. Это зафиксировано в промпте и в плане.

## Этапы

| Этап | Команда агенту | Файл | Что делаю я |
|---|---|---|---|
| 1. Концепции | «работай по промпту» | `agents/agent-NN/concept.md` | скоринг 100 баллов, таблица, разбор, замены |
| 2. Мокапы | «ЭТАП 2» (пять агентам) | `agents/agent-NN/mockup.html` | проверка по чек-листу, сборка превью, рекомендация |
| 3. Код | только победителю | ветка `dev` | ревью каждого PR, приёмка |

## Файлы

- `00-universal-agent-prompt.md` — единственный промпт для рассылки.
- `00-context-pack.md` — факты отдельно, для замен и дополнительных агентов.
- `../scripts/import-agent.sh` — импорт ветки агента с проверками.
- `../docs/06-fact-check.md` — что проверено, что нет и какие есть противоречия.
