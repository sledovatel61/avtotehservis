# Промпты для 5 агентов

## Как запускать

1. Открой пять агентов **в отдельных чатах** (чтобы они не видели ответы друг друга).
2. Каждому отправь **один** файл целиком — промпты самодостаточные, контекст уже внутри:
   - Агент 1 → `01-brand-strategist.md`
   - Агент 2 → `02-art-director.md`
   - Агент 3 → `03-ux-cro-architect.md`
   - Агент 4 → `04-tech-architect.md`
   - Агент 5 → `05-copy-content.md`
3. Если у агента есть доступ к интернету — он обязан им пользоваться (в промпте это указано). Если нет — он помечает непроверенное.
4. Ответы сохрани в `agents-output/round1/` с именами:
   - `agent-01-brand.md`
   - `agent-02-art.md`
   - `agent-03-ux.md`
   - `agent-04-tech.md`
   - `agent-05-copy.md`
5. Принеси их сюда — я оценю по рубрике и покажу таблицу.

## Что важно

- **Не подсказывай агентам «правильный» ответ.** Чем независимее концепции, тем полезнее сравнение.
- **Не давай им этот репозиторий целиком** — только промпт. Иначе они начнут соглашаться с брифом вместо того, чтобы предлагать.
- **Не проси код в раунде 1.** Это этап идей; HTML-мокапы будут в раунде 2.
- Если агент выдал воду — не переспрашивай «сделай лучше», а верни ему пункт «Формат ответа» и попроси переписать по разделам. Слабая работа должна дойти до меня как есть, иначе я не смогу честно сравнить.

## Общий контекст

`00-context-pack.md` — тот же набор фактов, что внутри каждого промпта, отдельным файлом. Нужен, если захочешь запустить дополнительного агента или замену: просто добавь контекст-пакет + новый мандат.

## Раунд 2

`06-round2-mockup.md` — задание на HTML-мокап. Отправляется только финалистам после скоринга, с подстановкой названия концепции и бренда.
