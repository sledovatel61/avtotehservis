## Дефект 1 — оценка подставляется «пятёркой» (нарушение правила владельца)

Правило владельца: **выдуманные оценки запрещены**, в том числе в админке. Сейчас в `reviews.js`:

- строка 59: «+ Добавить отзыв» создаёт `{ …, rating: 5, … }`;
- строка 56: «Разобрать» создаёт `rating: parsed.rating ?? 5`;
- выпадающий список оценки (`labelInput('Оценка', 'rating', …)`) вообще без пустого варианта — человек не видит, что оценку надо поставить самому, и сохраняет пятёрку не глядя.

Сделать:

1. Пустое значение по умолчанию: `rating: null` (в черновике — `null`, а не `0` и не `5`).
2. В `<select>` первым пунктом — `value=""` с текстом «— выберите оценку —», он же выбран для `null`.
3. `reviewErrors()` уже требует целое 1–5 → при `null` кнопка «Добавить в список» заблокирована, ошибка «Выберите оценку от 1 до 5.» показывается после попытки/при касании. Поведение не менять, оно верное.
4. При «Разобрать» из Telegram: если оценка в сообщении не нашлась — `null` (человек ставит сам), а не 5.
5. `demo: false` для отзывов из Telegram оставить.

## Дефект 2 — «Разобрать» не разбирает настоящее сообщение из Telegram

Формат, который реально приходит от воркера (`relay/src/telegram.ts`, `composeReviewTelegram`):

```
⭐ Новый отзыв с сайта (на модерации)

Оценка: 5/5 ⭐⭐⭐⭐⭐

Имя: Павел И.

Отзыв:
Заезжал на шиномонтаж, приняли вовремя, всё аккуратно.

Источник: /otzyvy

Согласие на обработку ПД: версия 2026-11-20, отметка 19.11.2026 14:22 МСК

Опубликовать: админка → Отзывы
```

Текущий `parseTelegram()` ищет строку строго как `^\s*Оценка\s*:\s*([1-5])\s*\/\s*5\s*$` — со звёздочками в конце она не совпадает, поэтому оценка теряется (и падала бы в 5). Всё остальное — заголовок «⭐ Новый отзыв…», «Отзыв:», «Источник:», «Согласие…», «Опубликовать…» — попадает в текст отзыва, то есть в публикацию.

Сделать нормальный разбор:

1. Оценка: искать `Оценка:\s*([1-5])\s*/\s*5` в любом месте строки, хвост со звёздочками игнорировать; нет совпадения → `null`.
2. Имя: `Имя:\s*(.+)` (после снятия HTML-тегов и `*`/`_` разметки, если сообщение скопировано с разметкой).
3. Текст: всё после строки `Отзыв:` до первой служебной строки (`Источник:`, `Согласие на обработку`, `Опубликовать:`). Если строки `Отзыв:` нет — брать все строки, кроме служебных и заголовка, как раньше.
4. Выбрасывать: строку с «Новый отзыв с сайта», пустые строки по краям, служебные строки (`Источник:`, `Согласие на обработку ПД:`, `Опубликовать:`), эмодзи `⭐` в начале текста.
5. `source: 'site'`, `status: 'hidden'`, `published_at` = сегодня, `demo: false` — как сейчас.
6. Правки в `parseTelegram()` должны сохранять экспорт функции: тесты её импортируют.
