# Задание 79-9 · Агент 7 — текст пустого состояния в списке работ

Повторная приёмка A9 (`reviews/round79-acceptance-2.md`, `6b287e5`) закрыла круг 79:
D4 принят, N1–N3 без регрессий, попытка публикации с кадром в одной зоне по-прежнему
блокируется. Осталось одно замечание по твоей зоне — текстовое, на одну строку.

**Ветка-источник:** `origin/preview/github-pages` = **`818d933`**.

## Что не так

`site/public/manage/app.js`, в `renderList()`:

```
'<div class="empty full">Работ пока нет. Нажмите «Новая работа».</div>'
```

Кнопка в панели называется **«＋ Новая работа»** — со знаком «＋». В тексте пустого
состояния он потерян, и получается «Нажмите «Новая работа»» вместо названия кнопки.

**Что сделать:** привести текст к одному виду с кнопкой и с остальными подсказками:
«Работ пока нет. Нажмите **«＋ Новая работа»**.»

Если у тебя в соседних сообщениях есть такие же расхождения с названием кнопки —
поправь заодно и перечисли в отчёте. Больше ничего не менять: остальные подписи приняты
приёмкой, код и поведение N1–N3 не трогать.

## Проверки

```bash

```
