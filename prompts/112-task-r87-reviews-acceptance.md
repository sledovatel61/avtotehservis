## Что проверять

### 1. Данные (Агент 10)

- `site/content/reviews.json` соответствует схеме из `prompts/113`.
- Битый файл, отсутствие файла, `rating: 9`, дубль `id` → сайт не падает; в отчёте — что именно отброшено.
- `hidden` не виден на сайте; `demo: true` виден только с `PUBLIC_DEMO_REVIEWS=1` и всегда с чипом «пример».
- `check-reviews.mjs` без флага → код 0 и сводка; `--strict` при демо → код 1.

### 2. Страница `/otzyvy` (Агент 5)

- 1440 / 768 / 390: сетка не ломается, нет горизонтального скролла, звёзды и чипы читаемы.
- Фраза «Читайте отзывы на Яндекс.Картах — там же оценки и схема проезда.» **дословно** на месте (главная и пустое состояние) — сверить с `origin/preview/github-pages`.
- Ссылка на страницу есть в подвале; `/otzyvy` попал в `sitemap.xml` и в `pages-dist`.
- Клавиатура: форма проходится Tab, звёзды — стрелками, ошибки объявляются `aria-live`.
- Контраст чипа «пример», подписей и звёзд ≥ 4.5:1 (замерить, не на глаз).

### 3. Форма (Агент 5)

- Пустая отправка → ошибки у всех обязательных полей, фокус на первом.
- 19 знаков → ошибка; 20 → уходит.
- Оценка не выбрана → ошибка (по умолчанию не 5).
- Без согласия → ошибка.
- Успех → «ушёл на проверку», поля очищены; повторная отправка того же текста в течение 10 минут — описать фактическое поведение (429 или тихий дубль-фильтр).
- Ссылка в тексте → отказ с понятным текстом.
- Honeypot заполнен через devtools → 201, но в Telegram **ничего** не пришло (подтвердить `wrangler tail` или логом).
- Демо-сборка без адреса прослойки → плашка «Отправка отзывов сейчас недоступна», запроса нет.

### 4. Прослойка (Агент 11)

- `POST /reviews` по контракту: коды 201 / 400 / 403 / 413 / 429.
- Уведомление реально приходит в группу Telegram — скрин в отчёт.
- Письмо на `Pavel.yakovenko@mail.ru`: если ключ уже стоит — подтвердить; если `/health` показывает `email:null` — отметить «не проверено, почта ещё не подключена», это **не дефект**.
- `/health` содержит `reviews:true` и **не потерял** `telegram`, `email`, `consentVersion`.
- Чужой `Origin` → 403; CORS-заголовок не стал `*`.
- В логах нет текста отзыва и имени.

## Формат отчёта `promts/r87-acceptance.md`

1. Итог: **принимаю / не принимаю** + одна строка почему.
2. Таблица проверок: пункт → результат → чем подтверждено (скрин/лог/команда).
3. Блокирующие дефекты: файл:строка, воспроизведение, ожидаемое/фактическое, **кому из агентов** (5 / 7 / 10 / 11).
4. Некритичные замечания.
5. Цифры тестов и гейтов до/после.
6. Раздел **«Что должен сделать владелец перед запуском»**: заменить демо-отзывы настоящими, прогнать `check-reviews.mjs --strict`, добавить домен в `ALLOWED_ORIGINS`.

## Чего НЕ делать

- Не мержить самому, не править прод-код «заодно», не ослаблять гейты и тесты.
- Не удалять демо-отзывы из файла — это решает владелец через админку.
- Не трогать `docs/email-setup.md` и `docs/domain-migration.md`.
