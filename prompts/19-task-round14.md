## 3. Задание

### 3.1 Главное: пересобрать кадр первого слайда под фулл-блид

Сейчас кадр симметричный: BMW стоит в левых 18–50 % кадра. Текст (46 % слева) ляжет **прямо
на BMW и NGN-стойку** — см. `evaluation/assets/r13/hero-r13-zone.jpg`, красная рамка это зона текста.

Нужна композиция наоборот:

| Зона | Что должно быть |
|---|---|
| `x` 0–45 % | **Пусто:** мокрый асфальт в глубокой тени, зелёные неоновые отблески, ни машин, ни букв вывески, ни забора, ни столбов |
| `x` 45–55 % | Переход: край фасада, дальняя машина может начинаться не раньше 50 % |
| `x` 50–100 % | Вся сцена: фасад, вывеска «АвтоТехСервис» с тремя телефонами, NGN-стойка, BMW G30 M-пакет и Camry XV70 нос к носу |

Требования к кадру (каждое проверяется глазами по кропу 1:1, не «на глазок по превью»):

1. Основа — **оригинал заказчика** `docs/photos-source/r13-clean/master-clean.jpg` (3840×2142,
   уже без Citroën C4) и принятый кадр `docs/photos-source/r13-clean/gen-hero-c.jpg` 1376×768.
   Никаких вырезанных и вклеенных машин — только цельная сцена.
2. Вывеска читается: «АвтоТехСервис», ниже три номера **+7(951) 826-98-39 · +7(951) 826-58-47 ·
   +7(863) 229-19-50**; логотипы NGN / BARDAHL / KORSON / PROMATIX / LYNX / SU:FIX / ICHIRO на месте.
3. NGN-стойка между воротами читается, текст «АВТОСЕРВИС ЗАМЕНА МАСЛА ШИНОМОНТАЖ» не размыт.
4. Габариты и ближний свет у обеих машин горят, номера пустые (без реальных номеров).
5. Зелёная неоновая подсветка в цвет темы: отблески на асфальте, на стене справа, свечение
   вывески. Не «кислотный фильтр», а свет.
6. Вечер, мокрый асфальт, отражения. Без людей, без мусора, без калитки/забора в кадре.
7. Пропорция ровно **16:9**, исходник не меньше 2560 px по ширине.

Нарезка и мобильный кроп: `resize(960,1200,fit:cover)` из того же мастера — машины и вывеска
обязаны попасть в 4:5, а не один асфальт.

в проёмы. Лимиты: webp ≤ 160 КБ, avif ≤ 80 КБ.

### 3.5 Мобильный 390×844

## 4. Чего делать нельзя

- Резать оригинал на куски и склеивать «полосу» из фрагментов.
- Вставлять вырезанные машины в проёмы ворот (получаются наклейки — уже было).
- Класть текст на машину: если после сборки зона `x < 45 %` не пустая — кадр не принят.
- Заливать небо градиентом на весь кадр (`xc:black` на весь холст заливает фото).
- Отдавать webp с артефактами «мыла» на вывеске: телефоны должны читаться в 1600 px.
