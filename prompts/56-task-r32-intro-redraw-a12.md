## 3. Что перерисовать — по пунктам

### 3.1 Полоса ДХО: не прямая, а кривая с коленом

Сейчас в коде прямая: `float sy = 450.0 - (mx - 51.0) * 0.0625;` плюс дрожь
`wob = (vnoise(...) - 0.5) * 30.0`. Отсюда и «кривые линии»: прямая не совпадает
с эталоном, а шум добавляет изломов.

Эталон снят по точкам (`reference-samples.md`, §1). Левая половина, в % от кадра:

```
t = clamp((x%W − 21,88) / 13,12, 0, 1)
y%H = 41,45 − 2,89 · (1 − smoothstep(0, 1, t))        // 0 — у внешнего конца
```

Проверка по таблице: x = 28,13 %W → 40,0 %H (эталон 39,95); x = 39,06 → 41,44 (эталон 41,44).
Правая половина — зеркально. В пикселях полотна 1920×1080 то же самое:
`y = 447,7 − 31,2 · (1 − smoothstep(0, 1, (x − 420) / 252))`.

Требования к штриху:

- **никакого `vnoise` в смещении по x.** Гладкость задаётся формулой; микротекстуру,
  если она нужна, добавляй амплитудой ≤ 0,4 px и только у внешних 8 %W;
- толщина: плато **5–6 px** при 1920 в середине плеча, **9–12 px** у внешнего конца (клин,
  как на фото) — сейчас плато 4,8 px и одинаковое по всей длине;
- спад кромки вверх — **4 px** от 255 до фона (сейчас 1 px: верхний край обрывается);
- ореол: на 0,9–1,3 %H от центра полосы фон должен быть **10–30 L** (сейчас 1,9 L).
  Это отдельный мягкий слой, не размытие самой полосы;
- **убрать «бровь»** (`browX`/`browY`, uT 0,22–0,34). В эталоне над полосой максимум
  42–48 L — это отблеск кузова, а не второй штрих. У нас там 204–235 L: висящая
  в воздухе линия. Именно она сильнее всего читается как «нарисовано от руки»;
- разрыв по центру 5,8 %W (47,3…53,1) — он у нас верный, не трогай;
- концы полосы не должны обрываться вертикальным срезом: у эталона на конце скругление
  радиусом ≈ половины толщины.

### 3.2 Знак

Форма у нас правильная (тот же SVG `public/img/vy-mark-light.svg`), неправильно исполнение:

- размер: **3,96 %W × 8,70 %H** (76×84 px при 1920), пропорция h/w **1,237**.
  Сейчас 3,25 %W при той же высоте — знак вытянут и узок;
- заливка в bbox **30 %**, у нас 40 %: штрихи слиплись, потому что ядро складывается
  аддитивно (`light += WHITE * a * … * 1.55`) и клиппируется до белого пятна. Ядро
  должно собираться через `max()`, ядро = 1,0 на плато и не выше; свечение — отдельным
  слоем с весом ≤ 0,35;
- ореол вокруг знака — да, у эталона он есть (75 px), но он не должен съедать форму:
  штрихи «крылья» и центральное лезвие обязаны читаться раздельно при 100 % масштабе.

### 3.3 Кромка кузова: красная, ровная, без белого ядра

Эталон: R **105–135**, G **12–17**, B **3–5** (G/R ≈ 0,13), мягкая полоса шириной ~13 px,
одинаковая по всему контуру — от макушки крыши вниз по стойкам и крыльям.

У нас: у крыши и стоек R 226–244 при G/R 0,50 (бело-розовая горячая обводка),
а ниже, у дверей, R 74–95 — наоборот тускло. То есть контур обведён неравномерно
и белым — это второй по силе признак «рисунка».

Сделать: цвет кромки — чистый красный из палитры (`#791003` / `#740F03`), яркость
постоянная (R 105–135), ширина спада ~4 px, ореол 10–13 px. Белого ядра нет совсем.

### 3.4 Кузов: объём, а не плоская заливка

Нижняя часть кузова у эталона действительно почти чёрная (1–3 L) — это верно и у нас,
не трогай. Объём даёт **верх**: капот и плечи ловят свет.

- отблеск: max **35 L**, p90 **14 L** в полосе 33–37 %H внутри силуэта (у нас 14/12);
- отблеск не сплошной: у эталона светлее зона капота и верхняя кромка плеча,
  тёмная — середина двери и всё ниже подоконника;
- мягкий градиент, без видимых границ: переход не круче 25 L на 10 px.

### 3.5 Крыша: купол, а не коробка

Главная причина «непропорциональности». Замер: ширина силуэта на 2 %H ниже макушки —
эталон **33,5 %W**, у нас **66,6 %W**. То есть у нас плоская крыша с двумя углами,
у эталона — дуга, которая набирает ширину постепенно.

По таблице §2 (`reference-samples.md`) верх: x 32 %W → 12,4 %H, x 36 → 10,2,
x 40 → 9,7, x 45 → 9,4, x 50 → 9,4, x 55 → 9,4, x 60 → 9,7, x 64 → 10,1, x 68 → 12,6.
Никаких ступенек больше 1,5 %H между соседними 2 %W: у нас на x 32→36 прыжок 4,8 %H.

Требования: радиус скругления угла крыши ≥ 3 %W; переход крыша→стойка плавный
(у эталона это 9,4 → 12,4 %H на 4 %W); лобовое и заднее стекло читаются наклоном
верхней кромки, а не отдельным штрихом.

### 3.6 Зеркало: округлый камень, не треугольник на палочке

Разрез `mirror-ours.jpg` — там буквально дерево на ножке: чёрный треугольник
со стеблем. У эталона (`mirror-ref.jpg`) зеркало — округлый камень с тонкой светлой
кромкой по нижней губе, а ножка скрыта за стойкой.

- верх 18,6 %H (у нас 20,8), низ 38,2 %H (у нас 37,2);
- форма: овал со срезом, отношение сторон ~1,25:1, нижняя губа чуть выступает;
- свет: тонкая кромка по нижней губе (R 150–200, G/R ≤ 0,25), не по всему периметру;
- ножки-стебля не видно: она уходит за стойку.
