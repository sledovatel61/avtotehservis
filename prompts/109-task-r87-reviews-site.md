## B. Форма отзыва

Поля:

- **Имя** (2–40 знаков, обязательно), подсказка «Как к вам обращаться. Достаточно имени и первой буквы фамилии — «Павел И.»».
- **Оценка** — 5 звёзд-радиокнопок, обязательно, **по умолчанию пусто** (не 5 — иначе это накрутка).
- **Отзыв** (20–1500 знаков), счётчик знаков.
- **Согласие на обработку персональных данных** — чекбокс со ссылкой на `/consent`, версия из настроек (`getSettings().consent_version`), как в форме заявки (`site/src/client/wizard.ts`) — переиспользуй подход, не копируй код.
- Скрытое поле-ловушка `honeypot` (визуально скрыто, `tabindex="-1"`, `autocomplete="off"`).

Отправка:

```json
{ "author": "…", "text": "…", "rating": 5, "consent": true,
  "consentVersion": "2026-11-20", "honeypot": "", "page": "/otzyvy" }
```

Ответы: `201 {"ok":true,"status":"pending"}` — успех; `400` — показать, что именно не так; `429` — «Слишком часто. Попробуйте через несколько минут»; `503` — «Не удалось отправить, попробуйте позже или позвоните».

Требования:

- Адрес прослойки — из существующего механизма (`site/src/shared/leads-endpoint.ts`), **не хардкодить**.
- В демо-сборке без адреса (`npm run build` без `PUBLIC_LEADS_ENDPOINT`) форма показывает плашку «Отправка отзывов сейчас недоступна» и не отправляет.
- Состояния: отправка (кнопка занята, повторный клик не дублирует) → успех («Спасибо! Отзыв ушёл на проверку — опубликуем в течение дня») → ошибка без потери введённого.
- Доступность: `label` у всех полей, `aria-live` для статуса, фокус на первое поле с ошибкой, звёзды работают с клавиатуры (стрелки), `aria-checked`.
- CSP: убедись, что `connect-src` в `site/src/middleware.ts` разрешает адрес прослойки (как у формы заявки), экспорт на Pages это не ломает.

## D. Тесты `site/tests/reviews-page.test.ts` (jsdom, по образцу существующих)

1. Пустая отправка → ошибки у всех обязательных полей, запроса нет.
2. 19 знаков → ошибка; 20 → запрос уходит.
3. Оценка не выбрана → ошибка (не подставляется 5).
4. Без согласия → ошибка.
5. Успех → сообщение «ушёл на проверку», поля очищены, кнопка снова активна.
6. `429` → текст про «слишком часто»; `503` → текст про «попробуйте позже»; введённый текст сохраняется.
7. `honeypot` заполнен → запрос **не** уходит, но пользователь видит успех.
8. Ссылка в тексте (`http://…`) → предупреждение до отправки.
9. Демо-отзыв рендерится с чипом «пример», обычный — без чипа.
10. Фраза про Яндекс.Карты присутствует дословно в пустом состоянии.
