## 2. Форма отзыва (Агент 5)

Ключевое: ответ воркера **плоский**. Проверить на живой форме каждое сообщение:

| Ответ воркера | Что должен увидеть человек |
|---|---|
| `400 {error:'validation', fields:{text:'too_short'}}` | под полем «Текст — от 20 знаков…», фокус на поле |
| `400 {error:'link_not_allowed', fields:{text:'link_not_allowed'}}` | под текстом про ссылки |
| `400 {error:'consent_version'}` | «Документ согласия обновился. Обновите страницу…» |
| `403 {error:'origin'}` | «Отправка с этого адреса недоступна» + почта и телефон |
| `413 {error:'too_large'}` | «Отзыв слишком длинный…» |
| `503 {error:'delivery_failed'}` | «Не получилось передать отзыв…» |
| `429` без заголовка, тело `{retryAfter:120}` | «Слишком часто. Попробуйте через 120 с.» |
| `201` | благодарность, поля очищены |

Плюс: оценка без дефолта, honeypot, `aria-live`, Tab/стрелки, вложенный формат `{error:{code,fields}}` тоже не ломает показ.
