## 3. Что сделать в этом раунде

### 3.1. Довести объём до 6000–7000 знаков без пробелов — содержанием, не водой

Добавить два новых блока (места в структуре — после «Что входит»):

Плюс расширить существующее до 3–4 предложений в каждом блоке, где сейчас 2:
- «Почему Voyah Free — это не обычное ТО» (сейчас 4 предложения — добавить, чем отличается регламент по редукторам и почему тормоза на гибриде смотрят отдельно);

### 3.4. Проверки — цифрами в отчёте, а не словами «проверил»

Приложить в `## Отчёт` фактические результаты (команды можно взять отсюда):

```sh
# объём страницы и тизера без пробелов (python3)
python3 - <<'EOF'
import re
s = open('content/merged-r28/a8/voyah-free.md').read()
def block(a, b):
    return s[s.index(a):s.index(b)]
def plain(t):
    t = re.sub(r'<!--[\s\S]*?-->', '', t)
    t = re.sub(r'[#*`>|]', ' ', t)
    return re.sub(r'\s+', ' ', t).strip()
for name, t in (('тизер', block('<!-- блок: home-teaser -->', '<!-- блок: hero -->')),
                ('страница', block('<!-- блок: hero -->', '<!-- блок: seo -->'))):
    p = plain(t)
    print(name, 'без пробелов:', len(re.sub(r'\s', '', p)), '| с пробелами:', len(p))
EOF

# запрещённое
grep -niE "воя|202[1-6]|рестайл|поколен|высоковольт|батаре|электроник|зарядк|bms" content/merged-r28/a8/voyah-free.md || echo "чисто"
```
