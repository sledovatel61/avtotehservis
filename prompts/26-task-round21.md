## A1. Фона нет вообще — плоская заливка

```
section.sec.sec--deep.slider-sec  →  background-color: rgb(16, 32, 26)
                                     background-image: none
яркость левого поля на 1440      →  mean 28,2   min 28   max 28   разброс 0,0
```

Ноль разброса — это не «строгий тёмный фон», это отсутствие фактуры: секция выглядит
как залитый прямоугольник между двумя секциями с настоящими фонами («Три направления» —
`tri-bg`, «Как мы работаем» — `est-bg`). На общем ритме страницы это читается как дырка.

## A2. Верх карточки — заглушка с текстом «фото появится после съёмки»

`.svc-img` имеет `background-color: rgb(20, 40, 31)` и внутрь подставляется `svc-1.svg…svc-6.svg`
(800×600, около 800 байт каждый):

```svg
<rect width="800" height="600" fill="#14281F"/>
<g stroke="#B7C4BB" stroke-opacity=".07">…сетка 100×100…</g>
<circle cx="400" cy="278" r="150" fill="#C87F45" opacity=".08"/>
…иконка: колесо / канистра / звезда…
<text x="400" y="536" text-anchor="middle">Шиномонтаж · фото появится после съёмки</text>
```

То есть **надпись «фото появится после съёмки» нарисована внутри картинки** и видна на всех
шести карточках. Это прямой дефект: заказчик такие заглушки вычищал из «О компании» и «Трёх
направлений» ещё в кругах 18–19. Плюс тонкая сетка 100×100 поверх — это не фактура, а
технический паттерн с прошлых итераций.

# B. Работа

## B1. Фон секции — мастер, как у соседних секций

Схема ровно та же, что в `dirs`/`est-sec`:

```html
<section class="sec sec--deep slider-sec" aria-labelledby="svc-h">
  <div class="svc-bg" aria-hidden="true">
    <picture>
      <source media="(max-width:640px)" srcset="/img/svc-bg-m-960.avif" type="image/avif">
      …
      <img src="/img/svc-bg-1600.webp" alt="" width="1600" height="900" loading="lazy" decoding="async">
    </picture>
  </div>
  <div class="container">…</div>
</section>
```

- `.svc-bg { position:absolute; inset:0; z-index:0; overflow:hidden; pointer-events:none }`,
  `img { width:100%; height:100%; object-fit:cover }`;
- контент поверх: `.slider-sec > .container { position:relative; z-index:2 }`;
- затемнение — `::after` на `.svc-bg` (не `filter`, не поверх текста);
- `@media (prefers-reduced-data: reduce) { .svc-bg { display:none } }`, остаётся цвет `--deep`;
- `@media print` — фон убрать.

**Что должно быть на мастере.** Тёмная мастерская, но **не повторять** кадры, которые уже
стоят на сайте: `hero-service-1600`, `hero-tyre-1600`, `hero-tools-1600` (первый экран),
`strip-tyre|bay|gates` (полоса фото), `tri-bg-2560` и `tri-wheel|serv|diag` («Три направления»),
`about-bg-1600`, `about-service-960`, `about-c1…c4`, `about-f1…f4`, `about-btn-320` («О компании»),
`est-bg-960`, `est-p1…p4`, `est-aside` («Как мы работаем»). Нужен **свой** кадр: бокс на Портовой
вечером, инструмент на верстаке, свет из ворот — что угодно из жизни сервиса, но не пересекающееся
с перечисленным. Фото ищешь/генерируешь сам, как в кругах 18–20.

**Числа (1440, DPR 1, левое поле 8 % и зоны между карточками):**

| параметр | сейчас | требование |
|---|---|---|
| `background-image` | none | `url(...)` — мастер реально подключён |
| средняя яркость | 28,2 | **26…46** (секция остаётся тёмной) |
| разброс по секции | **0,0** | **≥ 22** |
| попарная разница левая/центр/правая треть | 0,0 | **≥ 3** |
| перепад между соседними горизонтальными полосами | — | **≤ 3** (нет шва и ступеньки) |
| «профиль по строкам» (как в круге 20) | — | монотонность без скачков > 4 на 40 px |

Не «клеёнка»: фактура должна читаться как материал (бетон, металл, свет), а не как шум.
Если мастер тянется из кадра 2048 px на 1440 — апскейл не больше ×1,5.

## B2. Верхняя зона каждой карточки — своя фактура, без текста внутри

Заменить `.svc-img > svg` на фото/фактуру:

```html
<span class="svc-img">
  <picture>
    <source …avif…>
    <img src="/img/svc-1-640.webp" srcset="/img/svc-1-640.webp 640w, /img/svc-1-960.webp 960w"
         sizes="(max-width:640px) 84vw, (max-width:1024px) 44vw, 380px"
         alt="" aria-hidden="true" width="800" height="600" loading="lazy" decoding="async">
  </picture>
</span>
```

Требования к трём видимым карточкам (шиномонтаж, ТО и масло, электрика):

| параметр | требование (1440) |
|---|---|
| средняя яркость верхней зоны | каждая в 34…96 — тёмный кадр, но не чёрный провал |
| разброс внутри зоны | **≥ 34** у каждой |
| разница средних между карточками | **≥ 6** в каждой паре (три разные фактуры, а не одна под тремя оттенками) |
| текст внутри картинки | **нет** — ни «фото появится после съёмки», ни подписей, ни водяных знаков |
| сетка-паттерн 100×100 | убрать |
| иконка | может остаться, но как акцент поверх кадра (один цвет, opacity ≤ 0,9), не вместо кадра |
| `object-fit` | `cover`, лицо/деталь не обрезается на 4:3 и на 390 |

Остальные три карточки (балансировка, двигатель, стёкла — те, что за кадром) — тоже получают
фоны по этой же схеме, просто приоритет у первых трёх: заказчик видит именно их.

Мастера класть в `docs/photos-source/r21-svc/`, производные — через `site/scripts/build-images.mjs`
(там уже есть блоки `r18`/`r19`/`r20`), размеры 640/960, форматы webp + avif.

## B3. «Подробнее» — настоящая кнопка в каждой карточке

Сейчас: строка 329×25, без рамки и фона. Нужно:

| свойство | значение |
|---|---|
| высота | **≥ 44 px** (включая padding) |
| ширина | по контенту (`inline-flex`), не на всю карточку |
| рамка | 1 px `rgba(224,169,109,.45)`, радиус `999px` |
| текст | 14–15 px, `#E0A96D`, letter-spacing .02em |
| `:hover` | заливка `#E0A96D`, текст `--deep`, контраст пары ≥ 6:1 |
| `:focus-visible` | `outline: 2px solid #E0A96D; outline-offset: 3px` — видно на тёмном |
| `:active` | `translateY(1px)`, заливка на 8 % темнее hover |
| `:visited` | не менять цвет |
| в покое | контраст текста к подложке карточки ≥ 4,5:1 |

Кнопка — `<span class="link-more">` внутри `<a class="svc-card">`. Карточка остаётся одной
ссылкой (вложенных ссылок не делать): стилизуем внутренний `span` как кнопку, кликается
вся карточка. Ховер-состояние должно срабатывать и от `:focus-visible` на самой карточке
(`.svc-card:focus-visible .link-more` — то же, что hover).

## B4. Иерархия текста

- `.svc-tag` — остаётся медным, но тише: 11 px, `letter-spacing .12em`, opacity .9;
- `h3` — **ivory `#F4EFE6`**, 19–20 px на ≥1280, 18 px ниже; контраст к подложке ≥ 9:1;
- `.svc-body p` — `--mist`, 14,5 px, не менять;
- `.link-more` — единственный акцентный элемент, см. B3.

Одна карточка = один акцент. Сейчас их три и они равны.

## B5. Стрелки карусели — вернуть в строку с заголовком

- на **≥ 1024**: `.slider-nav` на одной линии с `h2`, справа. Проверка: `|centerY(nav) − centerY(h2)| ≤ 24 px`
  и `nav.right` попадает в поле контейнера ±8 px. Заголовку разрешено сузиться до `max-width: 900px`
  (`text-wrap: balance`), чтобы освободить место;
- на **768** — допускается своя строка, но по правому краю контейнера, не под левым краем заголовка;
- на **390** — стрелки остаются, высота 44 px (сейчас 40), между ними 10 px, справа от заголовка
  не влезают — ставим под заголовком, но по правому краю и в один ряд с подписью «листайте»
  либо скрываем и оставляем свайп + `aria-live` счётчик. Выбор — твой, но управление
  каруселью с клавиатуры должно остаться.

3. **Карточки разные**: три верхние зоны — mean в 34…96, разброс ≥ 34, попарная Δ ≥ 6.
4. **Нет текста в картинках**: ни один файл `svc-*.svg` не содержит `<text>`, и в `alt`
   нет строки «фото появится».
5. **Кнопка**: высота ≥ 44, `border-radius ≥ 999px` или явное скругление, есть `:hover`
   и `:focus-visible` (проверять по вычисленным стилям и через `CSSStyleSheet` — искать правило).
6. **Стрелки**: на 1440 и 1280 `nav` в одной строке с `h2` (±24 px по центру).
7. **Иерархия**: `h3` не того же цвета, что `.svc-tag` (сравнение строк).
8. **Контраст**: `p` ≥ 4,5:1, `h3` ≥ 9:1 к реальной подложке (пиксель под текстом, а не `background-color`).

**Мутанты (`--self-test`):** не меньше **12**, каждый обязан валить гейт. Обязательные:

- фон `display:none` (фон исчез);
- фон сплошной заливкой вместо мастера;

- разброс верхней зоны 12;
- `h3` снова `#E0A96D`;
- кнопка высотой 25 px;

- `alt` «фото появится после съёмки»;
