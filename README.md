## Как запустить этап 1

1. Откройте `docs/03-prompts-for-5-agents.md`.
2. Скопируйте каждый блок «ПРОМПТ №N» отдельному агенту (5 разных агентов, разные модели/сессии — так идеи
   будут разнообразнее).
3. Попросите каждого вернуть файл `ideas/agent-N-<тема>.md` по контракту из конца промпта
   (шаблон — `ideas/_template.md`).
4. Положите файлы в репозиторий и верните мне — я оценю по рубрике, отберу топ-3, заменю двух слабых и выдам
   задание на мокапы.
