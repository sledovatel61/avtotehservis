# Раунд 1: концепции агентов

Сюда попадают работы **после импорта из веток**, а не вручную пересланные файлы.

## Как это работает

1. Агент пушит ветку `agent/NN-<слаг>` и открывает PR в `main`.
2. Заказчик присылает номер PR или ссылку на ветку.
3. Оркестратор запускает:

```bash
scripts/import-agent.sh --branch agent/01-brand-concept
```

4. Скрипт читает только `agents/agent-NN/`, проверяет типы и размеры файлов, отсутствие секретов и внешнего JS, затем копирует сюда: `agents-output/round1/agent-NN/`.

## Что должно быть в работе

- `concept.md` — 12 разделов по универсальному промпту.
- Достаточно 12–20 КБ; больше — не значит лучше.
- Никаких секретов, бинарников, скриншотов и `node_modules`.

## Чего здесь быть не должно

- готовых мокапов (они попадут в `mockups/`);
- кода проекта (он появится только после выбора мокапа);
- файлов от оркестратора — я не пишу концепции за агентов.

## Имена папок

Совпадают с номером агента: `agent-01` … `agent-05` (после замен — те же номера, новые участники).
