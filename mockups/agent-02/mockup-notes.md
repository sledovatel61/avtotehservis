# Агент 02 · Раунд 2Б — заметки к многостраничному мокапу

**Папка:** `mockups/agent-02/`. Это статический демо-макет: восемь обязательных страниц, опциональная открытая `admin.html`, общие CSS/JS и локальные SVG/шрифты. Страницы открываются напрямую с диска; сборка и сервер не требуются. Заявки и публикации не отправляются в сеть.

## 2. Решения, палитра и шрифты

1. Визуальный язык A2: бумага, чернильный синий, коралл; номера, тонкие линии и авторские схемы вместо заимствованных фото.
2. Основные сведения взяты только из `docs/01-company-research.md` и `prompts/00-context-pack.md`. График ежедневно 09:00–19:00 помечен как подтверждённый владельцем 21.10.2026. Цены, срок гарантии, достижения и личные данные клиентов не добавлены.
3. Отзывы, новости, галерея, заявка и админка отмечены как демо. Политика и согласие — заглушки, не юридический документ.
4. Навигация и карточки ведут на реальные относительные HTML-файлы; на внутренних страницах один хлебный маршрут и активный раздел.
5. Все медиа самодельные SVG/локальный предпросмотр; схема проезда условная, не масштабная.
6. Внешние ссылки (карты, `tel:`, `mailto:`) открываются только по нажатию; шрифты и ресурсы локальные.
7. `admin.html` не защищена авторизацией и не пригодна для реальных заявок. Это демонстрация состояния редакторской панели.

Проверены также контуры фокуса и состояния. Axe-core 4.11: 0 нарушений WCAG 2.2 A/AA на всех девяти страницах и ширинах 320, 390, 768, 1024 и 1440 px. Пара `#F9E6E1` на коралле (4.06:1) была отклонена; текст там заменён белым.

**Типографика:** Onest Variable для заголовков + Golos Text 400/500 для текста. Кириллица/латиница разнесены в локальные WOFF2 subsets; файлы загружаются CSS по unicode-range, в Chromium проверена загрузка кириллического текста. Onest — 88.6 КБ, Golos Text — 62.6 КБ; лицензии OFL-1.1 приложены рядом с файлами. Production fallback: системные `Arial, sans-serif`; при замене сабсетов — официальные полноязычные файлы Onest/Golos с сохранением OFL. Google Fonts/CDN отсутствуют. Preload не оставлен: для прямого открытия `file://` режим credentials у preload не совпадал с CSS-запросом шрифта.

## 3. Движение и форма

| Эффект                       | Триггер / длительность                                          | Доп. вес                     | `prefers-reduced-motion`                          |
| ---------------------------- | --------------------------------------------------------------- | ---------------------------- | ------------------------------------------------- |
| Герой: fade + сдвиг          | смена слайда, 450 мс; автошаг 8 с, пауза на hover/focus         | 0 КБ библиотек; общий CSS/JS | автопрокрутка выключена, переход почти мгновенный |
| Появление секций             | вход в viewport, 220 мс                                         | без отдельной библиотеки     | отключено, контент сразу виден                    |
| Карусели услуг/работ/отзывов | стрелка или горизонтальный свайп, 250–280 мс                    | общий CSS/JS                 | без заметного движения                            |
| Карточки и CTA               | hover/focus, translate 160–200 мс                               | общий CSS                    | переход почти мгновенный                          |
| Шаг формы + прогресс         | Далее/Назад: 220 мс; `scaleX`: 250 мс                           | общий CSS/JS                 | остаётся только смена состояния                   |
| Лайтбокс                     | открытие/закрытие, fade/scale 180 мс                            | общий CSS/JS                 | переход почти мгновенный                          |
| Мобильное меню               | открытие/закрытие, opacity/translate 180 мс                     | общий CSS                    | переход отключён; фокус сразу на кнопке закрытия  |
| Нижний CTA                   | прокрутка страницы, opacity/translate 180 мс                    | общий CSS/JS                 | без движения                                      |
| Строка марок                 | один CSS-проход 34 с (42 с на узких экранах), пауза hover/focus | только CSS                   | отключена                                         |

Все движения — transform/opacity; нет анимации размеров, параллакса, scroll-jacking, видео и внешних библиотек. Отдельный вес эффектов не выделяется: всё уже входит в локальные `style.css`/`app.js`.

**Запись.** Payload-просмотр включает E.164-телефон `+7…`, `contact_method`, поля автомобиля, массив slug-услуг, дату ISO/слот или `asap`, число фото, согласие, `page` и UUID v4 `idempotency_key`. Черновик — `localStorage` с безопасным fallback; вложения можно удалить; фото остаются в браузере. Демозадержка 820 мс показывает ошибку без потери введённых полей и успех с номером `DEMO-…`; одинаковый ключ сохраняется при повторе. Запросов `fetch`, XHR и `sendBeacon` нет.

**Будущий серверный контракт (не реализован):** `POST /api/leads` → `201 {"ticket":"…","status":"accepted"}`. Сервер валидирует данные и согласие, сохраняет заявку в БД и transactional outbox; worker отправляет Telegram `sendMessage` владельцу и письмо на `avtotehservis439@mail.ru`, ретраит доставку и обновляет статус админки. Если Telegram недоступен — остаётся email; если упали оба канала — заявка остаётся в БД/outbox, клиент видит принятый номер. Bot token, `chat_id` и SMTP-секреты — только в env; никогда не в клиентском мокапе.
