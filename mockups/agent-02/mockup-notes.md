# Agent 02 · Этап 2 — заметки к мокапу

**Файл:** `mockups/agent-02/mockup.html` · один автономный HTML-файл, CSS и JS встроены. Открывается локально; сборка и сервер для самого макета не нужны. Файл — прототип интерфейса, не продакшн и не подключён к сервису заявок.

## Решения

1. **Светлая палитра с охрой.** Тёплая бумажная поверхность, графит и жёлтый маркер продолжают концепцию «приёмной-поста»; один основной текст CTA — «Оставить заявку». Альтернативная формулировка для будущей проверки: «Опишите задачу»; в самом макете она не используется.
2. **Первый экран отвечает на «куда нажать».** Четыре входа: колёса, ремонт, «не знаю» и отдельный B2B-переход. Телефон остаётся самостоятельным действием, заявка — добровольной.
3. **Иллюстрация вместо фальш-фото.** Колесо, схема карты и шесть SVG-карточек нарисованы inline. Все кейсы помечены демо; на галерее есть интерактивное пустое состояние.
4. **Квиз из семи экранов.** Есть выбор направления, список из 20 марок и свободный ввод, модель/год, VIN, неисправности, контакт, сводка и отдельное согласие. «Не знаю VIN» и пропуск года сохраняют остальные ответы. Макет имитирует отправку 850 мс, но ничего не отправляет и не хранит.
5. **Ошибки и доступность.** Ошибки видны текстом рядом с полем, ошибки VIN и телефона появляются при проверке/уходе из поля, согласие блокирует отправку. Меню и лайтбокс закрываются по Esc; лайтбокс поддерживает кнопки, стрелки и свайп. FAQ раскрывается по нажатию.
6. **Контакты без встроенной карты.** Схема нарисована в SVG; маршрут, телефон, почта и Telegram открываются только по пользовательскому нажатию. Telegram-ссылка — заглушка до проверки аккаунта.
7. **Демо-панель админа.** Открывается из футера, показывает пример списка заявок и локальную форму публикации изображения. Файл виден только через object URL в текущей вкладке; нет загрузки на сервер, БД или сохранения после перезагрузки.
8. **Анимация.** Появление секций и карточек при прокрутке — `IntersectionObserver`; переход шага квиза, sticky-панель, меню/модалка, hover-кнопка — короткие `opacity`/`transform`. `prefers-reduced-motion` выключает движение/плавную прокрутку. При ограничении бюджета первыми можно удалить reveal и hover.

**Что не проверял:** визуальное отображение в браузерах и фактический overflow на перечисленных ширинах, скринридер, реальный файл с телефона/HEIC/MOV, доступность внешних контактов, юридическую корректность текста документов. JSDOM проверяет DOM и обработчики, но не рендерит layout. Перед оценкой макета откройте файл в браузере на 320/390/768/1440 px и проверьте сценарии клавиатурой и с экранным увеличением.
