# Временные медиа для мокапов

Эти изображения **сгенерированы AI** и используются только как плейсхолдеры для мокапов и прототипов.
Они **не являются** фотографиями работ АвтоТехСервис и не должны публиковаться как реальные кейсы.

| Файл | Назначение |
|---|---|
| `hero.jpg` | первый экран: подъёмник, механик, вечерний цех |
| `work-suspension.jpg` | кейс «подвеска / ходовая» |
| `work-engine.jpg` | кейс «двигатель / ДВС» |
| `work-wheel.jpg` | кейс «шины и диски» |

## Что нужно от клиента для продакшна

1. 10–20 горизонтальных и вертикальных фото: цех, подъёмники, оборудование, команда за работой.
2. 3–5 вертикальных видео 15–30 с: разборка агрегата, стенд развала, правка диска, финальная проверка.
3. Фото «до/после» по 5–8 самым частым услугам.
4. Логотип (если есть) в SVG/PNG с прозрачным фоном; фото вывески и въезда (для блока «как добраться»).
5. Письменное согласие клиентов на публикацию фото их авто и отзывов.

Требования к файлам: JPG/PNG ≥ 2000 px по длинной стороне, видео MP4/H.264 или MOV (пережмём), без «рыбьего глаза»,
без чужих логотипов и номеров (номера закрываем на постобработке).
