# Mockup-notes — Агент 04 (Технологии и стоимость владения)

**Идея (100 слов).** Мокап — это «диспетчерская на Портовой» в светлой теме: за первую прокрутку на 390×844 понятно что это автосервис и шиномонтаж на Портовой, 439, как доехать от остановки «3-й Поселковый» 330 м (индекс 344033, координаты 47.193068, 39.648295), когда открыто («ежедневно до 20:00 — уточните по телефону» без выдуманных часов) и куда жать. Развилка «Колесо / Ремонт / Не знаю» ведёт в квиз 6 шагов (марка → модель/год → VIN → что случилось → фото → контакты). Акцент Агент-4 вынесен в hero и блок доверия: стек Astro 7.4.1 SSG + SQLite на VPS РФ, TCO 3 года ~15 тыс ₽ без разработки, 0 КБ JS по умолчанию, карта по клику (экономим ~200 КБ). Тон — как приёмщик: «смета до начала, старт после вашего да, без VIN — тоже ок». Все цены — только «от 800 ₽ за R14» из каталогов [уточнить], отзывы — честно 4,5/182 [не проверено] + 3,6/12 + 2,2/1, без фейковых гарантий.

**Что получилось сильнее всего (120 слов).** 1) Квиз — полностью рабочий без внешних библиотек (≤40 КБ gzip): ветвление wheel/repair/unknown, поиск марки из топ-15, модель/год с «не помню», VIN 17 символов без I,O,Q с маской, кнопкой «Не знаю VIN» и подсказкой «Где найти на СТС», выбор услуг чекбоксами (динамика по ветке + «Не знаю — диагностика»), фото 1–3 с удалением и HEIC-упоминанием, телефон с маской +7 (___) ___-__-__, имя, 2 чекбокса 152-ФЗ (на ПД — обязателен, на рекламу — нет, оба пустые по умолчанию), прогресс-бар, валидация inline, idempotency-key, офлайн-очередь в localStorage и экран успеха #ATS-4821 с ретраями. 2) Галерея — фильтры «Все/Колеса/Ходовая/ДВС/Стекла», «Показать ещё», лайтбокс с Esc, стрелками, свайпом, фокус-ловушкой и клавиатурой. 3) Видео — постер → модалка, без автоплея, `<video controls playsinline preload="none">` и подпись «звук только по тапу». 4) Mobile-first: 320 без горизонтального скролла, тапы ≥44 px, поля 16 px (iOS не зумит), sticky-бар с `env(safe-area-inset-bottom)`, `prefers-reduced-motion` вырубает все transform/opacity, вес 95 КБ (24 КБ gzip) — в лимите.

**Компромиссы.** Вместо селф-хостед шрифтов — один Google Fonts (Manrope 700/800 + Inter 400/600/700) + системный fallback `system-ui`, чтобы открываться двойным кликом без сборки. Карта не грузится сразу — кнопка «Показать карту» подгружает iframe Яндекса по клику, остальное — внешние ссылки на Яндекс/2ГИС/Google без трекеров до согласия. Фото — inline SVG-заглушки «До/После — пример оформления», не сток чужого бокса (чтобы не обманывать). Админку не встраивал в один файл — показал TCO-бейджем (330 ₽ VPS, 199 ₽ домен) и описал 4 экрана в концепции (публикация 60 сек), иначе файл превысил бы 400 КБ и потерял бы perf.

**Что не успел и что улучшить.** Не сделал URL `?filter=wheel&page=2` для SEO галереи и пагинацию с `noindex` для пустых фильтров, не подключил Turnstile (только honeypot + rate-limit + проверка времени заполнения ≥3с в коде), нет `aria-live="polite"` на каждый шаг квиза и микроразметки `AggregateRating` только по подтверждённым ссылкам (сейчас честный текст + ссылка). Видео — без реального `src` (нужен WebP-постер 800×450 ~30 КБ и MP4 720p). Дальше — добавить 2 реальных кейса с согласия, JSON-LD `AutoRepair` с `alternateName: Портовая`, sitemap.xml и тест на 4G LCP <2,2с, оставаясь в лимите ≤400 КБ.
