# Voyah Free — мокап раздела и два прототипа входа (круг 28, задание №38, агент 6)

Что открывать двойным кликом, всё локально, без сборки и без внешних запросов:

| Файл | Что это |
|---|---|
| `index.html` | страница `/voyah-free`: первый экран, «почему не обычное ТО», «что входит» (5 групп), прайс (15 строк), «как проходит визит», FAQ (6), финальный CTA. Шапка с **семью** пунктами, в неё добавлен «Voyah Free» |
| `home-section.html` | секция-тизер для главной **между «О компании» и «Как мы работаем»**: сверху фрагмент тёмной секции, снизу — айвори, между ними пунктирные «линейки стыка» (только в мокапе) |
| `intro-a.html` | прототип входа, вариант A «Световая линия» |
| `intro-b.html` | прототип входа, вариант B «Сборка силуэта из световых полос» |
| `shots/` | скриншоты (см. ниже) |
| `src/` | исходники страниц без инлайн-CSS — для правок; `node build.cjs` пересобирает четыре итоговых файла |

`build.cjs`, `measure.cjs`, `shot.cjs`, `verify.cjs` — служебные скрипты стенда (puppeteer-core + Chromium 131).
Их наличие в папке не мешает: сами мокапы — это четыре HTML + `img/` + `fonts/`.

## 4. Анимация

### Вариант A — «Световая линия» (2,4 с)

| Время | Что происходит | Свойство |
|---|---|---|
| 0,00–0,06 | чёрный экран, тонкая линия 2 px по центру | `opacity` |
| 0,06–0,44 | линия «включается» и растягивается с 36 до 300 px | `width` + `opacity` |
| 0,30–0,72 | от линии расходятся две «фары» — короткие светящиеся полосы влево-вниз и вправо-вверх | `transform: scaleX/translateY` |
| 0,64–1,16 | SVG проявляется (фейд + масштаб 0,98 → 1) | `opacity`, `transform` |
| 0,68–1,99 | силуэт собирается: земля, контур кузова с арками, обе шины, световая полоса фар, 5 ламелей решётки, вставка бампера, подоконная линия, стойки, двери, ступицы — 11 шагов по 52 мс, каждый 760 мс; последний стартует в 1,23 с | `stroke-dashoffset` |
| 1,46–1,84 | линия и фары гаснут, остаётся силуэт | `opacity` |
| 1,70–2,12 | вспышка по линии | `opacity`, `transform: scaleY` |
| 1,96–2,39 | две шторы разъезжаются влево/вправо | `transform: translateX` |
| 2,40 | оверлей удаляется из DOM, скролл разблокирован | — |

### Вариант B — «Сборка силуэта из световых полос» (2,4 с)

| Время | Что происходит | Свойство |
|---|---|---|
| 0,03–1,08 | восемь коротких полос света влетают с боков (поочерёдно слева/справа, старт 30…380 мс, каждая летит 520 мс), две из них зелёные — «отражение кузова» | `transform: translate/rotate/scaleX`, `opacity` |
| 0,45–1,03 | полосы встают по линиям кузова: крыша, верх остекления, подоконная линия, порог, низ кузова, отражения на полу | `transform` |
| 1,08–1,55 | полосы гаснут по очереди, «растворяясь» в контуре | `opacity` |
| 0,66–1,74 | силуэт собирается по `stroke-dashoffset` (те же 11 шагов, шаг 34 мс, каждый 620 мс) | `stroke-dashoffset` |
| 1,18–1,88 | по линии земли проходит световое пятно (градиент + `mask-image`, без `filter`) | `transform`, `opacity` |
| 1,98–2,40 | створки расходятся через `clip-path: inset()` | `clip-path` |

**Чем A лучше/хуже B.** A за 2,4 с успевает рассказать историю «включили свет → увидели машину», и её ключевой кадр (1,2–1,6 с) — это уже узнаваемый силуэт: если человек сорвётся на 1,5 с, он всё равно понял, про что страница. B кинематографичнее в первые 0,6 с (движение с двух сторон читается как «сборка»), но её пик — 0,9–1,4 с, а «полосы + силуэт» вместе выглядят шумнее; на слабом ноутбуке восемь одновременных `transform`-слоёв с `box-shadow` дают заметно больше работы композитору, чем два слоя у A. Пауза 1,5 с у A — «дыхание» перед вспышкой, у B пауз меньше, сцена плотнее.

**Рекомендация — вариант A.** Он дешевле по слоям, лучше читается в середине сцены и его финальный кадр (силуэт + вспышка) прямо переходит в первый экран, где та же световая линия оставлена статикой над H1.

**Что упадёт на слабом железе.** `stroke-dashoffset` на 12 сегментах — это перерисовка SVG каждый кадр, на бюджетных Android и на старых Intel GPU возможны просадки до 30–40 fps в момент 0,6–1,4 с. В мокапе нет `filter: blur()` на полноэкранных слоях: подсветка сделана `drop-shadow` у двух коротких элементов A и `box-shadow: 0 0 14px` у 3-пиксельных полос B, `blur(1px)` стоит только на дублирующем контуре силуэта (тонкая SVG-обводка). Canvas не используется. Оверлей вне потока — layout shift нулевой, LCP-элемент (H1) не перекрывается.

**Как ведёт себя при отказах:** `prefers-reduced-motion: reduce` и `navigator.connection.saveData` — сцена не создаётся вовсе; без JS оверлея нет (он собирается скриптом), контент виден сразу; клик, `Esc`, колесо и `touchmove` прерывают сцену за 180 мс; повторно в той же сессии интро не показывается (`sessionStorage`, ключи `voyah-intro-a` / `voyah-intro-b`), кнопка «Смотреть снова» сбрасывает ключ.

Замеры (Chromium 131, 09.11.2026, `node verify.cjs` → `verify-report.json`):


## 5. Как это переносить в Astro

1. **Страница** — `site/src/pages/voyah-free.astro` + `site/src/styles/voyah.css`. Все классы уже с префиксом `v-`
   (`v-hero`, `v-why`, `v-incl`, `v-tbl`, `v-steps`, `v-faq`, `v-cta`), конфликтов с `.sec`, `.tri`, `.est-` не будет.
2. **Что остаётся SVG:** силуэт в интро (10 `<path>` + 4 `<circle>`: контур с арками, шины, ступицы, решётка, стойки, двери, земля) и четыре линейные иконки в «почему»
   (по 1 `<path>`, `stroke-width:1.7`). Логотип — существующий `/img/logo.svg`.
3. **Что остаётся CSS-анимацией:** шторы (`transform: translateX`), створки B (`clip-path: inset`), линии и фары
   (`transform`, `opacity`), `stroke-dashoffset` у сегментов силуэта.
4. **Где нужен JS:** только создание оверлея, `classList.add('is-play')` через `requestAnimationFrame`, таймер 2400 мс,
   обработчики `click/keydown/wheel/touchmove`, `sessionStorage`. Всё — один `<script>` на ~40 строк, без библиотек;
   в Astro его место — `src/client/voyah-intro.ts`, подключать как остальные клиентские модули (`lightbox.ts`).
5. **Переменные завести в `tokens.css`:** `--v-ink:#070B12; --v-panel:#0E1622; --v-graphite:#2A3442; --v-silver:#C9D3DE;
   --v-cold:#EAF2FF; --v-green:#16402F;` — рядом с существующими `--night/--deep/--brass`, чтобы «остров» не ломал тему.
6. **Секция главной** вставляется в `index.astro` между `<section class="sec sec--narrow about">` и
   `<section class="sec sec--ivory est-sec">`, с `id="voyah"` (нужен для ссылок из футера и прайса).
7. **Шапка:** добавить `<li><a href="/voyah-free">Voyah Free</a></li>` седьмым пунктом и такие же правила сжатия,
   как в `assets/voyah.css` (на 1024–1199 телефон скрыть, на 1280–1439 убрать подпись под логотипом). Гейт
   `check-hero-layout.mjs` проверяет защищённые медиа-блоки — эти правки лежат внутри разрешённых ширины.
8. **Гейты сайта:** прайс на странице — не `.price-tbl` (чтобы не менять счётчики `check-price-tables`), а `.v-tbl`;
   FAQ — `<details class="v-faq">`, вне `.price-foot`. Если решено встроить в `/prices`, счётчики трогать придётся.

## 6. Что в мокапе — заглушка

- **Кадры.** Три изображения — **AI-визуализации**, сгенерированы по референсам владельца (`docs/content-source/r28/voyah-restyle-1…3.jpg`):
  рестайлинг узнаётся по узкой чёрной решётке с вертикальными ламелями, сквозной световой полосе, вертикальным
  вставкам в бампере и чёрной крыше. Это **иллюстрации**, а не фото сервиса; номера и шильдики не читаются, официальной
  символики марки нет. В продакшне заменяются съёмкой в боксе на Портовой, 439.
- **Тексты** — рыба по смыслу: финальные пишет агент 8 (`prompts/37-…`). Годы выпуска, транслитерация и высоковольтная
  тема не упоминаются нигде.
- **Кнопки и ссылки** ведут на `#` или на реальные адреса сайта — формы не отправляют, заявок нет.
- **Цены** — только из §3 задания (15 строк), без вилок и без «от», где цена фиксированная.
- **Чего нет специально:** официального логотипа и шрифта VOYAH, слов «официальный дилер», лет выпуска, темы батарей
  и зарядки, продажи запчастей как отдельной услуги.
