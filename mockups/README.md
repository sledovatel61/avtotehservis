## Чек-лист приёмки (проводит оркестратор)

- [ ] открывается локально, без сборки и сервера;
- [ ] нет внешних JS/CSS, шрифтов и картинок;
- [ ] вес ≤ 400 КБ;
- [ ] все 12 блоков из `prompts/01-mockup-task.md` §3;
- [ ] квиз проходится до экрана успеха, есть «не знаю VIN», согласие блокирует отправку;
- [ ] галерея: 6 карточек, лайтбокс с клавиатуры и свайпом;
- [ ] отзывы с источником, без выдуманных сумм и рейтингов;
- [ ] часы 9:00–19:00, телефоны и e-mail из контекст-пакета;
- [ ] нет горизонтального скролла на 320, 390, 768, 1440;
- [ ] `prefers-reduced-motion` отключает движение;
- [ ] нет Lorem ipsum, цен и выдуманных фактов;
- [ ] `mockup-notes.md` с заполненной таблицей самопроверки.
