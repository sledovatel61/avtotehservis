## Чек-лист приёмки (проводит оркестратор)

- [ ] открывается локально, без сборки и сервера;
- [ ] нет внешних JS-библиотек;
- [ ] вес ≤ 400 КБ;
- [ ] все 14 блоков из промпта;
- [ ] квиз проходится до экрана успеха, есть «не знаю VIN»;
- [ ] галерея фильтруется, лайтбокс листается с клавиатуры и свайпом;
- [ ] видео открывается модалкой с постером;
- [ ] нет горизонтального скролла на 320, 390, 768, 1440;
- [ ] `prefers-reduced-motion` отключает движение;
- [ ] нет Lorem ipsum и выдуманных фактов.

Результат проверки — `evaluation/round2-mockups.md`.

## Важно

Выбор делает **заказчик**. Оркестратор даёт рекомендацию, плюсы, минусы и риски, но не подменяет решение вкуса.
