## 2. Решения (с обоснованием)

1. **Акцент #C2410C вместо концептуального #E8590C**: белый на #E8590C даёт 3,58:1 (не AA для текста кнопок), на #C2410C — 5,18:1. Палитра светлая, «честная мастерская», как в концепции §7.
2. **Порядок шагов квиза — по спецификации задания §4** (марка раньше симптомов), а не по концепции. Микрокопирайтинг перенесён из концепции без потерь: «Не знаю VIN» с объяснением, «заявка ни к чему не обязывает», экран успеха с нумерованными «что дальше».
3. **Загрузка без бесконечного спиннера**: одноразовая 300 мс анимация полосы загрузки (правило «без бесконечных анимаций»), имитация отправки 700–1200 мс — как требует §4.
4. **Отзывы: все три карточки честно видны** (Яндекс 4,5/182 + 2ГИС 3,6/12 + Zoon 2,2/1) с текстом «одна компания — разные карточки, сводим их»; среднее не вычисляю, `AggregateRating` не ставлю (риск санкций поисковиков при неподтверждённом числе).
5. **Цен нет вообще, даже «от»**: FAQ «Сколько стоит?» объясняет отказ от прайса (точную сумму называем после диагностики). Из текстов концепции убрано «от 800 ₽».
6. **Демо-админка сделана** (сильный плюс по §5.3): вход без пароля → 3 демо-заявки со статусами → «Добавить работу» (файл, превью, подпись, категория, «Опубликовать») → карточка сразу появляется в галерее и открывается в лайтбоксе; таймер «цель 60 секунд» с зелёной/оранжевой оценкой. Основной сценарий концепции — Telegram-бот — в однофайловом мокапе не показать, поэтому он описан текстом внутри админки.
7. **HEIC-честность**: если выбрать HEIC и браузер его не отрендерит, превью показывает сообщение «в продакшне файл сконвертируется на сервере» вместо молчаливой пустоты (caniuse: HEIC — Safari 17+, Chrome/Firefox — нет).
8. **`:has()`-фолбэк**: подсветка выбранных опций дублируется классом `.sel` через JS — работает в браузерах без `:has()`.
9. **Карта — инлайновая SVG-схема** (без iframe): Портовая, переулок, база «Бум», остановка, пунктир «~330 м пешком». В продакшне — Яндекс.Карта с меткой.
10. **Системный шрифтовой стек** (по заданию); идентичность держат цвет, геометрия, знак-шестигранник со «срезанным лучом» и крупная номерная типографика блока «Смета до ремонта».

## 3. Что в мокапе заглушка (заменяется реальными данными)

- Все 6 кейсов галереи и видео-карточка (дизайнерские плашки, «демо-кейсы, заменим реальными»; в продакшне видео: постер сразу, ролик по тапу, `preload="none"`, без автоплея со звуком, MOV→H.264 на сервере).
- Тексты 3 отзывов (демонстрационные: без сумм, сроков, фамилий; публикация — после модерации) и форма отзыва (не отправляет).

- Заявки в демо-админке (3 строки, телефоны «+7 (900) 000-00-0X»), статусы — только в сессии.
- Политика и согласие — проекты документов (финал — юрист владельца); чекбокс согласия не предустановлен (ст. 9 152-ФЗ, ред. с 01.09.2025).

`quiz_open` (кнопки входа в квиз), `step_view` (каждый показ шага), `step_next`, `step_back` (в т.ч. «изменить» в сводке), `skip_vin`, `quiz_submit_attempt`, `quiz_success`, `call_click` (все tel-ссылки), `telegram_click`, `route_click` (маршрут/ссылка карточки).
