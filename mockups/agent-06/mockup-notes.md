# АвтоТехСервис · мокап раунда 2Б (этап 3)

Дизайн-направление **A6 «плакат»**. Многостраничный статический мокап по композиции `matronet.com/demo/car-7`:
свои данные, свой визуал, свои тексты. Bootstrap, jQuery, Revolution, Owl, Fancybox и Google Fonts не используются —
только HTML, CSS и один файл нативного JS. Проверки от 21.10.2026.

## 4. Типографика

- **Дисплейный:** Unbounded 800. **Текстовый:** Onest 400 + 600. Обе — OFL 1.1, кириллица есть, вес сабсетов 6,7–21,8 КБ на файл.
- 6 файлов woff2 (cyrillic + latin на каждое начертание) вложены в `style.css` как base64: **102 КБ**, ни одного внешнего запроса. `font-display: swap`.
- Размеры: H1 `clamp(30px, 6.2vw, 58px)`, H2 `clamp(24px, 3.6vw, 38px)`, текст 16–17 px, трекинг заголовков −0,03em.
- В проде: те же две гарнитуры с CDN-хостингом на своём домене; альтернатива без лицензионных вопросов — Onest (текст) + Unbounded (дисплей) остаются, они свободные.
- Google Fonts и любые CDN не используются (в референсе был `@import` с Google Fonts).

## 5. Решения

1. **Три плоскости вместо оранжевого.** Референс строит акцент на `#ff9320`; белый на нём не проходит AA. Взял чёрный + кобальт + кислотный: контрасты выше, ритм «три пятна» сохранён.
2. **Плакатная сетка с жирной линией `--bw`.** Все карточки, поля и панели обведены 2 px чёрным, тени — жёсткие, без размытия. Это дешевле в трафике, чем фотосток, и сразу читается как «сервис», а не «шаблон».
3. **Заглушки вместо фотографий.** Плакатные SVG (шина, диск, тормоз, двигатель, свеча, кондиционер, маршрут) генерируются в `style.css`/HTML инлайном, `aria-hidden`. Ни одного стокового фото и внешнего файла.
4. **Мастер вместо длинной формы.** 5 экранов с прогрессом «шаг N из 5» и неактивной «Далее»: у референса была одна портянка с `required` и слайдером года.
5. **Год — числовое поле + «не помню».** Слайдер 1987–2025 из референса не даёт ввести 2026 и не работает с клавиатуры.
6. **Слоты показывают занятость.** «Занято» видно, но недоступно — как в реальном расписании; данные демонстрационные.
7. **«Талон заезда» как экран успеха.** Вместо «Спасибо, мы свяжемся» — номер `АТС-XXXX`, телефон, «что дальше» и «что взять с собой».
8. **Черновик в `localStorage` с fallback.** Если хранилище недоступно (приватный режим), форма просто работает без сохранения — `try/catch`.
9. **Идемпотентность.** В payload уходит `idempotency_key` (генерируется один раз за сессию), повторная отправка не создаёт дубль.
10. **Админка как страница, а не скриншот.** Владелец публикует работу с телефона, виден таймер до 60 с и очередь при слабой сети.

## 7. Заявки

`POST /api/leads` → `201 {"ticket":"АТС-2412","status":"accepted"}`.

Payload (ровно то, что показывает панель «Что уйдёт на сервер»):

```json
{
  "name": "Пётр", "phone": "+79289065700", "contact_method": "call",
  "car": {"brand": "Kia", "model": "Rio", "year": 2019, "vin": null, "mileage": 84000},
  "services": ["perobuvka"], "diagnose": false, "photos_count": 1,
  "preferred": {"date": "2026-10-23", "slot": "12:00", "asap": false},
  "consent": true, "page": "/appointment.html", "idempotency_key": "ats-…"
}
```

Цепочка на сервере: валидация (телефон, VIN, год, обязательные поля) → запись в БД и номер заявки → outbox: Telegram владельцу и письмо на `avtotehservis439@mail.ru` → ретраи; если Telegram упал — письмо всё равно уходит; если упало всё — заявка остаётся в БД, а клиент всё равно видит «принято» и номер. Токен бота, chat_id и пароль почты — только в переменных окружения. В мокапе сети нет: отправка имитируется таймером 700–1200 мс, `fetch`/XHR/`sendBeacon` не вызываются.

## 8. Что демонстрационное

- Все фотографии заменены плакатными SVG-заглушками; реальных фото сервиса в мокапе нет.
- Новости, отзывы, работы в галерее, заявки в админке — **примеры текстов для вёрстки**, не публикации клиента.
- Рейтинги: 4,5 / 182 отзыва — помечено `[не проверено]`, остальные (3,6/12, 2,2/1, 5,0/1) — как в разборе; дата проверки указана рядом.
- Занятые слоты и «свободные окна» — придуманное расписание для демонстрации.
- Схема проезда нарисована вручную: без карт, iframe и ключей.
- Цены не публикуются: на странице услуги — «стоимость — после осмотра».

## 9. Чего не проверял

- **Не открывал мокап в браузере**: в песочнице нет Chromium (`@sparticuz/chromium` падает на `libnspr4.so`, ставить пакеты прав нет). Всё, что ниже про поведение, — автотесты jsdom и чтение кода, а не глаза.
- **320 / 390 / 768 / 1024 / 1440** — вёрстка не проверена визуально. Статически: фиксированных ширин нет (`max-width` вместо `width`), сетки на `minmax(0,1fr)`, календарь и карусели — `overflow-x:auto`, у форм `font-size:16px`.
- **`prefers-reduced-motion`** — блок CSS есть, эмуляцию не включал.
- **Свайпы** (герой, карусель, лайтбокс) — реализованы через pointer-события, на тач-устройстве не проверял.
- **Фокус-ловушка** в меню, лайтбоксе и модалке политики — читал код, Tab-цикл вручную не прокликивал.
- **Кириллица в шрифте** — по `unicode-range` и наличию `cyrillic`-сабсета, глифы посимвольно не сверял.
- **Печать** — есть `@media print`, принтер не подключал.
- **Почта и Telegram** — описаны как план, ничего не отправлялось.
