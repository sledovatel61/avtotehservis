## 4. Типографика
Пара: **Manrope 700/800 (дисплей)** + **Inter 400/600/700 (текст)** — обе OFL, кириллица подтверждена наличием глифов `А-Я а-я Ёё` в woff2-сабсете (файлы ≤120КБ: Manrope 98КБ, Inter 112КБ, сабсет кириллица+латиница). В мокапе — системный стек `Manrope, Inter, system-ui` без внешних запросов (CDN/Google Fonts запрещены). Дисплей — `clamp(28px,6vw,52px)`, трекинг -0.03em, 2 начертания; текст — 14/22, 16/26, капс только в eyebrow 11px и кнопках.

## 5. Решения (5)
1. **Оранжевый на бетоне, а не на чёрном** — индустриальный код без тёмной «серости»; белый на акценте только bold 14px+ с тенью, обычный текст — графит.
2. **Слайдер нативный 22 строки** вместо Revolution 9 плагинов — 0 КБ библиотек, пауза и reduced-motion из коробки.
3. **Форма 5 экранов без fetch** — имитация 700–1200ms, localStorage черновик с try/catch (file:// не падает), payload-панель — контракт с бэком честно.
4. **Галерея без Fancybox** — карусель на transform, лайтбокс 0.98→1, свайп 40px, фокус-ловушка — 2КБ JS.
5. **Марки — CSS marquee** вместо Owl — 28s linear, пауза hover, 0 JS, reduced-motion — пауза.

## 7. Заявки — payload и цепочка
Payload: `{name, phone:"+7928…", contact_method:"call|telegram", car:{brand,model,year,vin,mileage}, services:["shinomontazh",…], preferred:{date:"2026-10-24", slot:"10:00", asap:false}, photos_count:2, consent:true, page:"appointment", idempotency_key:"uuid-v4"}`  
Цепочка: `POST /api/leads → 201 {ticket, status:"accepted"}` → валидация → БД → outbox → Telegram `sendMessage` владельцу → письмо на `avtotehservis439@mail.ru` SMTP → ретраи → статус в `admin.html`. Telegram упал — письмо уходит; упало всё — заявка в БД, клиент видит «принято». Токены — только env, в мокапе 0 токенов/вызовов.
