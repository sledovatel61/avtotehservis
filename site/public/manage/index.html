Как получить личный токен?
  1. В GitHub откройте Settings → Developer settings → Fine-grained tokens и создайте токен.
  2. В Only select repositories выберите avtotehservis.
  3. В Repository permissions установите Contents: Read and write. Срок (Expiration) — 90 days.
  4. Скопируйте токен и вставьте ниже.

Токен = доступ к фото и текстам сайта. Не пересылайте его и не вставляйте на чужих устройствах.
