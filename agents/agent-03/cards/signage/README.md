# АвтоТехСервис · пять вывесок на Портовой, 439

[Коллаж JPG](ATS-signage-5-concepts.jpg) — варианты на одном ракурсе: слева день, справа визуализация вечерней подсветки. Это эскизы для выбора, не замер и не монтажная схема.

| № | Решение | Что выделяет |
|---|---|---|
| 01 | Апекс | Косая медная полоса с утверждённой визитки. Диагональ продолжается на центральном простенке. |
| 02 | Тихий свет | Тёмный фон и светлые буквы, отсылка к ночной сцене на главной сайта. |
| 03 | Портовая, 439 | Крупный номер дома и тёплый центральный простенок с часами работы. |
| 04 | Два бокса | Общее название и две цветовые плашки услуг; плашки не назначают функции воротам. |
| 05 | Светлый шильдик | Тёмные буквы на светлом поле и один номер телефона на нижней полосе. |

**Фото.** Широкий и ближний оригиналы на Drive (`image-22-10-26-06-02.jpeg` и `image-22-10-26-06-02-1.jpeg`) совпали по MD5 с `docs/photos-source/original-front-{wide,close}-3840x2160.jpg`. Широкий послужил основой монтажа; ближний, реальные кадры со страницы «О компании» и ночная главная сайта — референсы. Архитектура сохранена, вывеска и наружная панель простенка заменены в перспективе. Два читаемых регистрационных номера в боксах закрыты. В варианте 05 использован текущий основной номер опубликованной страницы «О компании» и существующей вывески, а не номер из «Апекса» для визитки.

**Следующий шаг после выбора:** обмерить верхнюю панель и простенок, проверить читаемость с дороги, уточнить технологию подсветки, согласовать цвет и телефон перед передачей в производство. Партнёрские знаки со старой вывески не переносились: при необходимости для них стоит обсудить отдельное размещение.

Повторный рендер из корня: `python -B agents/agent-03/cards/signage/build.py`; зависимости те же, что в `agents/agent-03/cards/requirements.txt`.
