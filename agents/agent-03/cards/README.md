## Форматы и печать

- По каждой концепции: `front.svg`, `back.svg` — самостоятельные векторы с буквами в кривых; `front.png`, `back.png` — 2268 × 1322 px с меткой 300 dpi, как в брифе. Для реального размера ориентируйтесь на SVG: 96 × 56 мм с вылетами, 90 × 50 мм после реза. При размещении PNG вручную выставьте 96 × 56 мм: у растра 2× при этом эффективные ≈600 dpi.
- Вылеты — 3 мм; безопасная зона для текста — 4 мм от линии реза. QR размером 16,5–17,5 мм, с тихой зоной в четыре модуля.
- Это экранные эскизы для выбора, не допечатные файлы: цвета RGB. Для тёмной заливки `#0B1410` в брифе указан ориентир CMYK **60/40/40/100**, его нужно согласовать с типографией под бумагу и ICC-профиль. Цветопроба, сканирование с бумаги и печатный PDF не делались.

## Что отличается от брифа и кода сайта

- На лицевой **+7 (928) 906-57-00** — это явное указание оркестратора. В `DEFAULTS` основным записан `+7 (951) 826-98-39`, а также есть `+7 (951) 826-58-47`: для эскизов первый показан только как Telegram на обороте, второй не использован. Перед печатью владельцу стоит подтвердить номер 928 и проверить, что он совпадает с номером, на который ведёт сайт.
- В брифе знак назван мишенью, но актуальный `logo.svg` — щит с автомобилем. Использован исходный знак с его собственными градиентами, без перерисовки. В «Мишени» он намеренно обрезается краем.
- В «Смете» ощущение бланка создают сетка, разрядка и правое выравнивание; отдельный моноширинный шрифт не вводился, чтобы сохранить два семейства сайта. Сайт и его настройки не менялись.

## Повторный рендер

Из корня репозитория, Python 3.11+:

```sh
python -m pip install -r agents/agent-03/cards/requirements.txt
python agents/agent-03/cards/render.py
```

Скрипт берёт SVG-знак, токены и локальные WOFF2 из `site/`, переводит глифы в контуры, рендерит стороны и собирает коллаж. При генерации проверяет тексты, физические размеры шрифтов, безопасную зону, пересечение текстовых блоков, контраст и распознавание QR.
