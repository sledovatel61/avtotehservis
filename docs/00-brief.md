# 00. Бриф проекта

## 1. Задача в одном абзаце

Сделать одностраничный сайт автосервиса «АвтоТехСервис» (Ростов-на-Дону, Портовая, 439), который превращает мобильный трафик из карт и поиска в заявки: квиз с выбором марки, VIN и описанием неисправностей, галерея фото и видео выполненных работ, отзывы. Заявки уходят на e-mail и дублируются в Telegram. Владелец без разработчика публикует фото/видео, редактирует отзывы и видит заявки в простой админке.

## 2. Проблема, которую решаем

У компании хорошая офлайн-репутация (4,5 / 182 оценки на Яндекс.Картах), но нет своего сайта. В сети она представлена разрозненными карточками каталогов с разными названиями, телефонами и оценками (от 2,2 до 5,0). Клиент, который выбирает сервис с телефона, не получает ни доверия, ни доказательств, ни удобного способа записаться, кроме звонка.

## 3. Цели и KPI

| Цель | Метрика | Целевое значение |
|---|---|---|
| Заявки | Конверсия из визита в заявку | ≥ 4% от всех визитов, ≥ 8% от дошедших до квиза |
| Квиз | Доля завершивших квиз | ≥ 65% |
| Доверие | Просмотр галереи/отзывов | ≥ 45% визитов |
| Скорость | Mobile Lighthouse Performance | ≥ 90 |
| Вес | Стартовый JS | ≤ 250 КБ gzip |
| Скорость | LCP на 4G (Moto G4-класс) | < 2,2 с |
| Стабильность | CLS / INP | < 0,05 / < 200 мс |
| Контент | Публикация нового кейса владельцем | ≤ 60 с, без помощи разработчика |
| Надёжность | Потеря заявок | 0 (e-mail + Telegram + журнал в админке) |

## 4. Аудитория

1. **«Сезонник»** — переобувка, грыжа, порез, правка диска. Срочно, с телефона, решение за 3–5 минут.
2. **«Постоянник»** — ТО, масло, тормоза, ходовая. Сравнивает, читает отзывы, выбирает рядом.
3. **«После поломки»** — двигатель, АКПП, электрика. Боится, что «разведут», нужен план и смета.
4. **B2B** — парки, коммерческий транспорт, грузовой шиномонтаж.

## 5. Объём: что входит

### P0 — обязательный минимум (без этого не сдаём)

- Hero с оффером, телефоном, CTA и пониманием, где это и когда работают.
- Блок услуг с двумя развилками: «Колёса» и «Ремонт/ТО».
- Доказательства: рейтинг с источником, гарантия, прозрачная смета, «покажем, что делаем».
- **Квиз**: марка (поиск + популярные + «другая»), модель/год (опционально), VIN (17 символов, необязательный, с объяснением зачем), неисправности (мультивыбор + «не знаю»), срочность, способ связи, имя, телефон, согласие на ПД.
- Ветвление квиза: колёса / ремонт / B2B / «не знаю».
- Галерея: фото и видео работ, фильтры по услуге, лайтбокс, загрузка через админку.
- Отзывы: реальные (Яндекс/2ГИС) + собственные с модерацией, рейтинг с указанием источника.
- Контакты: карта, маршрут, телефон, мессенджеры, часы, парковка.
- Sticky-CTA на мобиле: «Позвонить» + «Записаться».
- Админка: вход, заявки (список/карточка/статусы/экспорт), галерея (drag&drop, публикация, порядок), отзывы (модерация), настройки (телефоны, часы, сезонный баннер), 2FA.
- Интеграции: e-mail (SMTP) + Telegram-бот, ретраи, журнал доставки.
- Антиспам: honeypot, time-trap, rate limit, Яндекс SmartCaptcha (по необходимости).
- 152-ФЗ: согласие, политика, RU-хостинг, минимизация ПД в Telegram.
- SEO: метаданные, JSON-LD (AutoRepair/LocalBusiness, FAQ, Service), sitemap, robots, OG.
- Аналитика: Яндекс.Метрика + цели по шагам квиза и кликам.

### P1 — после запуска, в течение 4–6 недель

- Калькулятор шиномонтажа по радиусу и типу диска (после подтверждения прайса).
- Блок «до/после» с ползунком.
- Страницы услуг (SEO): /shinomontazh, /pravka-diskov, /remont-akpp, /remont-dvigatelya, /avtoelektrika.
- Сезонный лендинг «Переобувка 2027».
- B2B-страница с формой для парков.
- Отзывы с фото, ответы владельца на сайте.
- PWA-манифест + «добавить на главный экран».

### P2 — задел на будущее

- Онлайн-запись со слотами и подтверждением.
- Интеграция с CRM (Bitrix24/amoCRM).
- Программа лояльности, напоминания о ТО.

### Вне рамок

- Интернет-магазин шин и дисков, оплата онлайн, личный кабинет клиента, 1С, мобильное приложение.

## 6. Ограничения

**Дизайн**
- Mobile-first, базовый экран 390×844, проверка 320 / 390 / 768 / 1024 / 1440.
- Анимация: только `transform`/`opacity`, 150–400 мс, без scroll-jacking, без WebGL/3D, без автозвука, `prefers-reduced-motion` обязателен.
- Кириллица: шрифты с полной кириллицей и открытой лицензией, self-hosted, `font-display: swap`, максимум 2 гарнитуры и 4 начертания.
- Никаких стоковых «чужих» машин в галерее работ: только реальные работы или явно декоративные изображения без выдачи за кейсы.

**Техника**
- SSR/SSG, индексируемость, работа без JS в базовом сценарии (контент читается, контакты доступны).
- Изображения: AVIF/WebP, адаптивные `srcset`, lazy-loading ниже первого экрана, фиксированные размеры.
- Видео: постер + клик-воспроизведение, без автоплея со звуком; длинные ролики — через VK Video, короткие — mp4 H.264.
- Доступность: WCAG 2.2 AA, тапы ≥ 44 px, контраст ≥ 4,5:1, фокус-стили, семантика.
- Хостинг в РФ, HTTPS, бэкапы, 152-ФЗ.

**Контент**
- Русский язык, «вы» с строчной, без канцелярита, без «молодая динамично развивающаяся компания».
- Запрещены непроверенные утверждения: «лучший», «№1», «100% гарантия», «20 лет опыта» (если это не подтверждено).

## 8. Definition of Done для сайта

1. Все блоки P0 работают на мобиле и десктопе.
2. Заявка проходит полный путь: квиз → БД → e-mail → Telegram → отображается в админке; сбой одного канала не теряет заявку.
3. Владелец с телефона загружает видео, ставит обложку, публикует кейс — без подсказок.
4. Lighthouse mobile ≥ 90, JS ≤ 250 КБ gzip, LCP < 2,2 с, CLS < 0,05, INP < 200 мс.
5. Валидация W3C/HTML, нет горизонтального скролла на 320 px, клавиатурная навигация работает.
6. Есть политика конфиденциальности, согласие, чек-лист синхронизации карточек.
7. Написана инструкция владельцу (10–15 минут чтения) + короткое видео.
