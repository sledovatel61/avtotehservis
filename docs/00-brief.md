# 00. Бриф проекта

## 1. Задача в одном абзаце

Сделать одностраничный сайт автосервиса «АвтоТехСервис» (Ростов-на-Дону, Портовая, 439), который превращает мобильный трафик из карт и поиска в заявки: квиз с выбором марки, VIN и описанием неисправностей, галерея фото и видео выполненных работ, отзывы. Заявки уходят на e-mail и дублируются в Telegram. Владелец без разработчика публикует фото и видео, редактирует отзывы и видит заявки в простой админке — в том числе с телефона.

## 2. Проблема

У компании хорошая офлайн-репутация (4,5 / 182 оценки на Яндекс.Картах — данные заказчика), но нет своего сайта. В сети она представлена разрозненными карточками каталогов под разными названиями и с разными оценками (от 2,2 до 5,0). Клиент, который выбирает сервис с телефона, не получает ни доверия, ни доказательств, ни удобного способа записаться, кроме звонка.

## 3. Цели и KPI

| Цель | Метрика | Целевое значение |
|---|---|---|
| Заявки | Конверсия из визита в заявку | ≥ 4% от всех визитов, ≥ 8% от дошедших до квиза |
| Квиз | Доля завершивших | ≥ 65% |
| Доверие | Просмотр галереи/отзывов | ≥ 45% визитов |
| Скорость | Mobile Lighthouse Performance | ≥ 90 |
| Вес | Стартовый JS | ≤ 250 КБ gzip |
| Скорость | LCP на 4G | < 2,2 с |
| Стабильность | CLS / INP | < 0,05 / < 200 мс |
| Контент | Публикация кейса владельцем с телефона | ≤ 60 с |
| Надёжность | Потеря заявок | 0 |

## 4. Аудитория

1. **«Сезонник»** — переобувка, грыжа, порез, правка диска. Срочно, с телефона, решение за 3–5 минут.
2. **«Постоянник»** — ТО, масло, тормоза, ходовая. Сравнивает, читает отзывы, выбирает рядом.
3. **«После поломки»** — двигатель, АКПП, электрика. Боится, что «разведут», нужны план и смета.
4. **B2B** — парки, коммерческий транспорт, грузовой шиномонтаж.

## 5. Объём

### P0 — обязательный минимум

- Hero с оффером, телефоном, CTA, адресом и часами.
- Развилка «Колёса / Ремонт и ТО / Не знаю, что случилось».
- Услуги, доказательства, рейтинг с источником.
- **Квиз:** марка (поиск + популярные + «другая»), модель/год (опционально), VIN (17 символов, необязательный, с объяснением), неисправности (мультивыбор + «не знаю»), срочность, способ связи, имя, телефон, согласие на ПД.
- Галерея фото и видео, фильтры, лайтбокс, загрузка через админку.
- Отзывы: реальные (Яндекс/2ГИС) + собственные с модерацией.
- Контакты, карта, маршрут, мессенджеры, парковка.
- Sticky-CTA на мобиле.
- **Админка:** вход, заявки (список/карточка/статусы/экспорт), галерея (drag&drop, публикация, порядок), отзывы, настройки, 2FA.
- **Интеграции:** e-mail (SMTP) + Telegram, ретраи, журнал доставки.
- Антиспам, 152-ФЗ, SEO, аналитика.
- Мобильная публикация фото/видео с телефона.

### P1 — после запуска (4–6 недель)

Калькулятор шиномонтажа, «до/после», страницы услуг, сезонный лендинг, B2B-страница, ответы владельца на отзывы, PWA-манифест.

### P2 — задел

Онлайн-запись со слотами, CRM, программа лояльности, напоминания о ТО.

### Вне рамок

Интернет-магазин, оплата онлайн, личный кабинет, 1С, мобильное приложение.

## 6. Ограничения

**Дизайн**
- Mobile-first, базовый экран 390×844, проверка 320/390/768/1024/1440.
- Анимация: только `transform`/`opacity`, 150–400 мс, без scroll-jacking, WebGL/3D, автоплея со звуком, `prefers-reduced-motion` обязателен.
- Кириллица: шрифты с открытой лицензией, self-hosted, максимум 2 гарнитуры и 4 начертания.
- **Палитра и стиль не заданы** — выбираются по результатам конкурса концепций.
- Никаких стоковых «чужих» машин в галерее работ.

**Техника**
- Требования к результату: SSR/статика, индексируемость, базовая работоспособность без JS, AVIF/WebP, адаптивные изображения, видео без автоплея со звуком, WCAG 2.2 AA, хостинг в РФ, HTTPS, бэкапы.
- **Стек и CMS не зафиксированы.** Решение принимается по `docs/02-solution-options.md` и `docs/05-cms-vs-custom.md` после мокапа и теста мобильной публикации.

**Контент**
- Русский язык, «вы» со строчной, без канцелярита.
- Запрещены непроверенные утверждения: «лучший», «№1», «100% гарантия», «20 лет опыта» и любые выдуманные цифры.

## 7. Роли и процесс

| Роль | Кто | Зона |
|---|---|---|
| Заказчик | владелец «АвтоТехСервис» | факты, фото/видео, доступы, выбор мокапа, приёмка |
| Оркестратор | Arena Agent | бриф, промпт, фактчек, скоринг, ревью кода, приёмка |
| Агенты (5) | конкурс | концепции → пять мокапов → код победителя |

**Гейты:**
1. Пять независимых концепций по 12 разделам.
2. Скоринг, две замены — в конкурсе остаются пять работ.
3. Пять HTML-мокапов.
4. **Выбор мокапа заказчиком.**
5. Только после этого — разработка.

## 8. Definition of Done

1. Все блоки P0 работают на мобиле и десктопе.
2. Заявка проходит путь: квиз → БД → e-mail → Telegram → админка; сбой одного канала не теряет заявку.
3. Владелец с телефона загружает видео, ставит обложку, публикует кейс — **проверено на iPhone и Android**.
4. Lighthouse mobile ≥ 90, JS ≤ 250 КБ gzip, LCP < 2,2 с, CLS < 0,05, INP < 200 мс — с отчётом.
5. Нет горизонтального скролла на 320 px; клавиатурная навигация работает.
6. Есть политика конфиденциальности, согласие, чек-лист синхронизации карточек.
7. Написана инструкция владельцу + короткое видео.
8. Все заявления «работает/готово» подтверждены результатом проверки или помечены ограничением.
