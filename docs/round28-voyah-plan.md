### 2.2. Отдельная страница `/voyah-free`
Порядок блоков:

1. **Интро-анимация «Световая линия»** (см. §3) — один раз за сессию, скипается.

9. **Перелинковка**: «Другие работы» → `/services`, `/prices`; ссылка с `/prices` и из футера.

## 3. «Wow»-анимация входа на `/voyah-free`

Задача: при первом заходе на страницу — короткая кинематографичная сцена, затем контент. Требования жёсткие, иначе «вау» превращается в «тормозит и бесит»:

1. **Сценарий (2.4 с, 60 fps):**
   - 0.0–0.35 с — чёрный экран, по центру тонкая горизонтальная линия толщиной 2 px;
   - 0.35–0.9 с — линия «включается»: bloom, расходится влево-вправо в две фары;
   - 0.9–1.8 с — SVG-контур Voyah Free (собственный, 12–16 сегментов) собирается по `stroke-dashoffset`, снизу поднимается отражение на мокром асфальте;
   - 1.8–2.4 с — вспышка световой линии, две шторы разъезжаются (`clip-path`), под ними уже готовый контент.
2. **Технически:** отдельный оверлей `position:fixed; inset:0; z-index:100`, `aria-hidden="true"`, класс вешается **только из JS** — без JS контент виден сразу (никакого FOUC и пустого экрана). Только `transform`/`opacity`/`clip-path`, без `filter: blur()` на полноэкранных слоях (дорого), без canvas-loop после сцены.
3. **Управление:** клик, `Esc`, скролл или тап — мгновенно прекращают интро (переход 180 мс). Повторно в той же сессии не показывается (`sessionStorage`, ключ `voyah-intro`), после 24 часов — снова. При `prefers-reduced-motion: reduce` интро не запускается вообще.
4. **Производительность:** вес JS ≤ 12 КБ gzip, CSS ≤ 6 КБ, SVG ≤ 20 КБ, никаких внешних библиотек и шрифтов; сцена не создаёт layout shift (оверлей вне потока), LCP-элемент страницы — заголовок, а не оверлей.
5. **Доступность:** фокус не запирается, озвучка не перебивается, `prefers-reduced-motion` и «медленный интернет» (`navigator.connection.saveData`) отключают интро.

5. **SEO:** собственные `title`/`description`, `canonical`, `og:image`, включение в `sitemap.xml`, `BreadcrumbList`, ссылка с главной и из футера.
6. **Мутанты:** `check-voyah.mjs` обязан падать, если (а) секция уехала не между «О компании» и «Как мы работаем», (б) из прайса пропала позиция, (в) у интро нет reduced-motion-ветки, (г) интро блокирует контент без JS, (д) сумма цены расходится с таблицей §4.
