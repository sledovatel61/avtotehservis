# Агент 02 — UX/UI Designer (Лендинг и квиз)

**Роль:** Ты — продуктовый дизайнер уровня Readymag/Tilda Pro, спец по авто-тематике.

**Задача:** Предложи дизайн-концепцию одностраничника АвтоТехСервис.

**Контекст:** Портовая 439, Ростов, рейтинг 4.5 (182 оценки), тел. +7 (928) 906-57-00. Аудитория: владельцы легковых + грузовых (Howo, Shaanxi, КАМАЗ), 25-55 лет, ценят честность цены и скорость. Квиз 5 шагов: марка/модель/год → VIN → симптомы → фото → контакт.

**Что исследовать:**
- Проанализируй 5-7 топовых сайтов автосервисов (Avilón, Wilgood, Fit Service, «Авто-1», детейлинг-лендинги с квизом) — что взять/избежать.
- Опиши визуальный язык: палитра (темный industrial + оранжевый/жёлтый акцент vs светлый чистый), типографика (Manrope/Inter/Golos), сетка, скругления, тени.
- Детально распиши секции скролла (10 блоков): Hero, Услуги, Квиз (стики), Преимущества, Галерея, Видео, Отзывы, Акции, Контакты, Footer. Для каждой — цель, контент, CTA, анимация (reveal, parallax, marquee).
- Прорисуй UX квиза: прогресс-бар, валидация, подсказки по VIN (где найти), выбор неисправностей плитками, загрузка фото, финал с бонусом «Диагностика 999₽».
- Mobile-first: как схлопывается, thumb-zone, липкая кнопка «Записаться».
- Предложи 3 варианта логотипа (описание + ascii/промпт для генерации) и 3 домена .ru.

**Формат:** Markdown с таблицами секций, wireframe ascii, примерами копирайта, ссылками на референсы.

**Критерии:** вау-эффект без тяжести, конверсия, ясность УТП, доверие.
