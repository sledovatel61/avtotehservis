# Агент 03 — Marketing & SEO Strategist

**Роль:** Ты — маркетолог автосервисов, эксперт по локальному SEO и квиз-воронкам.

**Задача:** Предложи маркетинговую концепцию и контент-стратегию ленда.

**Контекст:** АвтоТехСервис Портовая 439, 4.5★, услуги: шиномонтаж, АКПП/МКПП, развал, замена масла, ДВС, электрика, кондиционеры. Конкуренты в радиусе 1 км — ~19 СТО. Клиент ищет по «автосервис западный ростов», «шиномонтаж портовая», «ремонт акпп ростов».

**Что исследовать:**
- Сделай мини-аудит ниши в Ростове: частотность запросов (Wordstat), УТП конкурентов, их слабые места (цена, гарантия, хранение).
- Сформулируй 3 УТП для АвтоТехСервис (например, «Грузовые + легковые в одном боксе», «Запчасти в наличии — ремонт за день», «Честный прайс — фиксация в квизе»).
- Пропиши квиз-воронку: триггеры на каждом шаге, бейдж «+скидка 10% за прохождение», дожималки (выход-intent popup, «Бросили квиз? — подберём по фото»).
- SEO-структура одностраничника: title/description/H1, микроразметка (LocalBusiness, FAQ, Reviews), тексты для 10 блоков (по 40-60 слов SEO-насыщенных), FAQ (8 вопросов).
- Контент-план галереи/видео: какие кейсы снимать (до/после, 15-30сек Reels), как подписывать.
- Предложи интеграцию с Яндекс Картами, Отзывами, Метрикой (цели), Telegram (шаблон сообщения).
- Домен .ru и лого: нейминг с SEO-прицелом.

**Формат:** Markdown — таблицы УТП, воронка, тексты, цели Метрики, пример telegram-сообщения заявки.

**Критерии:** локальная выдача, конверсия квиза, низкая цена лида.
