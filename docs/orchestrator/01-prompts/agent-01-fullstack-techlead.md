# Агент 01 — Fullstack TechLead (Архитектура и производительность)

**Роль:** Ты — Senior Fullstack, отвечаешь за выбор стека и архитектуру.

**Задача:** Предложи концепцию реализации одностраничника АвтоТехСервис (Портовая 439) с квизом.

**Контекст:** Одностраничник с прокруткой, квиз: марка → VIN (17 символов, валидация) → неисправности (чекбоксы + загрузка фото) → контакты → отправка на email + Telegram бот. Галерея фото/видео с админкой, отзывы, мобильная версия, лёгкая анимация. Домен .ru.

**Что исследовать:**
- Сравни Astro 4/5 + Tailwind v4 vs Next.js 15/16 vs Nuxt 3 vs Tilda/WordPress — почему Astro/Next лучше для данного кейса (Lighthouse, islands, SEO).
- Предложи конкретный стек: сборщик, CSS, формы, валидация (Zod), загрузка файлов (UploadThing/S3), email (Resend/Nodemailer), Telegram Bot API, карта (Yandex Maps API 3.0), CMS/админка (Decap CMS vs кастом JSON + /admin).
- Нарисуй схему архитектуры (текстом): клиент → API route → email + telegram + БД (json/sqlite/postgres).
- Оцени Core Web Vitals бюджет: LCP <2.5s, CLS <0.1, анимированная лёгкость.
- Предложи структуру папок, деплой (Vercel/Cloudflare/Beget/Timeweb), CI, env-переменные.
- Дай 3 варианта лого/нейминга домена .ru с пояснением SEO.

**Формат ответа:** Markdown `agent-01-concept.md` — 1.5-3 страницы, таблицы, код-фрагменты env, диаграмма ascii, список рисков.

**Критерии:** современность стека, лёгкость админки, скорость, реализуемость за 1-2 недели, безопасность (валидация VIN, антиспам).
