### Что берём в финальный проект

- **Стек:** Astro 5 + Tailwind v4 + Preact islands (Агент01). Deploy Vercel + fallback Beget.
- **Админка:** Кастом `/admin` + JSON + Turso (Агент05) + Decap опция Pro.
- **Дизайн:** Industrial Dark `#0B0E12` + `#FF5A1F`, 10 блоков, липкий квиз (Агент02).
- **Анимация:** CSS-only + Motion только квиз (Агент04, облегчённо).
- **Маркетинг:** 3 УТП, FAQ, LocalBusiness микроразметка (Агент03).
- **Домен:** **portovaya439.ru** (единогласие 5/5) + резерв ats61.ru.
