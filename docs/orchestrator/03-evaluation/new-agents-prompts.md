# Новые агенты после ротации

## Агент06 — HTML Prototyper
**Задача:** Сделать 3 HTML-мокапа в 1 файле (`04-mockups/index.html`). Каждый мокап — кликабельный прототип одностраничника (hero + услуги + квиз-черновик + галерея + отзывы + контакты). Используй Tailwind CDN, без сборки. Покажи вариативность: A) Industrial Dark, B) Light Trust, C) Brutal Garage. Добавь переключатель вверху. Оркестратор выберет лучший.

**Требования:** Mobile адаптив, анимация reveal, квиз как 5 шагов без бэкенда (JS прототип), галерея фильтры, карта-заглушка. 1 файл, <200KB.

## Агент07 — Content Creator
**Задача:** Напиши контент для финального сайта: H1/H2, 10 блоков по 50 слов, 12 кейсов галереи (до/после, цена, срок), 8 FAQ, 12 отзывов (6 с Яндекса перефраз, 6 новых), тексты для квиза, email и Telegram шаблоны. Тон: честный мастер, без воды. SEO: вхождения «автосервис Портовая 439», «шиномонтаж Западный».

**Дедлайн:** 1 день.
