# Концепция Агент 03 — Marketing & SEO | Локальная выдача + Квиз-воронка

## Аудит ниши Ростов Портовая

- Запросы Wordstat: «автосервис Ростов» 8k/мес, «шиномонтаж Ростов» 3.2k, «ремонт акпп Ростов» 1.1k, «автосервис западный Ростов» 320. Конкуренция высокая, но одностраничник с квизом даёт -30% CPL vs каталог.
- Конкуренты: Формула61 — сильный магазин запчастей, Портовая — демпинг шиномонтажом. Наша ниша: **«Единственный на Портовой кто делает и легковые и грузовые + хранит шины + даёт гарантию»**.
- Боль: страх развода → УТП «Цена фиксируется в квизе, доплаты только с вашим ОК по фото».

## 3 УТП

1. **Честный фикс-прайс:** Прошли квиз — цена заморожена, фото-отчёт до/после.
2. **Грузовые + легковые в одном боксе:** Howo/Shacman/КАМАЗ + LADA/Renault/Nissan — не гоняем по району.
3. **Запчасти в наличии 24ч:** Склад на Портовой + доставка 2ч, подменный авто.

## Квиз-воронка

- Триггер входа: Hero «Узнай точную цену за 60 сек + скидка 15%» (всплывашка через 15с + exit-intent).
- Шаг-логика: марка → если КАМАЗ → ветка «Грузовой», VIN → если пропустил → +вопрос «Госномер».
- Дожималки: бросил на шаге 3 → popup «Оставь телефон — мастер перезвонит за 5 мин и посчитает по фото». Ретаргет: Яндекс Аудитории + VK.
- Конверсия цель: 30% старт → 45% финиш.
