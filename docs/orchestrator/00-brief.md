## 2. Технические требования оркестратора

- Стек — топовый современный, 2025-2026: **Astro 4/5 + Tailwind v4 + TypeScript** (острова интерактивности на React/Preact для квиза). Альтернатива — Next.js 15/16 если нужен SSR для админки, но для ленда Astro даёт 95+ Lighthouse из коробки.
- Анимация: лёгкая, не тяжёлая — `Motion` (Framer Motion) + CSS-only parallax/marquee, IntersectionObserver reveal, без GSAP heavy если не нужен scroll-flight.
- Mobile-first, LCP <2.5s, CLS <0.1, INP <200ms.
- Админка: простая — **Decap CMS (Netlify CMS) + Git-based** или **CloudCannon/Frontmatter** или кастом JSON + админ-страница с Basic Auth (для MVP). Без WordPress.
- Интеграции:
  - Email: Resend / Nodemailer (SMTP timeweb/reg.ru)
  - Telegram: BotFather → `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
  - Карта: Яндекс Maps API 3.0
  - Отзывы: виджет Яндекс + своя база
  - Аналитика: Яндекс.Метрика + Plausible
