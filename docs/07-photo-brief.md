## 3. Технические требования

- **Формат:** JPEG или HEIC (сконвертируем), видео — MP4/MOV.
- **Размер:** фото ≥ 2000 px по длинной стороне; видео 1080p.
- **Свет:** дневной или свет из ворот; без вспышки в лоб и без жёлтых ламп, если можно.
- **Фокус:** резко по детали, а не по фону.
- **Ракурс:** «до» и «после» — с одной точки, одинаковый зум.
- **Чистота кадра:** убрать мусор, чужие лица, документы, экраны с VIN, крупные госномера.
- **Не присылать:** фото из интернета, стоки, скриншоты чужих сайтов, фото с водяными знаками, коллажи.
