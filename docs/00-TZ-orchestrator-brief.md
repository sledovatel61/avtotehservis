## 1. Что делаем

Одностраничный (лендинг с вертикальным скроллом) сайт автотехсервиса в Ростове-на-Дону:
премиальный по ощущению, быстрый по факту, с понятным путём «увидел проблему → выбрал марку →
указал VIN → отметил неисправности → оставил контакт». Плюс:

- **Квиз-заявка** (мультишаг) с выбором марки/модели, VIN, симптомов/неисправностей, срочности, контакта.
- **Галерея фото и видео выполненных работ** (кейсы «до/после», видео с ремонта).
- **Отзывы** (реальные, с карт + добавляемые вручную; рейтинг 4,5 / 182 оценки — якорь доверия).
- **Простое удалённое администрирование**: добавление фото/видео/кейсов/отзывов без программиста, с телефона.
- **Доставка заявок**: e-mail + дублирование в Telegram-бот, с журналом и защитой от спама.

## 5. Что нужно от клиента (блокеры, можно параллельно с этапом 1)

1. **E-mail** для заявок + доступ к SMTP (Яндекс 360 / Mail.ru для бизнеса) — или согласие на наш ящик-агрегатор.
2. **Telegram**: создать бота у @BotFather, прислать токен и `chat_id` группы/канала (куда дублировать).
3. **Реальные медиа**: 10–20 фото цеха/работ/команды, 3–5 видео (вертикальные с телефона — ок), логотип, если есть.
4. **Уточнения**: точный режим работы, какие работы делаете сами, а какие — партнёры; гарантия; есть ли эвакуатор/подменный авто.
5. **Домен**: согласовать имя из шортлиста (`docs/01-company-dossier.md`, раздел 6) — регистрация на РФ-регистраторе.
6. **Юрлицо/ИП, ИНН** для футера и политики ПД.

## 6. Правила игры для агентов (не обсуждаются)

- Не выдумывать факты, цены, отзывы, награды, сертификаты, годы опыта.
- Не копировать чужие сайты и тексты; референсы — только для механик и настроения.
- Каждое решение — с обоснованием «почему это принесёт звонок/заявку».
- Мобайл — не «версия», а основной сценарий.
- Анимация подчинена смыслу: подсказывает, а не развлекает.
- Стек — обосновать под задачу, а не по хайпу. Учитывать РФ-хостинг и простоту поддержки малым бизнесом.
- Любой спорный тезис — со ссылкой на источник в ресёрче.
