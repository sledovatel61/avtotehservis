## 1. Как проверяли и чего это стоит

| Что | Инструмент | Ограничение |
|---|---|---|
| Версии npm-пакетов | `npm view` из рабочей среды | видно только опубликованное, не качество |
| Сроки поддержки Node, PostgreSQL, WordPress, Next.js | API endoflife.date | даты обновляются, на 21.10.2026 актуальны |
| Лицензии | GitHub API + текст LICENSE | для «NOASSERTION» читали LICENSE вручную |
| Документация CMS | официальные сайты через веб-запрос | маркетинговые страницы, не аудит |
| Цены хостинга и CMS | страницы провайдеров | тарифы могут отличаться по региону/акциям |
| Рейтинги и телефоны компании | поисковая выдача и справочники | **карточки Яндекс.Карт и 2ГИС напрямую не открылись** |
| Локальная среда | Node 22.22.3, npm 10.9.8 | не равно продакшену |

Важно: **у среды нет прямого доступа в интернет из bash** — запросы к сайтам делались отдельным инструментом, поэтому часть карточек (Яндекс, 2ГИС) недоступна. Это ограничение, а не «не проверяли».

## 6. Что нельзя утверждать (запрещённые формулировки для агентов и для меня)

- «Сайт готов / работает / протестирован», если нет результата проверки.
- «Публикация фото и видео с телефона проверена» — до теста на iPhone и Android.
- «Соответствует 152-ФЗ» — до проверки документов и хостинга; корректно: «заложены требования 152-ФЗ».
- «Рейтинг 4,5 подтверждён» — подтверждён только заказчиком.
- «Гарантия», «20 лет опыта», «лучший сервис», «№1», «100%».
- «Цены от …» — без подтверждённого прайса.
- «CMS X не работает на телефоне» — корректно: «в документации не найдено, требуется тест».

## 8. Открытые проверки перед разработкой

1. Открыть карточку Яндекс.Карт и 2ГИС с российского IP, зафиксировать рейтинг, число оценок, часы, телефоны (скриншот + дата).
2. Проверить занятость доменов `.ru` на reg.ru/nic.ru.
3. Тест загрузки HEIC-фото и видео 40–60 МБ с iPhone и Android в выбранную CMS.
4. Проверить доступность официального приложения WordPress в RuStore/App Store/Google Play для РФ.
5. Получить у владельца: юрлицо/ИП, ИНН, точные часы, гарантию, e-mail, Telegram, прайс, фото.
6. Прогнать Lighthouse на прототипе (не на мокапе) и зафиксировать числа.
