## 1. Что поменялось

1. **`Header.astro`**: `<div class="hdr-in container">` → `<div class="hdr-in">`. Шапка больше не наследует
   `max-width:1200px` от `.container`.
2. **`tokens.css`**: новая переменная `--hdr-max:1800px` (только для шапки и демо-плашки).
   `--container:1200px` не тронут — текстовые секции остались той же ширины.
3. **`header.css`** переписана вместо пяти перекрывавших друг друга «патчей» кругов 15/27/29:
   - `.hdr-in,.hdr-wrap{max-width:var(--hdr-max);margin-inline:auto;padding-inline:clamp(20px,3vw,48px)}`;
   - `.hdr-in` — `display:flex;justify-content:space-between`, меню центрируется (`margin-inline:auto`),
     зазор между блоками `clamp(8px,1vw,24px)`;
   - вертикальные поля `clamp(9px,calc(36px - 1.359vw),14px)` — ужимаются ровно на рост логотипа,
     чтобы полоса во всём диапазоне 1024–2560 оставалась **72 px** (первый экран не съезжает,
     `--hdr:96px` не менялся);
   - логотип `clamp(62px,4.4vw,88px)`, пропорция держится `aspect-ratio:68/42`;
   - название `clamp(16px,.335vw + 12.57px,19px)`, подпись `clamp(10px,.2vw + 7.95px,11px)`;
   - пункты меню `clamp(13.5px,.625vw + 5px,15.5px)`, отступы `clamp(6px,.55vw,11px) clamp(4px,.55vw,12px)`,
     зазор `clamp(0px,.2vw,6px)`, `min-height:44px` сохранён;
   - телефон `clamp(14.5px,.3vw + 11.7px,17px)`, иконка `clamp(17px,.2vw + 15px,19px)`;
   - кнопка `clamp(12.5px,.35vw + 8.9px,14px)`, отступы `clamp(9px,.5vw,12px) clamp(12px,.9vw,18px)`;
   - остались два режима экономии: **1024–1199** — без подписи логотипа и без телефона;
     **1200–1359** — подпись есть, у телефона только трубка (`span` скрыт). С 1360 всё на месте.
4. **`export-pages.mjs`**: демо-плашка получает класс `demo-notice hdr-wrap` вместо
   `demo-notice container` — теперь её текст стоит по тем же краям, что и шапка.
5. **`scripts/check-header-fluid.mjs`** (новый гейт, подключён в `npm run test`):
   без headless-браузера пересчитывает вёрстку по метрикам шрифтов (fontTools по `public/fonts/*.woff2`)
   и тем же `clamp`-формулам из `header.css`. Есть `--self-test`: гейт обязан падать на четырёх
   поломках (узкая шапка 1200 px, меню 38 px, снятый `nowrap`, возвращённый `.container`).

**Чего не делали:** `--container` не расширяли, состав и порядок меню, телефоны, адрес и цифры
не меняли, бургер на десктоп не добавляли, шрифты/иконки/CDN не подключали, форму и согласие не трогали.

Плюс сквозной прогон 1024…2560 с шагом 16 px: минимальный запас 42 px (на 1024),
горизонтального выхода за край нет ни на одной ширине.

Почему `--hdr-max:1800px`, а не предложенные в задании 1680: при 1680 коробка на 2560 — 65.6 %
окна, а её видимый контент (за вычетом полей) — 61 %, то есть ниже требования «не меньше ~65 %».
1800 px даёт 70 % на 2560 и 94 % на 1920.
