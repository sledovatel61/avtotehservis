**Собрано:** 21.10.2026, по фотографиям владельца (Drive) и паспортным габаритам.
**Зачем:** чтобы «похожа на Voyah Free» перестало быть вкусовым спором и стало числом.
Этим документом пользуется **A11** (задание №54, геометрия машины для 3D-фона).

> **Важно, что изменилось 21.10.** Заставка больше не показывает машину в 3D: владелец выбрал
> фронтальный кадр «световая линия → силуэт», задание №52 переписано. Разметка фронта —
> в соседнем **`FRONT.md`**, она к этому файлу не относится: здесь профиль сбоку и метры
> из паспорта, там фронтальный кадр и его собственные пропорции. Не смешивать.

## 2. Паспорт (жёсткий, допуск ±2 %)

4905 × 1950 × 1645 мм, база 2960, клиренс 180, колёса 255/45 R20 (диаметр 0,7375),
колея 1654/1648. Отношения для гейта: **длина/высота 2,98**, **база/длина 0,603**,
**колесо/высота 0,448**.

## 3. Координаты по профилю `side-black.webp` (снято с сетки)

Пиксели кадра, начало — левый верхний угол. Дальше переводятся в метры по масштабу §3.1.

| Ориентир | Координата (px) |
|---|---|
| корма (крайняя левая точка кузова) | x ≈ **55** |
| нос (крайняя правая, бампер) | x ≈ **1140** |
| верх крыши (высшая точка) | y ≈ **330** (по линии крыши над стойкой B) |
| низ шин (линия земли) | y ≈ **700** |
| передняя ось (центр колеса) | x ≈ **960**, y ≈ **600** |
| задняя ось | x ≈ **280**, y ≈ **600** |
| диаметр колеса по фото | ≈ **130** px |
| подоконная линия | y ≈ **400** (у кормы 395, у зеркала 415) |
| линия капота (перед лобовым) | y ≈ **430** |
| низ кузова (порог) | y ≈ **620** |
| кромка спойлера над кормой | y ≈ **345**, x ≈ 90…190 |

### 3.1 Масштаб и контроль

- длина по фото: 1140 − 55 = **1085 px** → 4,905 м ⇒ **1 px = 4,52 мм**
- высота по фото: 700 − 330 = **370 px** ⇒ 370 × 4,52 = **1,672 м** (паспорт 1,645; +1,6 % — в допуске)
- колесо по фото: 130 px ⇒ 0,588 м… **не сходится с паспортом (0,7375)**. Значит на фото
  колёса стоят на асфальте с перспективой и частично перекрыты арками, и мерить диаметр
  «по внешнему контуру шины» нельзя. **Диаметр берётся из паспорта, из фото — только центр оси.**
- контроль базы: 960 − 280 = 680 px ⇒ 680 × 4,52 = **3,074 м** при паспорте 2,960 (+3,9 %):
  фото снято не идеально ортогонально, есть небольшой поворот. **Поэтому координаты — стартовая
  точка трассировки, а не истина; окончательные числа даёт гейт с эталоном §2.**

## 4. Что должно быть видно в силуэте (по фото, а не по памяти)

1. **Капот длинный и почти плоский**, поднимается к лобовому; передняя кромка капота
   заходит на фару — фара начинается сразу под ней.
2. **Лобовое сильно наклонено** (по фото ≈ 30° от вертикали), стойка A тонкая.
3. **Крыша** — выпуклая, самая высокая точка **над стойкой B**, к корме плавно падает
   и заканчивается **кромкой-спойлером**, выступающей над стеклом (на фото видно отдельным
   «козырьком» на x 90…190, y ≈ 345).
4. **Стойка C толстая и наклонная**, за ней — узкое окно-«форточка» (на фото читается
   треугольником у кормы).
5. **Заднее стекло наклонено ≈ 22–25°**, дверь багажника почти вертикальна, но с наклоном;
   фонарь идёт во всю ширину и заворачивает на борт.
6. **Подоконная линия непрерывная**, немного поднимается к корме (по фото 415 → 395).
7. **Арки** — выраженные, с небольшим зазором над шиной (по фото зазор ≈ 8–12 px)
   и с чёрным пластиковым молдингом по кромке; **между арками — порог**.
8. **Колёса крупные**, спиц много (5 сдвоенных), диск почти во всю шину.
9. **Передний свес короткий**, бампер с вертикальными воздуховодами по краям.
10. **Корма почти вертикальная**, но с выраженной «полкой» под фонарём.

## 5. Как этим пользоваться

- **Профиль строится по опорным точкам** §3–4, а не из «двух боксов и двух срезов».
- **Диаметр колеса, база, длина, высота — только из паспорта** (§2). Фото задаёт **форму**,
  паспорт — **масштаб**. Расхождение фото с паспортом (см. §3.1) — это перспектива, а не данные.
- **Орто-рендер** `scripts/car-profile.mjs` накладывается на `side-grid.jpg` — так видно,
  где форма ушла, без слов «мне кажется».
- **Если владелец пришлёт фото строго сбоку без перспективы** (телеобъектив, машина
  в профиль, ровный горизонт) — трассировку переделать по нему: это даст точность уровня
  знака (0,318 px), а нынешние числа — ±3 %.
