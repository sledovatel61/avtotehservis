# Круг 13 — эталон раскладки первого экрана

`hero-round13.css` — полный `site/src/styles/hero.css` после круга 13 (фулл-блид).
Здесь он лежит как эталон для задания №14: агенту 5 не нужно угадывать числа.

Что задаёт файл:

- `≥1024`: `.hero` держит пропорцию кадра 16:9 и ограничен `100svh − 96px`; `.slide-bg` растянут
  на весь блок (`position:absolute;inset:0`), фон без рамки, радиуса и тени; скрим — два градиента
  (слева под текст, снизу под подписи), `::after` отключён; текст `max-width:min(46%,720px)`;
  `hero-scroll` и `hero-ui` уведены вправо, из-под кнопок.
- `641–1023`: кадр 100 % ширины 16:9 + горизонтальный скрим, текст пока **под** фото
  (задание №14 переводит и планшет на фон).
- `≤640`: панель текста поверх фото, мобильный кроп 4:5, `object-position:50% 20%`.

Связанные ассеты круга 13 — `site/public/img/hero-service-*` (8 файлов, источник
`docs/photos-source/r13-clean/gen-hero-c.jpg`) и `about-service-*` (кроп `master-clean-3840.png`).
