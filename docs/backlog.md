## 7. Как читать эту доску

- **Раздел 1** — если пункт здесь, запуск не считается завершённым.
- Пункт, который висит **два круга**, перестаёт быть «потом»: либо ставим срок, либо
  официально отказываемся.
- Строка «в работе» без ссылки на PR старше суток — повод спросить агента, где он.
