# Конфликты между страницами, сервисным руководством и справочником сообщества

Сверка сделана по текущим текстам `origin/preview/github-pages` и корпусу `docs/research/voyah-chat/`. «Сайт» — конкретный контентный файл/блок. «Руководство» — только вложенный заводской Service Manual; «сообщество» — отдельный не-заводской источник. Владелец решил: рабочие интервалы сайта не менять; для интервалов показывать базовую цифру документа и пояснять сокращение в тяжёлых условиях; объёмы/моменты допустимы как справочная таблица без операций. Остальные конфликтующие спецификации не разрешены одной только этой политикой.
