## Файлы

- `corpus.jsonl.gz` — обезличенный корпус, 2,4 МБ, по строке на сообщение:
  `i` id, `d` дата, `a` автор (`u…`), `t` текст, `r` ответ на, `m` вложение (`p` фото,
  `f` файл), `fw` переслано.
- `stats.json` — цифры выше в машинном виде.
- `scan.mjs` — выборки без чтения всего файла в контекст:

```bash
cd docs/research/voyah-chat-r75
node scan.mjs stats
node scan.mjs grep "не встал" --min 300 --limit 20
node scan.mjs grep "tbox" --context 2 --limit 10
node scan.mjs thread 552779 --depth 3
node scan.mjs sample --n 25 --min 500 --seed 7
node scan.mjs top --field month
```

`--min` отсекает односложные «+» и «спасибо», без него выборка бесполезна.

## Границы

- Авторы обезличены необратимо, но текст сообщений остаётся чужим: **на сайт он не
  переписывается дословно**. Разрешён пересказ факта, а не цитата.
- Ссылки из чата (t.me, disk.yandex.ru, сторонние скрипты `voyah-free-update` и подобные)
  на сайте не публикуются.
- Фото и файлы из экспорта в корпус не входят и как источник для сайта не используются.
