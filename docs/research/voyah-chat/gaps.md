# Voyah Free: чего в чате нет и где он сам себе противоречит

Этот файл важнее `facts.md`: по нему видно, **что нельзя писать на сайте как факт**.
Формат: утверждение → что именно не подтверждено → какие сообщения смотрят в разные стороны.
Ссылки — `[msg НОМЕР, дата]`, источник тот же (53 662 сообщения, 17.06.2024 … 12.11.2026).

Ограничение метода: я читал корпус только через выборки по шаблонам (758 уникальных
сообщений из 53 662, из них 89 полностью). «Ответа не найдено» значит «не найдено в
просмотренном», а не «в чате его точно нет». Где это критично — помечено.

## B. Числа и артикулы, встретившиеся по одному разу (или только как вопрос)

Нельзя использовать без независимой проверки.

- Свечи на рест: «NGK SILZKR8E8G ?» — только вопрос [msg 848539]. Оригинального артикула
  свечи реста в просмотренном **нет вообще**; OEM 3707200-F00-00A — только для дореста
  [msg 818116]. Сообщества к единому ответу не пришло [msg 684912, 28.09.2024],
  [msg 726803, 26.10.2024], [msg 1139831, 08.10.2025].

- Ресурс свечей: «30» встречается в вопросах и личной практике [msg 576080], [msg 640174],
  прямой ссылки на документ нет.
- Момент затяжки свечей 25 Нм — одно сообщение [msg 933312].
- Артикул масла генератора реста H41203001 — одно сообщение [msg 550934].
- Артикулы масла редукторов H41202002 / H41202001 — по одному сообщению [msg 847102],
  [msg 1013943].

- Масляные фильтры 101202001 и 101202003 — одно сообщение, без указания, какой для какой

## D. Чего в чате нет вовсе (по результатам запросов)

- **Приводной ремень / ремень генератора / ГРМ**: 6 сообщений на весь корпус по шаблону
  `приводн.{0,10}рем|рем.{0,10}генератор|ремень грм|цеп[ьи] грм`. Ни интервала, ни
  артикула, ни случаев замены. Писать о проверке или замене ремня со ссылкой на опыт
  владельцев нельзя.
- **Разжижение масла бензином / рост уровня масла**: 0 попаданий по шаблону
  `разжиж|бензин в масл|уров.{0,20}масла.{0,20}(раст|выше|поднял)`; есть единичное «на
  салфетке запах бензина» [msg 558926].
- **Заводские моменты затяжки, зазоры, давления** — нет (кроме единичных выше).
- **Первичные документы** (сканы сервисной книжки, страницы руководства) — в экспорт не
  попали: фото не выгружены, вместо них ссылки. Все «по регламенту» — пересказ.
- **Ростов-на-Дону**: город упомянут в 56 сообщениях (41 автор), но почти всё это
  вопросы «где обслуживать», а не опыт и не цены: [msg 579358, 21.07.2024], [msg 688941,
  30.09.2024], [msg 694564, 04.10.2024], [msg 730748, 28.10.2024], [msg 1006352,
  01.06.2025], [msg 1051847, 27.07.2025]. Единственная найденная ростовская сумма — «В
  Ростове за это 10к отдал» за снятие транспортировочного режима [msg 631639, 25.08.2024].
  Цен на ТО, масла и ремонт по Ростову в просмотренном нет; названий рекомендованных
  сервисов я не выписывал (задание: локальные адреса не нужны). Из юга с суммой — только
  Сочи [msg 666738].
- **Статистика**: чат — это жалобы и вопросы. Доли («у каждого третьего») из него
  получить нельзя; счётчики в `facts.md` — число сообщений по шаблону, а не число машин.

## E. Что нужно знать о качестве самих данных

- В чате вперемешку Free дорест 33, дорест 39, рест, 318/Sport+, чистая электро, а также
  Dream [msg 821307, 26.12.2024], [msg 1608375, 18.08.2026]. Во многих сообщениях версия
  не названа, и число нельзя привязать к машине.
- Часть «проблем» — пересказы чужих историй («здесь писали», «читал на драйве»); в
  `facts.md` они вынесены в раздел 6.
- Счётчики «N авторов» считают по отображаемому имени: один человек с двумя именами даст
  двух авторов, тёзки — одного.
- Шаблон «рейк» ловит «батарейку»: исходный счётчик 422 по рулевой рейке завышен, верный
  порядок — 379 по `(^|[^а-яё])рейк|рулев`, включая любые упоминания руля.
