## Правила работы с кадром (редакция 2, 22.10.2026)

**Можно:**

- убирать случайное — машины на улице, бак, хлам, лужи, провода, заборы по краям;
- достраивать недостающее **нейтральным** (кирпичная кладка, зелень, ровный асфальт);
- ставить **две презентабельные машины** перед фасадом как композицию первого экрана —
  BMW 5, Camry, K5, Sonata, E-class, Vesta; на литых дисках; вариант «лоб в лоб».

**Нельзя:**

- перерисовывать вывеску, название, телефоны, бренды на баннере;
- менять число ворот, архитектуру, добавлять несуществующее оборудование;
- ставить суперкары (Bugatti, Ferrari, Lamborghini, Rolls-Royce), лимузины и «шоу-кары»;
- оставлять читаемые номера машин.

**Честность.** Машины на первом экране — добавленный декор, а не «работы сервиса». Поэтому честный
кадр без них обязан остаться на сайте: `about-service-*` и фото на «Контактах». В отчёте это
указывается явно.

## Как использовать

Финальные версии — в `site/public/img/` (публичные, оптимизированные), исходники и промежуточные
проходы — здесь, чтобы можно было пересобрать.

Ключевые кадры из одного фото:

1. **Фасад целиком с машинами** — hero, первый слайд.
2. **Фасад без машин** — «О компании», «Контакты» (честный кадр).
3. **Вывеска крупно** (верхняя треть) — для полосы «сервис вблизи».
4. **Левый бокс** (ворота + подъёмник) — для карточки «как выглядит внутри».
5. **Правые ворота** — альтернативный кроп, третий кадр полосы.

Подробности задания — `prompts/13-task-round8-fixes.md` (редакция 2).
