## Что на фото (по разбору оркестратора)

- **Вывеска** — синий баннер: логотип NGN, бренды (BARDAHL, KORSON, PROMATIX, LYNX, SUOFIX, ICHIRO),
  название «АвтоТехСервис», три телефона: `+7 (951) 826-98-39`, `+7 (951) 826-58-47`, `+7 (863) 229-19-50`.
  **Текст на вывеске менять нельзя** — это реальные контакты; при ретуши их надо сохранить читаемыми.
- **Боксы** — два проёма, внутри подъёмники, машины (белый кроссовер на подъёмнике, седан в боксе).
- **Что владелец просил убрать/поправить:** серую машину с открытым капотом справа (стоит на улице),
  мусорный бак слева, общий «рабочий» беспорядок; сделать кадр опрятнее и презентабельнее.
- **Ограничение:** это реальный объект. Убирать случайное (машина, бак, провода) — можно.
  Пририсовывать несуществующее оборудование, менять вывеску, телефоны, названия — **нельзя**:
  фото станет неправдой о сервисе.

## Как использовать

Положить финальные версии в `site/public/img/` (публичные, оптимизированные), а исходники
оставить здесь. Промежуточные кропы — тоже сюда, чтобы можно было пересобрать.

Ключевые кадры, которые можно вырезать из одного фото без потери смысла:

1. **Фасад целиком** — для hero и блока «О компании».
2. **Вывеска крупно** (верхняя треть) — для полосы фактов / мобильного hero.
3. **Левый бокс** (ворота + подъёмник) — для карточки «как выглядит внутри».
4. **Правая часть с воротами** — альтернативный кроп.

Подробности задания — `prompts/12-task-round7-home-design.md`.
