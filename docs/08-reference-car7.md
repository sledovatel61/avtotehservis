### 2.2. Типографика — почему «топорно»

```css
body        { font-family: 'Open Sans', sans-serif; font-size: 14px; line-height: 32px; color: #5f5f5f; }
h1…h6       { font-family: 'Montserrat', sans-serif; }
меню        { font-family: 'Varela Round', sans-serif; font-size: 11px; text-transform: uppercase; }
```

Четыре гарнитуры, три из них подключены `@import` с `fonts.googleapis.com` (медленно, и в РФ это ещё и внешний запрос). Заголовки — Montserrat 500, 25–38 px, **все капсом**. Основной текст — Open Sans 14/32: мелко и с огромным межстрочным. Отсюда ощущение «топорности»: капс + мелкий текст + разреженные строки.

### 2.3. Палитра

| Роль | Цвет | Где |
|---|---|---|
| Акцент | `#ff9320` | кнопки, ховеры, полоски, цифры, иконки |
| Тёмный | `#252525` | фон шапки, тёмные блоки, текст заголовков |
| Текст | `#5f5f5f` | основной текст (`body`) |
| Белый | `#ffffff` | фон, текст на тёмном |
| Светлые серые | без точных значений | пункты меню и второстепенный текст на тёмном |
| Тёмные серые | без точных значений | разделители и рамки в шапке |

Схема простая: тёмная шапка + оранжевый акцент + серый текст на белом. Ровно та, что заказчику не нравится.

В начале `style.css` CSS-переменных нет: цвета проставлены вручную в правилах. Отсюда и «перекраска» — чтобы сменить акцент, надо править файл по всему тексту.

### 2.4. Ключевые компоненты

**Шапка** — тёмная, три колонки: логотип 225 px, центральный блок 745 px в тонких рамках (сверху «Добро пожаловать на сайт автосервиса!» + адрес, снизу меню из 6 пунктов), справа телефон и кнопка «Заказать звонок» 165 px.

**Заголовок секции** (`.section-title`) — фирменный приём шаблона:

```
[eyebrow 11px капс оранжевый]
ЗАГОЛОВОК 25px КАПС #252525
— ———[оранжевая полоска 40px]——— —
```

Полоска сделана через `::before`/`::after` — две линии по 20 px с отступами. Этот приём можно переосмыслить.

**Слайдер-герой** — 750 px высотой, фото на весь экран, затемнение 45%, по центру H1 38 px + подзаголовок курсивом 15 px + кнопка. Автопрокрутка, эффект fade.

**Три блока услуг** — высота 320 px, фон оранжевый / оранжевый / чёрный, иконка 56 px, номер, заголовок капсом, текст.

**Карточка услуги** — фото 4:3, цена крупно, название, подпись «Высокое качество по доступной цене».

### 2.5. Форма записи — разбор кода

Файл `Запись/_files/car-7.html`, 24 КБ. Устроена так:

| Поле | Как реализовано | Проблема |
|---|---|---|
| Год выпуска | **jQuery UI slider**, диапазон 1987–2025, значение по умолчанию 2016 | Слайдер для года — худший способ ввода: 39 делений на 300 px, попасть в свой год невозможно |
| Марка | `<select>` из **9 марок**, превращённый в jQuery UI `selectmenu` | Нет поиска, нет «другой марки». Владелец ремонтирует всё, а форма знает только Lexus и Porsche |
| Пробег | текстовое поле без маски | «84 тыс», «84000», «84 000 км» — всё уйдёт как есть |
| Дата | текстовое поле с плейсхолдером **`MM/DD/YYYY`** | Американский формат в русском интерфейсе; `datepicker` навешан, но подсказка врёт |
| Время | `<select>` из 9 слотов **`09:00 AM – 10:00 AM`** | 12-часовой формат; слоты до 18:00, хотя сервис работает до 19:00 |
| Услуги | чекбоксы, значения собираются как **текст активных `li`** | Хрупко: любое изменение разметки ломает заявку |
| Контакты | имя, телефон, e-mail, сообщение | E-mail обязателен зря — лишнее поле |
| Валидация | `if(!name)` / `if(!phone)` → модалка «Укажите ваше имя» | Проверяется только пустота; телефон не проверяется на длину, e-mail — вообще |
| Согласие | **отсутствует** | Нарушение 152-ФЗ: персональные данные собираются без согласия |
| Отправка | `$.post('?page=appointment-send', {...})` → модалка «Отправлено» | Нет номера заявки, нет состояний, нет обработки ошибки |
| Потеря данных | поля очищаются **до** ответа сервера | Если запрос упал — человек вводит всё заново |

Это и есть «слабая форма», о которой сказал заказчик. Разбирать её в мокапе надо именно так — по пунктам.

## 4. Что копируем и что меняем

### Копируем

- Набор и порядок страниц, меню из 6 пунктов, хлебные крошки, активный пункт.
- Порядок секций главной целиком.
- Приём «три крупных блока услуг с номерами 01/02/03».
- Компоновку шапки: логотип — меню — телефон с кнопкой действия.
- Композицию заголовка секции (надзаголовок + крупный заголовок + графический акцент), но в новой графике.
- Логику формы: авто → время → услуги → контакты.
- Детальную страницу услуги с переходом в запись.
- Новости с категориями и пагинацией.

### Меняем

| У референса | У нас | Почему |
|---|---|---|
| Open Sans + Montserrat + Varela Round, `@import` с Google Fonts | Одна-две современные гарнитуры с кириллицей, самохостинг или системный стек | «топорные шрифты», плюс внешний запрос |
| `#ff9320` + `#252525` | **Своя палитра у каждого агента** (см. задание) | прямая просьба заказчика |
| Всё капсом, 14 px текст | Нормальный регистр, крупнее кегль, плотная шкала | читаемость и «не топорно» |
| Анимация = fade в слайдере + параллакс | Система движения: каскады, hover, переходы страниц, счётчики | «слабая анимация» |
| Слайдер года 1987–2025 | Поле года с валидацией или выбор из списка | попасть в год на слайдере невозможно |
| 9 марок в селекте | Поиск по марке + «другая» | сервис ремонтирует всё |
| `MM/DD/YYYY` | Русский календарь, формат `ДД.ММ.ГГГГ` | очевидно |
| `09:00 AM – 10:00 AM` | Слоты 09:00–19:00, шаг 1 час, 24-часовой формат | рабочий день владельца |
| Нет согласия | Отдельный чекбокс + ссылка на политику | 152-ФЗ |
| Модалка «Отправлено» | Экран с номером заявки и «что дальше» | понятный результат |
| jQuery + Bootstrap + 316 КБ CSS | Нативный CSS/JS, свой файл стилей | вес и поддерживаемость |
| Цены на карточках | Без цен («стоимость после осмотра») | у владельца нет прайса |
| «С 2010 года», «10 000 заказов», «лучшие в городе» | Только подтверждённые факты | запрет на выдумки |
| Стоковые фото и чужие отзывы «ООО Компания» | Заглушки + наши данные | нельзя копировать чужое |

**Тексты референса не переносим** — копируем архитектуру и приёмы, а не абзацы про «специализированный автотехцентр».
