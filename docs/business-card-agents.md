# Визитки «АвтоТехСервис»: промпт для трёх агентов

**Что это.** Готовое задание, которое копируется целиком в три отдельных чата агента (Claude Code, Cline, Cursor — любой, который умеет писать файлы и запускать код). Каждый агент делает **5 концепций визитки, каждая с двух сторон**, и собирает из своих пяти **один коллаж** для предварительного просмотра. Ничего не печатаем и не финалим, пока владелец не выберет.

**Сколько получится на выходе:** 15 концепций × 2 стороны = 30 макетов, три коллажа. Из них выбираем 1–2 и доводим до печати.

**Почему не генерация картинок нейросетью.** Ни одна модель не рисует кириллицу и телефонные номера без ошибок, а ошибка в одной цифре телефона — это брак тиража. Поэтому макеты делаются кодом (SVG/HTML с настоящими шрифтами и точными координатами), а картинка получается рендером в PNG 300 dpi. Все пятнадцать концепций будут с читаемым текстом, и любую можно сразу отдать в печать.

## Как запускать

1. Откройте три новых окна агента (Claude Code / Cline / Cursor) — почему новых, см. следующий раздел.
2. Подключите каждому только GitHub и выдайте доступ к репозиторию `sledovatel61/avtotehservis`. Drive не нужен.
3. В каждое окно вставьте два блока по порядку: сначала «Сообщение для отправки агенту», потом промпт «ТЫ — АГЕНТ N». В первом окне `N = 1`, во втором `N = 2`, в третьем `N = 3`.
4. Ничего больше не добавляйте: все факты, цвета, шрифты, формат и правила репозитория уже внутри.
5. Когда все три закончат — пришлите мне номер ветки каждого агента (вида `agent-NN/cards`) или три папки. Дальше я соберу общий коллаж 15 концепций и разберу их по критериям приёмки.

## Кого брать: новых или наших

**Новых, три чистых окна.** Причина простая: те агенты, что делали сайт, помнят свои прошлые решения и начнут повторять hero-блок вместо того, чтобы придумать визитку. Чистому агенту даём факты, палитру и доступ к репозиторию — он смотрит на сайт свежими глазами.

| Окно | Кто | Почему |
|---|---|---|
| 1 | Claude Code (Opus/Sonnet) | сильнее всех держит композицию и аккуратно пишет SVG |
| 2 | Cline + GPT | у вас уже настроен, хорошо считает геометрию и точки |
| 3 | Cursor (или второй Cline) | третье независимое мнение, чтобы не было «одной идеи в трёх окнах» |

Я (этот чат) — не участник, а приёмка: собираю все 15 концепций в общий коллаж и разбираю по критериям. Так голосов не четыре против одного.

**Не подключайте агентов к Drive с правами записи.** Сайт и шрифты им нужны только на чтение — репозитория достаточно. Drive с исходниками рискует получить кучу мусорных файлов, а нам это не нужно. Читать с Drive им нечего: все факты и палитра уже в промпте и в коде.

**Куда агент кладёт работу.** В репозитории уже есть протокол: работа агента живёт в `agents/agent-NN/`, оттуда её забирает скрипт `scripts/import-agent.sh` в `agents-output/`. Поэтому папка агента — `agents/agent-NN/cards/`, номер `NN` = 01, 02, 03 по числу окна. Ветку с сайтом агент не трогает, он пушит свою `agent-NN/cards` — её я и заберу.

**Что дать каждому агенту:**

1. Ветку репозитория `arena/ffa2735f-avtotehservis` (сайт уже в ней, папка `site/`) — чтобы открыть настоящий код и шрифты, а не угадывать по описанию.
2. Текст промпта из этого файла, с заменой `N` на номер окна.
3. Ничего больше. Палитра, знак, факты и формат внутри промпта.

Ключевые файлы, на которые агент смотрит в репозитории:

```

site/src/styles/fonts.css         какие начертания есть
site/public/fonts/*.woff2         сами шрифты (Unbounded 600, Golos Text 400/500/700)
site/public/img/logo.svg          знак-мишень
site/src/pages/index.astro        главная: ритм, воздух, как стоят заголовки
site/src/pages/contacts.astro     адрес, часы, телефоны — сверить с визиткой
site/src/server/settings.ts       единственный источник фактов (DEFAULTS)
```
