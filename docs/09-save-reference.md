# 09. Как сохранить референс целиком (если нужен исходный код)

Из моей среды полное зеркало сайта скачать нельзя: разрешены только GitHub, npm и PyPI, всё остальное блокируется на уровне сети (`curl` к `matronet.com` и даже к `example.com` даёт `SSL_ERROR_SYSCALL`). Инструмент чтения страниц отдаёт текст, но не CSS, JS и картинки.

**Хорошая новость:** для работы это не блокер. Структура всех 8 страниц, порядок секций и состав форм уже зафиксированы в `docs/08-reference-car7.md`. Исходный код нужен только если захочется дословно повторить вёрстку.

Ниже — три способа, от простого к полному.

---

## Способ 1. Сохранить в Яндекс.Браузере (просто, по одной странице)

1. Откройте страницу: `https://matronet.com/demo/car-7`.
2. Дождитесь полной загрузки (картинки, шрифты) — иначе сохранится пустая рамка.
3. Нажмите **Ctrl + S** (или меню ⋮ → «Сохранить страницу как…»).
4. В поле «Тип файла» выберите **«Веб-страница, полностью»**.
5. Сохраните в папку `reference/matronet-car-7/`.
6. Повторите для каждой страницы — их 8:

| Что сохраняем | Адрес |
|---|---|
| Главная | `https://matronet.com/demo/car-7` |
| О компании | `https://matronet.com/car-7?page=about` |
| Услуги | `https://matronet.com/car-7?page=services` |
| Одна услуга | `https://matronet.com/car-7?page=service&id=299782` |
| Запись | `https://matronet.com/car-7?page=appointment` |
| Новости | `https://matronet.com/car-7?page=news` |
| Одна статья | `https://matronet.com/car-7?page=post&id=299785` |
| Контакты | `https://matronet.com/car-7?page=contacts` |

**Важно:** браузер создаст рядом с каждым HTML папку `<имя>_files` со стилями, скриптами и картинками. Не переименовывайте и не разделяйте их — иначе страница откроется без оформления.

---

## Способ 2. SingleFile — каждая страница в один файл (удобнее для репозитория)

1. Установите расширение **SingleFile** (есть в Chrome Web Store, Яндекс.Браузер его поддерживает).
2. Откройте страницу, нажмите иконку расширения — страница сохранится в **один HTML** со встроенными стилями, шрифтами и картинками.
3. Сохраните все 8 страниц в `reference/matronet-car-7/singlefile/`.

Плюс: не нужно тащить папки с ресурсами, а имена файлов можно оставить осмысленными.
Минус: файлы тяжелее оригинала (картинки внутри base64).

---

## Способ 3. Полное зеркало сайта (HTTrack или wget)

### HTTrack (Windows)

1. Скачайте с `https://www.httrack.com` и установите.
2. «Next» → проект: имя `matronet-car-7`, папка — `reference/matronet-car-7/httrack`.
3. URL: `https://matronet.com/demo/car-7`.
4. В «Set options» → вкладка **Scan** → включите «Capture all links» и убедитесь, что параметры (`page=`, `id=`) не отбрасываются, иначе страницы с `?page=…` не скачаются.
5. «Finish» → дождитесь окончания.

### wget (Linux/macOS)

```bash
wget --mirror --page-requisites --adjust-extension --convert-links --no-parent \
     --span-hosts --domains=matronet.com \
     "https://matronet.com/car-7?page=home" \
     "https://matronet.com/car-7?page=about" \
     "https://matronet.com/car-7?page=services" \
     "https://matronet.com/car-7?page=appointment" \
     "https://matronet.com/car-7?page=news" \
     "https://matronet.com/car-7?page=contacts"
```

Без явного перечисления страниц с параметрами `wget` их не найдёт.

## Куда положить и как назвать

```
reference/
  matronet-car-7/
    README.md                 ← появится от меня, описание
    home/                     ← сохранённые страницы
    about/
    services/
    appointment/
    news/
    contacts/
```

Требования GitHub: один файл не больше **100 МБ**, репозиторий — желательно до 1 ГБ. Если получилось больше 50 МБ — лучше заархивировать (`matronet-car-7.zip`), но тогда я не смогу разбирать файлы по отдельности.

## Если не получится сохранить

Ничего не останавливается: структура референса уже описана, раунд мокапов можно запускать прямо сейчас. Исходный код пригодится только для точного повторения вёрстки — и то вряд ли: палитру, шрифты, анимацию и форму мы всё равно переделываем.
