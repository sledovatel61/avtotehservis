# Как добавить статью в «Полезное»

## 1. Войти

Откройте `/manage/`, подключитесь своим личным ключом в блоке доступа и
выберите вкладку **«Полезное»**. Не передавайте ключ другим людям.

## 2. Написать статью

Нажмите **«+ Новая статья»**. Заголовок увидят читатели на странице.
**«Заголовок для поиска»** — необязательная короткая подпись для Яндекса и
Google; если оставить поле пустым, используется обычный заголовок.

Описание — пара предложений о том, чем статья полезна. Хороший пример:
«Рассказываем, когда проверять состояние ремня ГРМ, какие признаки износа
опасны и почему замена вовремя помогает избежать серьёзного ремонта двигателя.»
Плохой пример: «Всё про ремни». Выберите категорию и напишите текст. В нём
можно использовать `#` для заголовка, `-` для списка, `**слова**` для
выделения и `[цены](/prices)` для ссылки. Справа или ниже виден предпросмотр.

Адрес создаётся из заголовка; до первой публикации его можно исправить. После
публикации адрес не меняется, иначе перестанут работать сохранённые ссылки и
поиск.

## 3. Добавить фото

Выберите фото в поле обложки, настройте рамку и нажмите **«Готово»**. Обложка
появится на карточке и в начале статьи. Добавьте короткую подпись к фото.
Если обложку не выбрать, будет показана картинка по умолчанию.

## 4. Сохранить и опубликовать

Нажмите **«Сохранить черновик»**, затем общую кнопку **«Сохранить»** внизу
вкладки. Черновик на сайте не виден. Чтобы показать статью, откройте её,
нажмите **«Опубликовать»**, а затем **«Сохранить»** внизу. Через 1–2 минуты
откройте ссылку на статью и проверьте результат. Состояние обновления можно
проверить кнопкой **«Обновить статус»**.

Чтобы снять статью с сайта, нажмите **«Скрыть»** и сохраните. Для удаления
нажмите **«Удалить»**, подтвердите и сохраните: после этого удаление необратимо.
Перед уходом со страницы сохраните изменения, иначе они потеряются.
