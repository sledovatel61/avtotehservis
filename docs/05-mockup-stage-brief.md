# Бриф этапа 2: HTML-мокап в одном файле

Кому: топ-3 агентов по итогам оценки.
Срок: 2 дня. Результат: `mockups/mockup-<агент>.html` + 5 строк самопрезентации в PR/сообщении.

## 1. Жёсткий формат

- **Один .html-файл**, всё внутри: `<style>` и `<script>` инлайн. Без сборки, npm и внешних CSS.
- Внешние ресурсы: только шрифты Google Fonts (или system stack) и опционально GSAP с CDN.
  Медиа берите из `mockups/assets/` (относительные пути `../assets/…`) — 4 изображения уже сгенерированы:
  `hero.jpg`, `work-suspension.jpg`, `work-engine.jpg`, `work-wheel.jpg`.
- Никаких `alert()` и «мертвых» кнопок: квиз реально проходит шаги и показывает экран успеха (отправку имитируем).
- Открывается двойным кликом, работает в Chrome/Safari/Firefox, без консольных ошибок.

## 2. Обязательный состав страницы

1. **Sticky-хедер**: лого/имя, телефон `tel:`, кнопка «Записаться», на мобиле — компактный + нижний sticky-бар
   `Позвонить · Заявка · Маршрут`.
2. **Hero**: сильный оффер, подзаголовок с фактами (Портовая 439 · рейтинг 4,5 · 182 оценки · ежедневно),
   два CTA, визуал, индикатор «листайте». Первый экран должен продавать за 3 секунды.
3. **Быстрый выбор проблемы** (чипы: «стучит подвеска», «горит чек», «толчки в АКПП», «шины/диски»,
   «кондиционер», «ТО») — клик подставляет выбор в квиз и скроллит к нему.
4. **Услуги** (bento/сетка, 8–10 карточек): ТО и масло, диагностика, ДВС, КПП, подвеска/рулевое, тормоза,
   электрика, климат, шины и диски, развал-схождение.
5. **Квиз** (ядро): 5–6 шагов, прогресс, назад, валидация; марка/модель (хотя бы datalist на 20–30 марок),
   VIN (17 символов + «не знаю VIN»), неисправности (мультивыбор + «не знаю, нужна диагностика»),
   срочность, контакт (телефон с маской, имя, канал связи, согласие), экран успеха.
6. **Как мы работаем**: 5 шагов (заявка → диагностика → согласование → ремонт → гарантия/выдача).
7. **Почему доверяют**: 4–6 фактов без выдумок (рейтинг 4,5/182, широкий профиль включая АКПП и правку дисков,
   адрес/удобный заезд, прозрачное согласование, реальные фото работ).
8. **Галерея работ**: минимум 6–8 карточек (можно повторять 4 изображения с разными подписями),
   фильтры по типам работ, у каждой карточки подпись «симптом → что сделали → срок», лайтбокс
   (клик, Esc, стрелки, свайп), видео-карточка с постером и кнопкой play.
9. **Отзывы**: сводка 4,5/182 (Яндекс.Карты), 5–6 карточек с источником и датой, кнопка «Оставить отзыв».
10. **FAQ** (6–8 вопросов) + **контакты**: адрес, карта-заглушка (красивый блок с кнопкой «Маршрут» на Яндекс.Карты),
    телефон, режим, ориентир.
11. **Футер**: реквизиты-заглушки, политика ПД, кнопка в Telegram/WhatsApp.

Дополнительно (плюс к оценке): мини-превью админки (например, модалка «Добавить кейс» с drag-зоной загрузки) —
показать, что администрирование простое.

## 3. Дизайн-требования

- Тёмная индустриальная палитра (графит/сталь + один акцент CTA), крупная типографика, много воздуха.
- Никаких стоковых «улыбающихся механиков», синих градиентов и шестерёнок.
- Единая сетка, ритм отступов (4/8), продуманные состояния (hover/focus/active/disabled/loading/error/success).
- Мобильная версия — не «сжатый десктоп»: 360, 390, 430 px проверяем в DevTools; квиз — одна колонка,
  крупные кнопки, bottom-sheet вместо модалок.
- Контраст AA, видимый фокус, семантика, alt у изображений.

## 4. Анимация (главный вау-эффект, но без тяжести)

- Reveal-появление секций через IntersectionObserver (или CSS scroll-driven), stagger 40–80 мс.
- Микроинтеракции кнопок и карточек (сдвиг 2–4 px, подсветка рамки, лёгкий scale 1.01–1.02).
- Прогресс квиза с плавным заполнением и сменой шагов (translate + fade, 250–350 мс).
- Один «вау»-эффект на выбор: (a) сборка схемы узла из SVG-линий при скролле; (b) счётчик рейтинга/цифр;
  (c) «сканирующая» полоса по фото кейса; (d) параллакс 3–5 % на hero-изображении.
- `prefers-reduced-motion: reduce` — всё отключается, остаётся статичная версия.
- Никаких видео-фонов, 3D, WebGL, автозвука, scroll-jacking.

## 5. Контент

- Только проверенные факты из `docs/01-company-dossier.md`. Никаких выдуманных отзывов, имён, цен и гарантий.
- Если данных нет — честная заглушка: «уточните по телефону» / «требует подтверждения».
- Тексты — живые, короткие, в одном тоне. Телефон везде `+7 (928) 906-57-00` как `tel:+79289065700`.
