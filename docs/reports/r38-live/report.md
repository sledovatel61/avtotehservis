**Остаток 1 — «призрак» кузова в фоновой пластине.** `plate-bg-1600.webp` — фон, в который
кузов был залит прямоугольной заплатой с жёсткими краями. После правки силуэта заплата
стала видна там, где альфа кузова уходит в ноль:

- файл `plate-bg`: вертикальная граница на 21,0 %W, ступенька 88–94 px, Δ 5,3…7,8 L;
- кадр 1440×900 t = 1400: грань на x = 256 (17,8 %W), длина 82 px, Δ 8,6 L — в эталоне
  в этом месте граней нет (скан 1440: «нет прямых граней», у нас одна);
- в gamma-boost (`plate-bg-ghost.jpg`) под бампером видны плоские блоки: пурпурный
  (≈ x 340…640), зелёный (≈ x 800…1270), серый клин — в эталоне там гладкий градиент.

**Остаток 2 — 390×844.** Линия ДХО упирается в левый край: зазор слева **0,0 %W**,
справа 3,8 %W (требование ≥ 3 % с каждой стороны).

**Остаток 3 — гейт `intro-vs-ref` зависит от аспекта.** На 16:9 проходит
(1600×900 — 2/22, 1920×1080 — 1/22 FAIL), на 1440×900 (16:10) — **7/22 FAIL**:
плато 6,7 px, купол 68,7 %W, зеркало верх 11,8 %H / низ 31,3 %H, знак 4,51 %W,
пропорция знака 1,094, заполнение зеркала 47,1 %. Часть строк — геометрия гейта
(порог задан в %H при разной высоте кадра), часть может быть реальной. Нужно либо
нормировать гейт по аспекту, либо доказать кадром 16:9, что на 16:10 всё в норме.
