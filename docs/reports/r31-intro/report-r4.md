# Круг 31 / задание №52 — A5, фаза 3: отражение в полу

База — дерево оркестратора `108c526` (A5 ред. 3 + A10 фаза 2 сведены). Правка одна, по §9
разбора `docs/reports/r31-review/review-3.md`: отражение не читалось в кадре.

## 1. Что было не так (подтверждаю разбор)

```
depth = clamp((p.y - FLOOR) / 280.0, 0.0, 1.0);
col  += acc / wsum * 0.30 * reflIn * pow(1.0 - depth, 2.4);   /* ноль на y = 1010 */
```

`FLOOR = 730`, зеркальная копия полосы ДХО живёт на `y = 2·FLOOR − 448 = 1012`, то есть
**на 2 px ниже порога затухания** — самое яркое, что могло отражаться, отсекалось
по построению. Плюс вес 0,30 против 35–40 % из `FRONT.md` §7.

## 2. Что сделано

```glsl
/* затухание до НИЗА кадра (1080), а не до FLOOR + 280 = 1010 */
float gap  = clamp((p.y - FLOOR) / (1080.0 - FLOOR), 0.0, 1.0);   /* 0 у пола, 1 у нижней кромки */
float fade = 1.0 - smoothstep(0.60, 1.0, gap);                     /* гаснет только в самом низу */
col += acc / wsum * 0.38 * reflIn * fade;                          /* вес 0,38 — по §7 */
```

- на копии ДХО (`y = 1012`, `gap = 0,806`) множитель `fade = 0,478`, итоговый коэффициент
  `0,38 × 0,478 = 0,182` — отражение доходит до копии полосы;
- у нижней кромки кадра (`y = 1080`) `fade = 0` — резкой «полки» нет;
- вес 0,38 — в коридоре 0,35–0,40;
- три тапа `layers()` и геометрия отражения не менялись, стоимость кадра не выросла (§5).

Рейлинги, тайминги, знак, заливка, фон, полосы-гейты — **не тронуты**.

Строка `y = 843` — это ровно копия полосы ДХО (`scene y = 1012`); до правки там было ровное
поле без линии, теперь полоса видна как линия отражения. Кроп «до/после» —

разбора («отражения в кадре нет») подтверждается: до правки в полосе пола не было ни знака,

## 6. Что осталось честно сказать

- Отражение теперь **видно**, но оно мягкое: копия ДХО — линия в 44/255 на фоне полосы 20/255,
  знак — до 130/255. Это ровно то, что даёт вес 0,38 при `reflIn ≈ 0,5` в фазе 1400 мс;
  если владельцу нужно «как в мокром асфальте» — это уже вес 0,5–0,6 вне §7, решать ему.
- Отражение силуэта кузова (тёмное) в кадре читается слабо по построению: кузов почти чёрный
  (`vec3(0.004)`), отражать в нём нечего — видны только знак, полоса ДХО и кромки.
- Проверял только Chromium/SwiftShader в песочнице; на живом железе картинка та же (шейдер
  без ветвлений по устройству), а вот fps надо мерить на ноутбуке/телефоне.
