# Круг 31 / задание №55 — A10, фаза 3: константы тени под новую длину кузова

База — дерево оркестратора `108c526`. Правка по §10 разбора `docs/reports/r31-review/review-3.md`
(поправка 2) и §7 того же разбора. Кромка — **не тронута** по прямому указанию.

## 1. Что было

```
gy  = q.y - CAR_GROUND;
shd = exp(-(q.x * q.x * 0.75 + gy * gy * 20.0));
col *= 1.0 - 0.62 * shd;
```

Коэффициент `0.75` писался под длину силуэта **1,976 ед.** сцены. После переезда на паспортный
масштаб (`SCALE.bg3d = 0.6 / 1.645`) длина стала **1,789 ед.**, а константа осталась — тень
выросла до **1,08 длины кузова** (было 0,97). На глаз это «мягкая тень», но это дрейф, а не решение.

## 2. Что сделано

Замер `scripts/bg3d-edge-shadow.mjs` показал: полуширина гауссианы `exp(−a·x²)` на полувысоте
равна `sqrt(ln2 / a)`, значит

```
полуширина = 0.97 · L / 2   ⇒   a = ln2 / (0.97 · L / 2)²
```

В `src/client/bg3d/shader.ts` коэффициент теперь **считается из данных**, а не зашит:

```ts
const SHADOW_LEN  = CAR.length * SCALE.bg3d;               /* длина силуэта, ед. ≈ 1.789 */
const SHADOW_HALF = 0.97 * SHADOW_LEN * 0.5;               /* полуширина на полувысоте ≈ 0.868 */
const SHADOW_X    = Math.LN2 / (SHADOW_HALF * SHADOW_HALF); /* ≈ 0.9206 */
...
float shd = exp(-(q.x * q.x * ${SHADOW_X.toFixed(4)} + gy * gy * 20.0));
```

- по **x**: `0.75 → 0.9206` — тень снова 0,97 длины кузова;
- по **y** `20.0` и множитель `0.62` **не менялись**: они задают вертикальную мягкость и
  плотность, а не длину — менять их значило бы менять вид тени, чего в задании нет;
- **кромка** `edge = 1 − smoothstep(0.0, 0.016, |sd|)` не тронута: 4,78 px, как принято в §7;
- при следующей смене профиля коэффициент поедет сам — дрейфа больше не будет.

## 4. Порт и гейт — в одной сдаче со сценой

- `scripts/bg3d-edge-shadow.mjs` больше **не хранит** константы «после»: коэффициент по x
  считается из `CAR.length * SCALE.bg3d` той же формулой, а `20.0` и `0.62` читаются регуляркой
  из `src/client/bg3d/shader.ts`. Если формулу в шейдере перепишут так, что регулярка не найдёт
  константы, скрипт падает с exit 1 — мерить «воспоминание» он не может.
- `tools/bg3d/ref.mjs` и `tools/bg3d/ref-dyn.mjs` (CPU-порты стоимости) обновлены тем же
  `SHADOW_X` — порт совпадает со сценой, замер `measure:bg3d`/`measure:bg3d:dyn` снят с неё же.

- Кромку не трогал (прямое указание §7): её +17,6 % относительно кузова — следствие того, что
