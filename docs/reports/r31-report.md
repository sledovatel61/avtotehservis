## 1. Фон включён — что именно сделано

Решение владельца: «давай включи 3д фон, давай хоть посмотрим». Для этого пришлось
убрать **две технические дырки**, которые не давали включить фон вообще:

| Что было | Что сделано |
|---|---|
| Слой фона был подключён только к шаблону `/services/<slug>`. Страница `/voyah-free` — отдельный файл `src/pages/voyah-free.astro`, и **фона на ней не было ни при каком флаге** | слой вставлен в первый экран `/voyah-free`, внутри `.v-hero-bg` (там же, где фото) — тёмный градиент героя остаётся поверх сцены, контраст заголовка не меняется |
| Фотография героя осталась бы под сценой и «спорила» с ней | при включённом фоне `picture` скрывается: `v-hero--bg3d .v-hero-bg picture{display:none}` |
| В песочнице и на витрине нет GPU (SwiftShader), гейт честно гасил фон → владелец не увидел бы **ничего** | серверный флаг `BG3D_DEMO=1`: снимает блокировку программного растеризатора и порог «слабое железо», watchdog не гасит сцену. **Это не параметр в адресе** — включает только тот, у кого есть доступ к env сервера; на боевой публикации не выставляется |
| Стенд `/lab/bg3d` падал с `ReferenceError: variant is not defined` — `variant` из frontmatter недоступен в клиентском скрипте | читаем вариант из адресной строки; стенд больше не гаснет от watchdog (его задача — показывать и мерить), появился `?demo=1` для машин без GPU |

**Важно про прод:** защита не тронута. Без `BG3D_DEMO=1` фон по-прежнему выключается на
программном растеризаторе, на слабом железе, при `saveData`, при низкой батарее и при
`prefers-reduced-motion` (в последнем случае — статичный кадр). Watchdog тоже на месте:
гасит сцену, если fps ниже 70 % цели даже на 50 % разрешения.
