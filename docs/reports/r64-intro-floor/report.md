# Круг 64 (r37-live, A12) — заставка VOYAH: убран прямоугольник пола

**Итог: прямоугольник убран, швов нет на всех трёх вьюпортах, гейт PASS 22/22.**

Дефект был такой: `body-1600.webp` — альфа 255 на 89,03 % площади, промежуточной
альфы 0,00 %, на y = 75 %H — 98,8 % непрозрачных при L = 1,1. Маска читалась
плитой, и в кадре был виден край: 1440×900 — x 226…1209 (68 %W), y 474…833
(40 %H), переход 34 → 6 L за 1 px; 1920×1080 — вертикальный шов 321 px на
x = 99,2 %W; 1568×882 при t = 1400 — шов 172 px, перепад 28 L на x = 19,1 %W.

## Что сделано и почему

### 1. Альфа — по силуэту машины, а не по кропу

Три причины плиты, все найдены замером:

1. **span-fill по столбцам** заливал каждый столбец от верхушки кузова до низа
   кадра (остался с круга 33, когда порог `isCar` рвал силуэт на полосы).
   Снят. Вместо него — построчная заливка **узких** просветов (порог 12 px):
   замер эталона показал, что детали кузова (перо капота, ДХО, знак, стыки
   панелей) выбивают просветы 1–3 px, а пол между шинами — 613 px уже на
   hero 850. Прежний порог 120 px рвал кузов и заливал пол.
2. **`ref-mask.png` для силуэта не годится**: на hero 867 он даёт 60 %W белого
   там, где фото честно даёт 35 %W (пол между шинами). Маска снята с залитым
   полом. Маску строим сами по тому же порогу, что и гейт: R < 45, R−B < 18,
   G−B < 12.
3. **Кроп был габаритом кузова** (372…1553 × 67…1080). Внутри такого кропа
   кузов занимает 83 % площади при норме ≤ 45, а края кропа совпадают с краями
   пластины — отсюда и швы. Кроп стал полным кадром 1920×1080: кузов = 38 %,
   края пластины уходят за кадр.

Плюс вертикальные просветы в зоне капота (hero 250…430): красный капот, ловящий
свет, не проходит `isCar` целыми строками — замер показал провал альфы по всей
ширине на hero 345…360, а выше и ниже силуэт сплошной.

Линия пола: hero y=900 — первая строка пола (83,2 %H кадра 1080). Ниже неё
альфа 0 и маска 0; дилатация RAD=4 тоже не заходит ниже (тянула соседей из
896…899 в строку 900 и давала 51 %W при маске 0 %W).

### 2. Мягкая кромка

Бинарная альфа давала 0,00 % промежуточных значений — на dpr 2 читалась лесенка.
Перо «наружу» (255 внутри, затухание за границей) дало только 38 %: сама граница
оставалась жёсткой 255. Рабочее решение — рампа **внутрь** силуэта на 2 px файла
(у края 0,38, через пиксель 0,8, дальше 1,0) плюс затухание 1 px наружу.
Профиль через левую кромку: `0 0 0 0 97 97 255 255` — переход в 2 px, обе
стороны промежуточные.

### 3. Тёмное пятно под машиной

Пятно приходит из `plate-bg` (не из альфы кузова). В зоне 0,66…0,98 H /
0,19…0,81 W медиана 1,5 L. Плюс убрана ступенька на стыке двух режимов фона:
выше 700 работает квадратичная аппроксимация светового пятна, ниже — медиана
пула пола, и на y=698 было 28…32 L, на y=700 — 8…9 L. Перепад 24 L за 2 строки
давал в кадре горизонтальный шов 1179 px. Теперь режимы смешиваются по весу на
полосе 40 px: 16 → 10 → 7 → 6 → 4 → 2 → 1 L на 60 px.

### 4. Швы

`scripts/intro-seams.mjs` — прогон t=100…1900 шаг 100 на 1920×1080, 1440×900,
390×844, порог 60 px / 2,5 L в зоне y 0,60…0,99 H. Отчёт — `seams.json`.

Метрика **сравнительная**: шов засчитывается только там, где в нашем кадре
перепад есть, а в эталоне на той же геометрии его нет. Без этого абсолютный
порог ловил борт машины как дефект — замер эталона на hero 781: x 377 держит
33 L (красный фон), x 379 уже 6 L (тёмный борт), и край этот прямой на 99 из
141 строки. Это край кузова, он есть в эталоне и дефектом не является.

### 5. Силуэт на 390×844

`k = 1.55 * uRes.x / BW` → `0.94`: кузов 94 % ширины экрана, зазор 3 %W.
Было 155 % — силуэт шире кадра, линия ДХО упиралась в оба края, читался
фрагмент бампера вместо машины.

### 6. FLOOR в шейдере

`FLOOR = 730` (67,6 %H) → `899` (83,2 %H, контакт шин). Было на 169 px выше
реального контакта: отражение включалось по `p.y > FLOOR` и ложилось поверх
бампера и низа кузова.

### 7. Флак гейта «купол крыши +2 %H» (п.6 задания)

На 1600×900 t=1400 гейт давал 21/22 по строке «купол крыши +2 %H» (66,1 %W при
норме ≤ 45): релинг 20 px (2,2 %H) поднимает topA, и окно +2 %H читает широкую
часть крыши. Сейчас строка проходит: кромка пластины стала мягкой, релинг не
даёт ложного тёмного пикселя у края.
