## 1. Устройство заставки

| Что | Как |
|---|---|
| Контекст | `canvas.getContext('webgl2', { antialias:false, alpha:false, depth:false, stencil:false, premultipliedAlpha:false, preserveDrawingBuffer:false, powerPreference:'high-performance', desynchronized:true })` |
| Геометрия кадра | один полноэкранный треугольник по `gl_VertexID` — буферов, атрибутов и VAO нет; сцена считается raymarching-ом SDF прямо во фрагментном шейдере |
| Bloom | два прохода через framebuffer: сцена → текстура, яркий проход по горизонтали в ¼ разрешения → композит (сцена + bloom, виньетка, тонмаппинг) |
| Текстуры-файлы | 0 — всё процедурное (`hash13`, SDF, `smoothstep`) |
| Внешние запросы | 0 (см. §6) |
| Когда создаётся | не в `head`: оверлей собирается скриптом страницы, первый `draw()` идёт в `requestAnimationFrame` |
| Тайминг | CSS-переменные `--vy-scene` (конец сцены) и `--vy-panel` (уход оверлея), JS читает их через `getComputedStyle` |
| Заставка на каждый заход | да, ни `sessionStorage`, ни cookie; `?intro=0` выключает |
| Пропуск | клик, Esc, колесо, touchmove → оверлей снимается ≤300 мс |
| Очистка | после снятия: `cancelAnimationFrame`, все `clearTimeout`, снятие всех слушателей, `WEBGL_lose_context`, `box.remove()`, `body.vy-lock` снят, canvas в DOM нет |
| Фолбэк без WebGL2 | статичный кадр своей же сцены (`img/vy-intro-poster.webp`, 1200×750, 25 КБ), оверлей живёт 782 мс |

Файлы:

- `site/src/client/voyah-intro.ts` — код заставки (шейдеры сцены/bloom/композита, оверлей, пропуск, адаптивное качество);
- блок `/* @intro-start */ … /* @intro-end */` в `site/src/styles/voyah.css`;
- `site/public/img/vy-intro-poster.webp` — кадр-фолбэк (снят с этой же сцены при t≈0,62);
- старая SVG-разметка заставки удалена (она собиралась из `voyah-intro.ts`, поэтому файл переписан целиком);
- `site/src/pages/voyah-free.astro` — по-прежнему `import '../client/voyah-intro.ts'`.

## 2. Длительность (3 прогона на размер)

Методика: стенд `site/pages-dist` на локальном сервере, Chromium 131
(`--enable-unsafe-swiftshader`), счётчик ставится **до** загрузки страницы;
`t0` — момент, когда canvas (или постер) реально получил размер и виден;
конец — удаление узла `.vy-intro` из DOM (опрос в `requestAnimationFrame`:
`MutationObserver` через `evaluateOnNewDocument` падает).

| Прогон | 1440×900 | 390×844 |
|---|---|---|
| 1 | 2501 мс | 1429 мс |
| 2 | 2547 мс | 1451 мс |
| 3 | 2504 мс | 1431 мс |
| норма задания | 2200–2600 мс | ≤1500 мс |
| финальная шторка (`--vy-panel` + 140 мс запаса) | 351–366 мс | 348–356 мс |

Тайминг в CSS: `--vy-scene:1950ms`, `--vy-panel:300ms`; мобильная ветка
`.is-quick`: `1000ms` / `240ms`. Итог = сцена + шторка + 140 мс на снятие узла.
Последние ~300 мс оверлей прозрачнеет — на кадре `desk-1850.jpg` уже видно
открывающуюся страницу.

## 3. fps

**В песочнице нет GPU**: все браузерные прогоны идут на SwiftShader
(программный растеризатор), поэтому fps ниже реального в разы и
**показателем не является**. Измерено (`window.__vyIntro3d`):

| Размер | fps (SwiftShader) | кадров за заставку | адаптивный scale |
|---|---|---|---|
| 1440×900 | 10,1–10,6 | 20–21 | 0,42 |
| 390×844 | 28,9–31,0 | 29–32 | 0,45 |

**fps на трёх реальных устройствах не измерен** — в песочнице нет ни одного
реального устройства, выдумывать цифры не буду. Косвенно: сцена — три прохода
по одному треугольнику, адаптивное качество после 8/20/44-го кадра понижает
разрешение сцены, если средний кадр тяжелее 32 мс, и повышает, если легче
13 мс.

ни шрифтов.

## 10. Что честно не сделано / ограничения

1. **fps на реальных устройствах не измерен** — в песочнице нет GPU и нет
   реальных устройств. Цифры §3 показывают только, что анимация живая.
2. Гейт и скрипты круга запускаются в песочнице с `LD_LIBRARY_PATH`,
   указывающим на библиотеки NSS из `@sparticuz/chromium` (в образе нет
   системного NSS). На CI это не нужно.
3. Покадрово сверить «как на GPU» нельзя: SwiftShader даёт ту же геометрию
   (сверялось по пикселям), но иначе считает `fwidth`, поэтому толщина
   неоновых линий на реальной видеокарте будет чуть другой.
4. Незакоммиченная версия заставки была потеряна при обнулении песочницы и
   переписана заново; кадры и цифры этого отчёта — с новой сборки.
