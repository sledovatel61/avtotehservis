# Круг 74 — заставка и 3D-фон выключены к показу заказчику

Запрос владельца (13.11.2026): «Отключи пока заставку и 3д анимацию — я хочу показать
страницу заказчику, а в таком виде показывать нельзя».

Вердикт по эффектам не изменился: оба варианта не приняты («очень топорно», «сейчас вообще
не годится»). Поэтому **код не удалён, а выключен** — возврат одним флагом сборки.

## Что сделано

| Что | Где | Как выключено |
| --- | --- | --- |
| Заставка на `/voyah-free/` | `site/src/client/voyah-intro.ts` | флаг `PUBLIC_VY_INTRO` (по умолчанию `off`), проверка первой строкой |
| 3D-фон | `.github/workflows/pages.yml` | убраны `BG3D=voyah-free` и `BG3D_DEMO=1`; `bg3d-config.ts` и так отдаёт `off` |

Заставка: при выключенном флаге Vite подставляет `false`, бандлер выкидывает `boot()`
вместе с шейдерами — в странице остаётся 44-байтный модуль с маркером
`window.__vyIntro = 'off'`. Ни `matchMedia`, ни WebGL-кода в бандле нет.

3D: без переменной `BG3D` страница не рендерит ни `data-bg3d`, ни `<canvas>`,
ни кнопку «Выключить 3D-фон»; `Bg3dLayer` — обычный кадр героя `vy-art-*`.

## Гейты

- `site/scripts/check-voyah-layout.mjs`, L6 переписан: по умолчанию проверяет, что
  оверлея `.vy-intro` нет ни сразу, ни через 2,9 с, нет `body.vy-lock`, нет `canvas`,
  заголовок не перекрыт, прокрутка свободна; при `VY_INTRO=1` — прежние тайминги
  (2200–2600 / 1200–1500 мс), шторка 250–470 мс, пропуск ≤300 мс. В `--self-test`
  добавлен DOM-мутант «заставка вернулась»; CSS-мутанты интро при выключенной
  заставке не гоняются (иначе self-test зеленел бы вхолостую).
- Новый `site/scripts/check-intro-3d-off.mjs` — проверка по собранному артефакту без
  браузера: нет разметки оверлея, нет `data-bg3d`/`canvas`/кнопки, шейдеров заставки
  нет в `_astro/*.js`, есть маркер `off`, inline-модуль ≤200 Б. `--expect=on` —
  обратная проверка для сборки с `PUBLIC_VY_INTRO=1`. Подключён в `npm test` и в
  workflow `pages.yml` (шаг после `check-pages`).

**Почему статический гейт:** в песочнице приёмки Chromium не стартует —
`@sparticuz/chromium` требует `libnss3`, которого в образе нет (`libnss3.so: cannot open
shared object file`), а `apt-get` без root не работает. Поэтом браузерные L1–L6 здесь
не прогнать; артефакт проверяется статически, а `check-intro-3d-off.mjs` в CI проверяет
ровно тот файл, который уезжает на Pages.

## Как вернуть

```bash
# заставка
PUBLIC_VY_INTRO=1 npm run build:pages
# 3D-фон (демо-показ без GPU — только на превью)
BG3D=voyah-free BG3D_DEMO=1 npm run build:pages
```

Гейт компоновки в этом случае запускать с `VY_INTRO=1`, чтобы проверять включённое
состояние, а не выключенное.
