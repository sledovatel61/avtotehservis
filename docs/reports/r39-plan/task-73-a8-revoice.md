Разбирать жалобы владельцев — правильно, раздел «Что чаще всего беспокоит владельцев»

### Что исправить на странице

Сейчас на `/voyah-free` есть такие формулировки (`.astro` и `.md` — синхронно):

1. `voyah-free.astro:430`: «Это темы чата, не статистика неисправностей.»
   → «Это не статистика неисправностей: жалоба — не диагноз, проверяем машину.»
2. `voyah-free.astro:91`: «В чате описывали ошибку сразу или примерно через 100 км…»
   → «Встречается ошибка сразу после заправки и примерно через 100 км; причина не
   установлена.»
3. Таблица, строка 318: «задний 2,35–2,7 **(чат)**/0,85±0,05 л (справочник)»
   → «задний 2,35–2,7 л по практике/0,85±0,05 л по справочнику» — или просто
   «задний: 2,35–2,7 или 0,85±0,05 л, уточняем по VIN».
4. Подпись под таблицей: «Задний 318: **чат** — 2,35–2,7 л, справочник — 0,85±0,05 л.»
   → «Задний 318: 2,35–2,7 л либо 0,85±0,05 л, уточняем по VIN.»
5. FAQ, вопрос про редукторы: «Для заднего 318 **чат** приводит 2,35–2,7 л…»
   → «Для заднего 318 встречаются значения 2,35–2,7 л и 0,85±0,05 л; уточняем по VIN.»
6. Eyebrow раздела: «По сообщениям владельцев» → «На подъёмнике» или «Частые обращения».

Правило то же, что и для статей A9: убрать `чат`, `переписк*`, `сообщени*` в значении
«сообщение в чате», `авторов`, `форум`, `обсуждени*`. Оставить можно `справочник
сообщества`, `наша практика`, `владельцы описывали` — последнее допустимо, это не про чат.

Проверка:

```bash
grep -ciE "чат|переписк|форум|обсуждени" site/src/pages/voyah-free.astro content/merged-r28/a8/voyah-free.md
grep -o -i "чат[а-я]*" site/pages-dist/voyah-free/index.html | wc -l   # после сборки → 0
```

(`«сообщени»` отдельно проверь глазами: «на сообщения владельцев» — плохо, «сообщим после
осмотра» — нормально.)
