## Как читать (важно для контекста)

Целиком 65 МБ не читать ни в контекст, ни в один вызов. Читай так:

1. Скачай нужные файлы в рабочую папку вне git (например `/tmp/chat/`) через
   коннектор `google_drive` → `download_file` (файл приходит base64) либо
   `read_file_text` с `max_chars` 120 000–150 000.
2. Дальше работай **grep'ом по локальным файлам**, а не чтением в контекст:
   `grep -o` по ключевым словам (масло, редуктор, генератор, свечи, антифриз,
   тормозная, колодки, регламент, ТО, пробег, гарантия, гул, стук, ошибка, цена, ₽, руб).
   Получив список хитов, читай только окрестности ±3 сообщения.
3. Минимум — **8 файлов**, равномерно по всей длине: `messages.html`, `messages10`,
   `messages20`, `messages30`, `messages40`, `messages50`, `messages60`, `messages75`.
   В отчёте честно перечисли, что прочитано, а что нет.

## Что отдать

### 1. `docs/research/voyah-chat/facts.md`

Только проверяемые утверждения, каждое — со ссылкой:

```
### Масло в редукторах
- Объём переднего редуктора — 0,9 л, допуск … [messages42.html, msg 612345, 14.03.2025]
- Владельцы отмечают гул после 60 тыс. км … [messages51.html, msg 700112, 02.06.2025]
```

Разделы (пустой раздел лучше пропустить, чем наполнить домыслами):
1. **Расходники и допуски** — масло ДВС (вязкость, допуски, объём), масло генераторной
   установки, масла редукторов (объём, тип), антифриз, тормозная жидкость, свечи
   (артикул, зазор, ресурс), фильтры, ремни.
2. **Регламент и интервалы** — что и через сколько км/лет, что проверяют на ТО,
   что отдельно у гибридной части.
3. **Типичные неисправности** — симптом → причина → на каком пробеге → чем закончилось.
   Отдельно выдели то, что повторилось у 3+ разных владельцев.
4. **Стоимость** — кто сколько платил за конкретную работу (регион, дата, сумма),
   и отдельно цены на расходники.
5. **Вопросы владельцев** — 15–25 штук, формулировка близко к оригиналу + краткий
   ответ из чата. Это заготовка FAQ для страницы, пиши так, чтобы редактору было
   из чего выбирать.
6. **Спорное и мифы** — где источники расходятся или утверждение сомнительное:
   помечай `[спорно]`, не выбирай «удобную» версию.

Правила:
- **Ничего не додумывать.** Нет числа в чате — нет числа в файле.
- Каждый факт со ссылкой: файл + номер сообщения + дата. Без ссылки — не пишем.
- Артикулы, допуски и объёмы копировать посимвольно, включая варианты написания.
- Личные данные (имена, телефоны, адреса, VIN, номера машин) **не переносить**:
  вместо имени — «владелец».
- Локальные адреса сервисов из других городов нам не нужны.
