## 4. Дисциплина: что A13 сделал правильно

- **Не выдал пересказ за документ.** Первая строка `facts.md`: «это пересказ сообщений
  владельцев, а не данные завода». Числа, у которых источники расходятся, не «разрешены»,
  а вынесены в `gaps.md` (10 противоречий) — включая главное: по интервалу редукторов
  в чате живут четыре разных «регламента» (10 / 30 / 40 / 60 / 80 тыс.).
- **Разделил версии машины** (дорест 33 / дорест 39 / рест / 318 / чистая электро 88).
  Без этого объём масла в редукторе «0,85 л» и «3 л» выглядели бы как ошибка, а это
  разные машины.
- **Честно о покрытии**: 758 уникальных сообщений из 53 629 (1,4 %), 89 полным текстом,
  106 запросов с шаблонами и счётчиками — весь список в приложении отчёта. Это выборка,
  и так и написано.
- **Не затащил персональные данные**: имён, телефонов, VIN, госномеров в файлах нет
  (проверил по никам, которые точно есть в корпусе, — ноль вхождений).
- **В git попали только `docs/**`**, сам чат не закоммичен.

## 6. Три замечания редакторам (не переделывать, учесть при письме)

1. **Покрытие 1,4 %.** «Ответа не найдено» в `gaps.md` означает «не найдено в выборке»,
