## Что было не так в самом векторе

При первом прогоне `vectorize-voyah.py` выяснилось, что причиной «обрезанного» файла был не
размер `viewBox`, а его вид: `viewBox` писался в абсолютных координатах эталона
(`546,8 50,2 441,6 620,1`), а контуры — в локальных, от нуля. Браузер показывал пустоту,
метрики по локапу этого не видели. Теперь кадр начинается в нуле, а привязка к эталону живёт
в JSON (`frames.*.origin_px`) — и гейт сверяет svg с эталоном именно по ней, поэтому подмена
кадра ловится (мутант обрезки).

## Границы

- Вектор ведётся от `docs/brand/voyah/source/logo-black-on-white.png` (1536×864): знак 440×620,
  пропорция **0,7097**. `site/public/img/vy-mark.png` (512×733, 0,699) искажён на ~8 % —
  он не эталон и остался только как PNG-фолбэк вне разметки. Пропорцию 0,757 из постановки
  не воспроизводили: в исходнике владельца её нет.
- `docs/brand/voyah/source/` не менялся; тексты, прайс, шапка, футер, заставка (`A5`),
  3D-фон (`A10`), `preview/github-pages` не тронуты.
- PNG-фолбэки (`vy-mark.png`, `vy-mark-ghost.png`, `vy-label.png`, `vy-lockup.png`) остаются
  в `site/public/img`, но из разметки и CSS убраны.

## Как перепроверить

```bash
cd site
python3 scripts/vectorize-voyah.py          # пересобрать 12 SVG + JSON из эталона
node scripts/check-voyah-vector.mjs         # C/M/L/K/E/J/I — 22 пункта
node scripts/check-voyah-vector.mjs --self-test   # 3 мутанта
node scripts/make-voyah-vector-report.mjs   # compare.png + metrics.json
npm test                                    # весь конвейер, rc=0
```

`@resvg/resvg-js` — только в `devDependencies`: рантайм сайта от него не зависит,
в `src/` он не упоминается.
