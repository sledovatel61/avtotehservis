# Отзывы: как управлять ими на сайте

Отзывы клиентов не появляются на сайте автоматически. Сначала проверьте текст и
опубликуйте его в мастерской. Для сохранения нужен личный ключ GitHub с правом
Contents: Read and write для этого сайта — инструкция по его созданию находится
в блоке «Подключение к GitHub» на странице мастерской.

## Шаг 1. Открыть список

1. Откройте `/manage/` на сайте, вставьте ключ в разделе подключения и нажмите
   **«Проверить»**.
2. Откройте вкладку **«Отзывы»**. Кнопки **«Все»**, **«Опубликованные»** и
   **«Скрытые»** помогают отобрать нужные записи. Числа рядом — их количество.
3. У опубликованного отзыва нажмите **«Скрыть»**, чтобы убрать его с сайта,
   или у скрытого — **«Опубликовать»**, чтобы показать. Изменения вступят в
   силу только после сохранения.

## Шаг 2. Опубликовать отзыв из Telegram

1. Скопируйте сообщение с отзывом из Telegram и вставьте его в поле
   **«Вставить текст из Telegram»**. Нажмите **«Разобрать»**.
2. Проверьте имя, оценку, текст и дату. Строки «Оценка: 5/5» и «Имя: Павел И.»
   разбираются отдельно; остальное становится текстом. Удалите из текста лишние
   служебные сведения, если они есть. Данные из Telegram мастерская сама не
   получает: вставлять текст нужно вручную.
3. Нажмите **«Добавить в список»**, затем у нового скрытого отзыва —
   **«Опубликовать»**. Внизу вкладки нажмите **«Сохранить»**.
4. Дождитесь сообщения об отправке. Через 1–2 минуты откройте ссылку
   **«Открыть /otzyvy на сайте»** и проверьте отзыв. Ссылка **«Ход сборки»**
   покажет состояние обновления сайта.

## Шаг 3. Добавить или исправить вручную

Нажмите **«＋ Добавить отзыв»**, укажите имя (2–40 знаков), оценку, текст
(20–1500 знаков), источник, дату и при необходимости ссылку на источник.
Нажмите **«Добавить в список»**. Новый отзыв скрыт до нажатия
**«Опубликовать»**. Для исправления существующего нажмите **«Изменить»**,
затем **«Готово»**. Сохраните изменения одной кнопкой внизу вкладки.
Если есть ошибка, исправьте поле, указанное под формой: сохранить с ошибкой
нельзя. При закрытии страницы несохранённые изменения потеряются.

## Шаг 4. Удалить примеры перед запуском

Примеры отмечены чипом **«пример»**. Нажмите **«Удалить все примеры»** и
подтвердите действие; настоящие отзывы останутся. Затем нажмите **«Сохранить»**.
Отдельный отзыв можно убрать кнопкой **«Удалить»** с подтверждением. Если
удалить последний опубликованный отзыв, на сайте вернётся заглушка про
Яндекс.Карты. Дождитесь сообщения об отправке и проверьте страницу отзывов.

Если другой человек изменил тот же отзыв одновременно, сохранение может
остановиться с предупреждением. Обновите страницу, ещё раз проверьте данные и
повторите правку; до обновления перепишите свои несохранённые изменения.
