# 12. Контент-чек-лист для владельца

Дата: 21.10.2026. Сайт собирается с честными заглушками; здесь — что заменить своим, чтобы он стал «настоящим». Приоритет — сверху вниз. Подробные требования к съёмке — `docs/07-photo-brief.md`.

**Правила:** ни одного стокового фото, ни одного выдуманного факта, ни одной цены без подтверждения. Пока контента нет, на сайте стоит аккуратная заглушка или пустое состояние — не «красивая ложь».

## 4. Чего на сайте не будет

- цен, «от N ₽», прайс-листа — прайса нет;
- «с 2010 года», «20 лет на рынке», «1000 клиентов», «№1», «лучший», «100%»;
- сертификатов, наград, брендов оборудования без подтверждения;
- отзывов, написанных нами;
- фотографий из шаблона matronet и любых стоков;
- рейтингов без источника и даты;
- `AggregateRating` в разметке.

## 5. Как заменять заглушки

*Реализовано в `site/` (этап 4, M3): админка работает по этому сценарию. Обновлено по факту внедрения 21.10.2026.*

1. Войти в `/admin/login` (логин и пароль создаются командой `npm run admin:create` на сервере; пароль печатается один раз).
2. **Кейс:** «Кейсы» → «＋ Новый кейс» → фото (мультивыбор, до 12) или видео (+ постер) → заголовок → «Опубликовать». Обложка — первое медиа, слаг генерируется автоматически, услуга — по желанию. Цель — ≤ 60 секунд с телефона (4 действия на одном экране).
3. **Услуга:** «Услуги» → выбрать → поправить тексты (Markdown), метку, порядок, SEO-поля; изображение — поле пути (до съёмки остаются SVG-заглушки `/img/svc-*.svg`).
4. **Главная (hero):** hero-изображения — файлы `/img/hero-1..3.svg` в сборке; замена на фото — через разработчика (слайдер рассчитан на SVG-арт). Марки и блок рейтингов — в «Настройках» (рейтинги скрыты, пока владелец не подтвердит цифры).
5. После замены проверить: фото не растянуто, alt заполнен, страница открывается на телефоне.

## 6. Критерий «контент готов»

- [ ] 6 кейсов с фото «до/после» опубликованы.
- [ ] Hero и 6 услуг с реальными фото.
- [ ] 1–3 видео в галерее.
- [ ] Тексты о компании, преимуществ и услуг проверены владельцем.
- [ ] Гарантия описана.
- [ ] Рейтинги либо подтверждены со ссылками, либо скрыты.
- [ ] Политика ПД проверена юристом, дата и версия совпадают с формой.
- [ ] Ни одной заглушки и ни одной пометки «демо» на публичных страницах.
- [ ] Доп. телефоны подтверждены владельцем и включены в `/admin/settings` (или намеренно оставлены скрытыми).
