## 4. C: плашки — здесь блокер

Разметка (`site/src/pages/index.astro`, строки 199–203):

```html
<div class="fact">
  <div class="fact-bg" aria-hidden="true">…about-f4…</div>
  <div class="fact-bg" aria-hidden="true">…about-f3…</div>
  <div class="fact-bg" aria-hidden="true">…about-f2…</div>
  <div class="fact-bg" aria-hidden="true">…about-f1…</div>
  <b>{S.address_full}</b><span>ост. «3-й Поселковый» ~330 м</span>
</div>
<div class="fact"><b>{S.hours}</b><span>без выходных</span></div>
<div class="fact"><b>Гарантия на работы</b>…</div>
<div class="fact"><b>Легковые и грузовые</b>…</div>
```

Замер DOM на 1440 и 390 совпадает: у первой плашки `bgCount = 4` (все четыре картинки `about-f4/f3/f2/f1`, каждая 283×106, `z-index:0`, `display:block`), у второй–четвёртой `bgCount = 0`. То есть:

1. три из четырёх плашек **без своего фона** — уровень C выполнен на одной;
2. в первой плашке видна только последняя по порядку фактура (`about-f4`, сталь и резина) — а должна была быть «тёплый бетон и медь» по §2.5 для 01 «адрес»;
3. четыре файла фактуры (25,9 КБ) приезжают ради одной видимой — остальные три лежат друг под другом и не видны никогда;
4. «стеклянность» `.fact` (было `rgba(16,32,26,.6)`) снята, а замена стоит только в первой плашке: у трёх остальных сквозь текст виден фон секции.

Скриншоты: `facts-390-2x.jpg` (все четыре плашки — своя фактура только у первой), `fact1-bg-2x.jpg` (первая плашка без текста: видна ровная тёмная поверхность, `mean 21,1 / sd 5,0` — тот же порядок, что и у пустого фона), `fact1-2x.jpg` (с текстом).

**Почему гейт зелёный.** В `check-about-bg.mjs` разметка проверяется глобальным счётом:

```js
if (cnt(/<div class="fact-bg" aria-hidden="true"><picture>/g) !== 4) bad.push(…);
```

Счёт по всему документу — 4. Где именно эти четыре стоят, гейт не спрашивает. Мой внешний мутант «удалить второй `.fact-bg`» падает (стало 3), а **реальное состояние** — четыре слоя в одной плашке — проходит. Это тот самый случай «гейт, который не может упасть».

### 8.11 **minor — мастера 2400×1600 получены апскейлом из 1408×768**

Стоит написать это одной строкой в отчёте, чтобы приёмка не считала размеры независимым подтверждением качества.
