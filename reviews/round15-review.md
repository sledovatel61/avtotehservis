Что это значит:

1. **Панель съехала влево на 20 px.** Причина в CSS: два `@media (max-width:640px)` подряд — сначала новый блок (`hero.css:178`, `.slide{…display:flex;flex-direction:column}` без `align-items`, `.slide-in{margin:0}`), затем **старый дубль** (`hero.css:292`, `.slide{align-items:flex-end}` + `.slide-in{margin:0 10px 10px}`). `width:100%` + `flex-end` + боковые `margin:10px` дают коробку шире контейнера: левая кромка уходит за экран, левый padding аннулируется. Итог — H1 в 2 px от края экрана.

3. **Следствие** — на 320×640 и 360×800 кнопки уезжают под сгиб, а это ровно тот сценарий, который задание §5 называет «первый экран перестаёт быть первым».

### M2. Гейт «закрыть навсегда» — тавтология; меню проверяется формулой

`site/scripts/check-hero-layout.mjs`, §3b:

```js
for (const [vw, vh] of [[1217,598], …]) {
  const heroW = vw;                                   // width:100% — переноса ширины нет
  const heroH = Math.min(vh - 96, vw * 9 / 16);
  const band = vw - heroW;                            // всегда 0
```

Ни одного обращения к DOM/рендеру: `band` математически всегда 0, значит `band === 0` и «полоса справа 0 px» печатаются при **любой** вёрстке. Единственный реальный предохранитель — регулярка на текст CSS (`\.hero\{[^}]*width:100%;min-height:0;aspect-ratio:16\/9`).

Проверил мутацией на копии (`/tmp/mut`):

| что подложил | ожидание | результат скрипта |
|---|---|---|
| убрал `width:100%` из обоих блоков ≥1024 (возврат дефекта №1) | FAIL | **exit 1** — но только по регулярке; строка «окно 1217×598: герой 1217×502, полоса справа 0 px» при этом «ok» |
| **добавил** `.hero{max-width:calc(100vw - 96px)}` (герой реально уже окна на 96 px) | FAIL | **exit 0, «нормы §2 выполнены»** |

То есть §1.4 задания («добавить числовую проверку ширины и падать с exit 1») **формально выполнен, по существу нет**: проверка подтверждает намерение, а не результат. Ровно эту болезнь задание и описывает в §0.

Там же §3d — «шапка 1024: меню в одну строку: нужно **834 px из 1024**»: цифра собрана из таблицы «символ × 7,4 + padding», а в браузере меню занимает **1 107 px** и выносит кнопку за край (§6 M1). Проверка зелёная при сломанном рендере.
