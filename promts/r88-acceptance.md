Задание требует лишь «`robots.txt` указывает на домен», формально пункт пройден, но по смыслу это надо решать. **Адресат: Агент 10** — сделать `Disallow: /` только для превью, а для `PUBLIC_ORIGIN` домена писать `Allow: /` + `Sitemap: https://ats-rostov.ru/sitemap.xml`. ## Что осталось владельцу

1. **Отправить настоящий отзыв и заявку с `https://ats-rostov.ru/`** и убедиться, что обе пришли в Telegram-группу. Из моего окружения это невозможно — сеть до домена закрыта. Коды ответов и разбор я проверил на точном коде воркера: отзыв `201`, заявка `201` с талоном, повтор — `duplicate:true`.
2. **Заменить демо-отзывы настоящими.** Админка → Отзывы → «Удалить все примеры» (кнопка блокируется, когда примеров не осталось), затем «+ Добавить отзыв». После этого выставить переменную репозитория `PUBLIC_DEMO_REVIEWS=0`, чтобы гейт сборки не пропустил демо обратно.
3. **Включить KV.** `npx wrangler kv namespace create ATS_KV`, вписать id в `relay/wrangler.toml` (блок закомментирован) и передеплоить. Сейчас `/health` отдаёт `reviewsKv:false` — лимиты и идемпотентность живут в памяти изолята и сбрасываются при перезапуске. Это не дефект (задание прямо разрешает `false`), но дубли отзывов между перезапусками сейчас не отсекаются.
4. **Подключить почту (Resend или Brevo).** `/health` → `email:null`, письмо на `Pavel.yakovenko@mail.ru` при `email:null` — **не блокер** (так и в задании). Команда: `npx wrangler secret put RESEND_API_KEY` (или `BREVO_API_KEY`), затем передеплой.
5. **Проверить Enforce HTTPS** в настройках GitHub Pages для домена. Сейчас он уже отдаётся по HTTPS и старый адрес редиректит на домен, но сам переключатель стоит подтвердить глазами.
6. **Решить судьбу `robots.txt`** — см. замечание 1. Пока на домене стоит `Disallow: /`, поисковики сайт не увидят.
